# ประกาศฯ หลักเกณฑ์การบริหารงานบุคคลและสวัสดิการพนักงาน พ.ศ. 2566 — ดัชนีหัวข้อ

**ทะเบียนเอกสาร:** [`manifest/documents.yaml`](../manifest/documents.yaml) → `hr-personnel-welfare-2566`
**เจ้าของเอกสาร:** HD (พัฒนาศักยภาพบุคลากร) · **กระบวนการ:** `people.personnel-welfare`
**ฐานอำนาจ:** ข้อ 18 ข้อบังคับ มช. ว่าด้วยการบริหารหน่วยงานของส่วนงานวิชาการฯ พ.ศ. 2555 และมติคณะกรรมการอำนวยการอุทยานฯ ครั้งที่ 2/2565 (6 ธันวาคม 2565)
**สถานะ:** **ฉบับปัจจุบัน** ผู้ดูแลยืนยัน 2026-09-20

> **เอกสารนี้เป็นดัชนี ไม่ใช่สำเนา** repository เป็น public และเอกสารแนบท้ายมีตารางค่าตอบแทนรายตำแหน่ง
> จึงเก็บเฉพาะ "มีเรื่องอะไรอยู่ตรงไหน" เพื่อให้ AI ชี้ทางได้ถูก แล้วให้ผู้ใช้เปิดฉบับจริงจาก HD

## คำนิยามที่ใช้ทั้งฉบับ

| คำ | ความหมายตามประกาศ |
| --- | --- |
| ผู้บริหาร | ผู้อำนวยการ รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป |
| ผู้บริหารสาย L | ผู้บริหารที่**ไม่ได้**เลื่อนขั้นมาจากพนักงาน |
| ผู้บริหารสาย S | รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป ที่**เลื่อนขั้นมาจากพนักงาน** |
| ที่ปรึกษาอาวุโส | บุคลากรที่อุทยานฯ ว่าจ้างให้เป็นที่ปรึกษาในการบริหารงาน |
| หัวหน้าทีม / รองหัวหน้าทีม / ผู้ช่วยหัวหน้าทีม | พนักงานประจำที่ผู้อำนวยการแต่งตั้งตามโครงสร้างองค์กร |
| พนักงานประจำ | บุคลากรที่จ้างให้ปฏิบัติงานประจำ |
| พนักงานโครงการ | บุคลากรที่จ้างให้ปฏิบัติงานเฉพาะกิจหรือตามโครงการที่มีกำหนดเริ่ม-สิ้นสุด |
| ปีงบประมาณ | 1 ตุลาคม ของปีปัจจุบัน – 30 กันยายน ของปีถัดไป |

ข้อสังเกตสำหรับ AI: สิทธิและเงื่อนไขหลายข้อใช้คำว่า **"พนักงานและผู้บริหารสาย S"** ซึ่งไม่รวมผู้บริหารสาย L
ถ้าผู้ใช้ไม่ระบุสถานะการจ้าง ให้ถามก่อน อย่าสรุปสิทธิแทน

### หมวด 5 ระเบียบวินัยและการลงโทษ

- 5.1 ระเบียบวินัยที่ต้องปฏิบัติตาม (16 ข้อ)
- 5.2 การลงโทษ — 3 ขั้น: เตือนด้วยวาจา → เตือนเป็นลายลักษณ์อักษร → ตัดเงินเดือนหรือเลิกจ้าง
  โดยอุทยานฯ มีสิทธิ์พิจารณาขั้นการลงโทษได้โดยไม่ต้องเรียงลำดับตามขั้นความผิด

## ข้อ 5.1.16 — ฐานภายในของกติกาข้อมูลใน repository

ประกาศข้อ 5.1.16 กำหนดให้พนักงาน "รักษาข้อมูลทุกอย่างของอุทยานฯ รวมทั้งข้อมูลของลูกค้าเป็นความลับ
ห้ามนำออกไปเผยแพร่โดยไม่ได้รับอนุญาตจากผู้บริหาร" และระบุว่าเป็น **ความผิดขั้นร้ายแรง**

ข้อนี้เป็นฐานภายในที่รองรับ [Repository Data Boundary](repository-data-boundary.md) และ [Knowledge Policy](knowledge-policy.md)
การนำทำเนียบพนักงาน ตัวเลขผลประกอบการ รายชื่อคู่สัญญา หรือเนื้อหาจากระบบภายใน ขึ้น repository สาธารณะ
จึงไม่ใช่เพียงเรื่องความเหมาะสม แต่ขัดระเบียบวินัยขององค์กรโดยตรง

## Guardrails เมื่อ AI ตอบเรื่องนี้

1. ใช้ดัชนีนี้เพื่อชี้ว่าเรื่องอยู่หมวดใดข้อใด แล้วให้ผู้ใช้เปิดฉบับจริงยืนยัน — **ห้ามตอบตัวเลขวันลา เงินเดือน หรือวงเงินสวัสดิการจากความจำ**
2. การประเมินผลงานรายบุคคล การพิจารณาทางวินัย และการลงโทษ เป็น human-only ตาม [`manifest/authority.yaml`](../manifest/authority.yaml) → `hr-performance-evaluation`
3. การผ่อนผันระเบียบเป็น `policy-waiver` ไม่ใช่สิ่งที่ AI ตีความให้ได้
4. แยก "พนักงานและผู้บริหารสาย S" ออกจาก "ผู้บริหารสาย L" ทุกครั้งที่สรุปสิทธิ
5. เอกสารเป็นฉบับปัจจุบัน (ยืนยัน 2026-09-20) ถ้าพบฉบับแก้ไขใหม่ ให้ปรับ `documents.yaml` และดัชนีนี้พร้อมกัน
