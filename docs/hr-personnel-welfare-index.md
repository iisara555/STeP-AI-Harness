# ประกาศฯ หลักเกณฑ์การบริหารงานบุคคลและสวัสดิการพนักงาน พ.ศ. 2569 — ดัชนีและสาระสำคัญ

**ทะเบียนเอกสาร:** [`manifest/documents.yaml`](../manifest/documents.yaml) → `hr-personnel-welfare-2569`
**เจ้าของเอกสาร:** HD (พัฒนาศักยภาพบุคลากร) · **กระบวนการ:** `people.personnel-welfare`
**ฐานอำนาจ:** ข้อ 18 ข้อ 30 และข้อ 32 ของข้อบังคับ มช. ว่าด้วยการบริหารหน่วยงานของส่วนงานวิชาการฯ พ.ศ. 2555 ประกอบมติคณะกรรมการอำนวยการอุทยานฯ ครั้งที่ 1/2569 (21 พฤษภาคม 2569)
**ประกาศ ณ วันที่:** 23 กันยายน 2569 · **บังคับใช้:** 1 ตุลาคม 2569 · **ลงนาม:** ผู้อำนวยการอุทยานฯ
**สถานะ:** **ฉบับปัจจุบัน** — ยกเลิกประกาศฯ ฉบับ พ.ศ. 2566 ทั้งฉบับ (ข้อ 3)

> **ขอบเขตของเอกสารนี้:** ประกาศฉบับนี้เป็นประกาศตราครุฑที่ลงนามและประกาศใช้กับบุคลากรทั้งองค์กร
> HD อนุมัติให้เก็บสาระสำคัญรวมอัตราและจำนวนวันไว้ใน repository ได้
> เอกสารนี้จึงสรุป **หัวข้อ + ตัวเลขที่ประกาศกำหนด** เพื่อให้ AI ตอบได้ตรงข้อ
> แต่ **ไม่ใช่สำเนาฉบับเต็ม** — ถ้อยคำบังคับ ข้อยกเว้น และการตีความสิทธิเฉพาะกรณี ต้องเปิดฉบับจริงจาก HD

> **การเปลี่ยนผ่านจากฉบับ 2566:** ดูสรุปที่ [สิ่งที่เปลี่ยนจากฉบับ พ.ศ. 2566](#สิ่งที่เปลี่ยนจากฉบับ-พศ-2566)
> เอกสาร SOP หรือแบบฟอร์มที่ยังอ้างเลขข้อของฉบับ 2566 ต้องถือว่าอ้างเลขข้อผิดจนกว่าจะปรับ

## คำนิยามที่ใช้ทั้งฉบับ (ข้อ 4)

| คำ | ความหมายตามประกาศ |
| --- | --- |
| อุทยานฯ | อุทยานวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยเชียงใหม่ |
| ผู้บริหาร | ผู้อำนวยการ รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป |
| ผู้บริหารสาย L | ผู้อำนวยการ รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป ที่**ไม่ได้**เลื่อนขั้นมาจากพนักงาน |
| ผู้บริหารสาย S | รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป ที่**เลื่อนขั้นมาจากพนักงาน** |
| ที่ปรึกษาอาวุโส | บุคลากรที่อุทยานฯ ว่าจ้างให้เป็นที่ปรึกษาในการบริหารงาน |
| หัวหน้าทีม / รองหัวหน้าทีม / ผู้ช่วยหัวหน้าทีม | พนักงานประจำที่ผู้อำนวยการแต่งตั้งหรือมอบหมายตามโครงสร้างองค์กร |
| พนักงานประจำ | บุคลากรที่จ้างให้ปฏิบัติงานประจำของอุทยานฯ |
| พนักงานโครงการ | บุคลากรที่จ้างให้ปฏิบัติงาน **ไม่เกิน 1 ปี** โดยมีสิทธิ์ได้รับการประเมินเป็นพนักงานประจำ (จัดเป็นพนักงานชั่วคราวตามข้อบังคับ มช. พ.ศ. 2555) |
| พนักงานทดลองการปฏิบัติงาน | บุคลากรที่จ้างให้ทดลองปฏิบัติงานให้อุทยานฯ |
| พนักงาน | พนักงานประจำ + พนักงานโครงการ + พนักงานทดลองปฏิบัติงาน |
| ปีงบประมาณ | 1 ตุลาคม ของปีปัจจุบัน – 30 กันยายน ของปีถัดไป |

ข้อสังเกตสำหรับ AI:

1. สิทธิและเงื่อนไขหลายข้อใช้คำว่า **"พนักงานและผู้บริหารสาย S"** ซึ่ง**ไม่รวมผู้บริหารสาย L**
2. ฉบับนี้แยก **พนักงานทดลองปฏิบัติงาน / พนักงานโครงการ / พนักงานประจำ** ออกจากกันในหลายสิทธิ
   (เช่น การลากิจ การลาพักผ่อน เบี้ยขยัน รอบจ่ายเงินเดือน) — สถานะการจ้างเปลี่ยนคำตอบ
3. ถ้าผู้ใช้ไม่ระบุสถานะการจ้าง **ให้ถามก่อน อย่าสรุปสิทธิแทน**

## หมวด 1 ระเบียบการจ้างงาน

**เส้นทางการจ้าง:** พนักงานทดลองปฏิบัติงาน → พนักงานโครงการ → พนักงานประจำ
แต่ละช่วงผูกกับผลการประเมิน หากไม่สัมฤทธิ์ผลตามเกณฑ์ หรือไม่เหมาะสมกับตำแหน่งหน้าที่
อุทยานฯ มีสิทธิ์พิจารณาสิ้นสุดการจ้างได้ทันที

| เรื่อง | ที่ประกาศกำหนด |
| --- | --- |
| เกณฑ์คัดเลือก | ความรู้ ความสามารถ คุณสมบัติเฉพาะตัว และ/หรือประสบการณ์การทำงาน |
| สัญญาพนักงานประจำ | ครั้งแรก **1 ปี** จากนั้นต่อสัญญาทุก ๆ **3 ปี** |
| การนับอายุงาน | นับตั้งแต่วันเริ่มปฏิบัติงานในตำแหน่ง **พนักงานทดลองปฏิบัติงาน** |
| แจ้งเปลี่ยนข้อมูลทะเบียนประวัติ | เป็นลายลักษณ์อักษรพร้อมหลักฐานส่ง HD ภายใน **7 วัน** นับแต่มีการเปลี่ยนแปลง |

## หมวด 2 ระเบียบการทำงาน

### 2.1 วันและเวลาปฏิบัติงาน

- วันทำงาน: **จันทร์–ศุกร์** · วันหยุด: เสาร์ / อาทิตย์ / วันหยุดประจำปีตามที่อุทยานฯ ประกาศ
- เวลาทำงาน: **08.30–17.00 น.** (พัก 12.00–13.00 น.) ช่วงเวลาอื่นให้หัวหน้าทีมกำหนดเป็นรายกรณี
- ถ้าได้รับมอบหมายให้ทำงานวันหยุด ต้องมาปฏิบัติงาน และได้วันหยุดพิเศษตามข้อ 2.2

### 2.2 การทำงานในวันหยุด

ทำงานวันหยุดเต็มวัน **1 วัน** → ได้วันหยุดพิเศษ (จันทร์–ศุกร์) **1 วัน**
ให้หยุดทันทีหลังปฏิบัติงานเพื่อพักผ่อน หรือตามที่หัวหน้าทีมเห็นชอบ

### 2.3 การบันทึกเวลาปฏิบัติงาน

| ข้อ | สาระสำคัญ |
| --- | --- |
| 2.3.1 | ต้องบันทึกเวลาเข้า-ออกด้วยตนเองทุกครั้ง ถ้าไม่ได้รับอนุมัติล่วงหน้าถือว่าขาดงาน และ HD จะ**หักวันลากิจเท่าจำนวนเวลาที่ขาด** |
| 2.3.2 | ออกปฏิบัติงานนอกสำนักงาน / เข้าหลัง 08.30 / ออกก่อน 17.00 ต้องแจ้งก่อน และเสนออนุมัติ**ภายใน 5 วันทำการ** มิฉะนั้นถือว่าขาดงาน |
| 2.3.3 | ให้ผู้อื่นบันทึกเวลาแทน หรือบันทึกแทนผู้อื่น = ผิดระเบียบวินัย |
| 2.3.4 | ข้อมูลเวลาใช้ประกอบการพิจารณาปรับเงินเดือน ค่าตอบแทนตามผลงาน ความดีความชอบ และโทษ |
| 2.3.5 | ปฏิบัติงานวันหยุดต้องแจ้งก่อน และบันทึกเวลาเสนอให้ลงนามรับทราบหลังปฏิบัติงาน |

### 2.4 การแต่งกาย (พนักงานและผู้บริหารสาย S)

| วัน | เสื้อ | กางเกง/กระโปรง | รองเท้า |
| --- | --- | --- | --- |
| จันทร์ และ พฤหัสบดี | เชิ้ตสีขาว | ผ้า/กระโปรงสีสุภาพ (ดำ เทา กรมท่า น้ำตาล) | คัชชูสีสุภาพ (ดำ เทา กรมท่า น้ำตาล ครีม ขาว) |
| อังคาร และ พุธ | เชิ้ตสีขาว หรือเชิ้ตสีสุภาพ | ผ้า/กระโปรงสีสุภาพ หรือยีนส์สีเข้มไม่ขาด | คัชชูสีสุภาพ |
| ศุกร์ | เชิ้ต เบลาส์ โปโลแบบสุภาพ หรือชุดเดรสสุภาพ | ยีนส์สีเข้มไม่ขาด | คัชชูสีสุภาพ **หรือรองเท้าผ้าใบ** |

| 3.1.2 | **พนักงานทดลองปฏิบัติงาน** — จ่ายเข้าบัญชีทุกวันที่ **11** ของเดือน |
| 3.1.3 | **พนักงานโครงการ พนักงานประจำ ผู้บริหารสาย S** — จ่ายเข้าบัญชีทุกวันที่ **26** ของเดือน |
| 3.1.4 | ปรับอัตราเงินเดือนพนักงานประจำและผู้บริหารสาย S **ปีละ 1 ครั้ง** |

### 3.2 เบี้ยขยัน

- ผู้มีสิทธิ์: **พนักงานโครงการ พนักงานประจำ ผู้บริหารสาย S** (ไม่รวมพนักงานทดลองปฏิบัติงาน)
- เงื่อนไข: ไม่ลา ไม่ขาด ไม่สาย (เริ่ม 08.30) ไม่ออกก่อนเวลา (17.00) และบันทึกเวลาเข้า-ออกทุกครั้ง
  ถ้าไม่มีการบันทึกต้องชี้แจงและเสนอให้หัวหน้าทีมหรือผู้บริหารอนุมัติ
- อัตรา: **1,000 บาท/รอบครึ่งเดือน** (รอบแรก 1–15, รอบหลัง 16–31) เบิกจ่ายเดือนละ 1 ครั้งพร้อมเงินเดือนรอบถัดไป
- **3.2.2** ถ้าบันทึกเวลาครบแต่หัวหน้าทีม/ผู้บริหารพบว่าไม่พร้อมปฏิบัติงานเพราะกิจส่วนตัวหรือธุระอื่นที่ไม่ได้รับมอบหมาย → ไม่ได้รับเบี้ยขยัน

### 3.11 สวัสดิการด้านการรักษาพยาบาลและสุขภาพ

| ข้อ | สาระสำคัญ |
| --- | --- |
| 3.11.1 | **ประกันอุบัติเหตุกลุ่ม** — พนักงานโครงการ และพนักงานทดลองฯ ตำแหน่งช่างเทคนิคประจำห้องปฏิบัติการ / สนับสนุนงานซ่อมบำรุง / สนับสนุนโรงงานต้นแบบเทคโนโลยี |
| 3.11.2 | **ประกันสุขภาพกลุ่ม** — พนักงานประจำ ผู้บริหาร และที่ปรึกษาอาวุโส (คุ้มครองสุขภาพ + อุบัติเหตุ + ชีวิต) |
| 3.11.3 | **วงเงินค่ารักษาพยาบาล** — พนักงานประจำ ผู้บริหาร และที่ปรึกษาอาวุโส คำนวณตามสัดส่วนระยะเวลาปฏิบัติงานในปีงบประมาณ แยกเป็น **Core Benefits** (ตนเอง บิดา มารดา คู่สมรสและบุตรตามกฎหมาย — รักษาพยาบาลและป้องกันโรค เช่น วัคซีน) และ **Flexible Benefits** (เสริมสร้างสุขภาพกายและใจของตนเอง) เบิกตามจริงตามรายการที่อุทยานฯ กำหนด |

**วงเงินเป็นบาทอยู่ในประกาศฯ เรื่องสวัสดิการด้านการรักษาพยาบาลและสุขภาพ (เอกสารแยก ยังไม่ได้ลงทะเบียนใน repo)**
กรณีนอกเหนือจากที่กำหนด ให้ผู้อำนวยการพิจารณาตามความเหมาะสมเป็นรายกรณี

ครอบคลุมพนักงานโครงการ พนักงานประจำ ผู้บริหาร ที่ปรึกษาอาวุโส บิดา มารดา คู่สมรสและบุตรตามกฎหมาย
กรณีนอกเหนือจากที่กำหนด ให้ผู้อำนวยการพิจารณาตามความเหมาะสมเป็นรายกรณี

### 3.13 สวัสดิการกรณีเดินทางไปปฏิบัติงานนอกสถานที่

**3.13.1 เบี้ยเลี้ยง** — ต้องได้รับอนุมัติจากผู้บริหารก่อนทุกครั้ง

- ในประเทศ (นอกพื้นที่จังหวัดเชียงใหม่): **300 บาท/วัน/คน** สำหรับพนักงานและผู้บริหารสาย S

| ระยะเวลาปฏิบัติงานนอกพื้นที่ | เบี้ยเลี้ยง |
| --- | --- |
| 1–6 ชั่วโมง | ไม่คิดเบี้ยเลี้ยง |
| 7–12 ชั่วโมง | ครึ่งวัน |
| 13–24 ชั่วโมง | เต็ม 1 วัน |

- **ผู้บริหารสาย L และที่ปรึกษาอาวุโส ไม่ได้รับเบี้ยเลี้ยงสำหรับงานนอกสถานที่ภายในประเทศ**
- ต่างประเทศ: อิงแนวปฏิบัติของมหาวิทยาลัย ภายใต้ดุลยพินิจของผู้อำนวยการเป็นรายกรณี
  (สาย L และที่ปรึกษาอาวุโสเบิกจากอุทยานฯ ได้ หากไม่ได้เบิกจากมหาวิทยาลัยด้วยสาเหตุใดก็ตาม)

**3.13.2 ค่าที่พัก** (กรณีเดินทางนอกพื้นที่จังหวัดเชียงใหม่และต้องพักค้างคืน)

| กรณี | เพดาน |
| --- | --- |
| พักเดี่ยว | ไม่เกิน **2,200 บาท/คืน/ห้อง** |
| พักคู่ | ไม่เกิน **2,400 บาท/คืน/ห้อง** |
| พัก 3 คน | ไม่เกิน **3,000 บาท/คืน/ห้อง** |
| ผู้บริหารและที่ปรึกษาอาวุโส | เบิกได้ตามความเหมาะสม |

ต้องมีใบเสร็จรับเงินพร้อมเอกสารยืนยันการเข้าพัก (**Folio**) ประกอบการเบิกจ่าย
กรณีพื้นที่ปฏิบัติงานไม่มีที่พักในอัตราที่กำหนด ขออนุมัติจากผู้บริหารเป็นกรณีไป โดยคำนึงถึงประสิทธิภาพของงานเป็นหลัก

**3.13.3 ค่ายานพาหนะ**

- เบิกค่าเดินทางทุกประเภทตามจ่ายจริง · กรณีเร่งด่วนหรือจำเป็นโดยสารเครื่องบินได้
- ใช้ยานพาหนะส่วนตัว ต้องขออนุมัติผ่านหัวหน้าทีมทบทวนและเสนอผู้บริหารพิจารณา คิดตามระยะทาง:
  - **รถยนต์ส่วนบุคคล 5 บาท/กิโลเมตร**
  - **รถจักรยานยนต์ส่วนบุคคล 2 บาท/กิโลเมตร**
- **ยานพาหนะส่วนบุคคลเสียหายด้วยเหตุใดก็ตาม เบิกค่าซ่อมจากอุทยานฯ ไม่ได้**

## หมวด 4 การลางานประเภทต่าง ๆ

### 4.1 การลาหยุดงาน (หลักทั่วไป)

- เกณฑ์คำนวณวันลาใช้ **ปีงบประมาณ** · ปฏิบัติงานไม่ครบ 12 เดือน คำนวณตามสัดส่วน
- ลาทุกประเภทต้องบันทึกวันลาและ**ได้รับอนุมัติจากหัวหน้าทีมและผู้บริหารก่อน**จึงหยุดได้
- ลาครึ่งวัน (เช้าหรือบ่าย) นับเป็นการลาครึ่งวันตามประเภทการลานั้น
- ขอยกเลิกวันลาที่ยังไม่ได้หยุดได้ ให้ถือว่าการลาสิ้นสุดวันที่ขอยกเลิก
- หัวหน้าทีมหรือผู้บริหาร**เรียกกลับเข้าปฏิบัติงานก่อนกำหนดได้** ถือว่าการลาสิ้นสุดในวันก่อนกลับมาปฏิบัติงาน
- กรณีฉุกเฉิน แจ้งทันทีหรือ**ก่อน 08.45 น.** ของวันนั้น แล้วบันทึกวันลาทันทีที่มาทำงานวันถัดไป

**เกณฑ์มาสายที่แปลงเป็นลากิจครึ่งวัน** (HD เป็นผู้แจ้งให้ทราบ)

| ข้อ | เงื่อนไข | ผล |
| --- | --- | --- |
| 4.1.7 | มาหลัง **08.45** แต่ไม่เกิน **09.00** ครบ **4 ครั้ง** | ลากิจครึ่งวัน |
| 4.1.8 | มาหลัง **09.00** แต่ไม่เกิน **09.30** ครบ **2 ครั้ง** | ลากิจครึ่งวัน |
| 4.1.9 | มาหลัง **09.30** หรือกลับก่อน **15.30** | ลากิจครึ่งวัน (ทันที) |

### 4.2 การลาป่วย

- **ไม่เกิน 15 วัน/ปีงบประมาณ โดยได้รับเงินเดือน** (พนักงานและผู้บริหารสาย S)
  บันทึกวันลาเพื่อขออนุมัติทันทีที่กลับมาปฏิบัติงาน
- ลาป่วย **ตั้งแต่ 3 วันขึ้นไปติดต่อกัน** ต้องแนบใบรับรองแพทย์ผู้ขึ้นทะเบียนและรับใบอนุญาตประกอบวิชาชีพเวชกรรม
  · HD หัวหน้าทีม หรือผู้บริหาร ขอใบรับรองแพทย์หรือให้ไปตรวจจากแพทย์ของทางราชการเพิ่มเติมได้
- ประสบอันตรายหรืออุบัติเหตุจากการทำงาน ให้แจ้ง HD โดยเร็วที่สุดเพื่อขอเงินทดแทนจากประกันสังคมตามสิทธิ์

### 4.3 การลากิจ

| ผู้มีสิทธิ์ | สิทธิ |
| --- | --- |
| พนักงานทดลองปฏิบัติงาน | **ไม่มีสิทธิ์ลากิจ** |
| พนักงานโครงการ / พนักงานประจำ / ผู้บริหารสาย S | **ไม่เกิน 12 วัน/ปีงบประมาณ** — ได้รับเงินเดือน **6 วัน** และไม่ได้รับเงินเดือน **6 วัน** |

ต้องขออนุมัติล่วงหน้า **อย่างน้อย 2 วันทำการ** ต่อหัวหน้าทีมและผู้บริหาร
กรณีเร่งด่วนแจ้งหัวหน้าทีมเป็นลายลักษณ์อักษรและส่งหลักฐานให้ HD

### 4.4 การลาพักผ่อนประจำปี

- **พนักงานประจำและผู้บริหารสาย S: 10 วัน/ปีงบประมาณ** · สะสมได้ **ไม่เกิน 20 วัน/ปีงบประมาณ**
- ขออนุมัติล่วงหน้า **อย่างน้อย 5 วันทำการ** ก่อนวันที่ได้รับอนุญาตให้ลา
  ลาครั้งเดียวหรือหลายครั้งก็ได้ แต่ต้องไม่เป็นผลเสียหายต่องาน

### 4.5 การลาคลอดบุตร และการลาดูแลคู่สมรสที่คลอดบุตร

| ข้อ | ผู้มีสิทธิ์ | สิทธิ |
| --- | --- | --- |
| 4.5.1 | พนักงานทดลองปฏิบัติงาน | ลาคลอดก่อน+หลัง ครรภ์หนึ่ง **ไม่เกิน 120 วัน** (นับรวมวันหยุด) และ**ขยายระยะเวลาทดลองงาน**ตามจำนวนวันที่ลา |
| 4.5.2 | พนักงานโครงการ / ประจำ / ผู้บริหารสาย S | ลาคลอด **ไม่เกิน 120 วัน** (นับรวมวันหยุด) · ลาต่อเนื่องได้อีก **ไม่เกิน 30 วัน โดยไม่ได้รับเงินเดือน** |
| 4.5.4.1 | ผู้ลาคลอด | ใช้สิทธิ์ประกันสังคมเบิกค่าคลอดบุตรและค่าสงเคราะห์การหยุดงานเพื่อการคลอดบุตร |
| 4.5.4.2 | ผู้ลาคลอด | อุทยานฯ จ่ายเงินเดือนและค่าตอบแทนอื่นเท่าเงินเดือนปัจจุบัน **ไม่เกิน 60 วัน** (นับรวมวันหยุด) |
| 4.5.5 | พนักงานทดลองปฏิบัติงาน (คู่สมรสคลอด) | **ไม่เกิน 7 วันทำการติดต่อกัน โดยไม่ได้รับเงินเดือนและค่าตอบแทนอื่น** · แจ้งล่วงหน้า **อย่างน้อย 2 สัปดาห์** · ขยายเวลาทดลองงาน |
| 4.5.6 | พนักงานโครงการ / ประจำ / สาย S (คู่สมรสคลอด) | **ไม่เกิน 15 วันทำการติดต่อกัน โดยได้รับเงินเดือนและค่าตอบแทนตามปกติ** · แจ้งล่วงหน้า **อย่างน้อย 2 สัปดาห์** |

กลับมาปฏิบัติงานแล้วต้องนำ**สำเนาสูติบัตร**มาแสดงต่อ HD เพื่อบันทึกประวัติ (ข้อ 4.5.3)
การลาดูแลคู่สมรสใช้กับ**คู่สมรสโดยชอบด้วยกฎหมาย**

### 4.6 การลาอุปสมบท / ลาไปประกอบพิธีฮัจญ์ / ลาปฏิบัติธรรม

- **พนักงานประจำและผู้บริหารสาย S** · **1 ครั้งตลอดอายุงานการเป็นพนักงานอุทยานฯ**
- ระยะเวลา **15–120 วัน** (นับรวมวันหยุด) · **ไม่ได้รับเงินเดือน**
- บันทึกวันลาเสนอหัวหน้าทีมและผู้บริหาร **ไม่น้อยกว่า 60 วันก่อนวันที่เริ่มลา**
- หลักฐานเมื่อกลับมาปฏิบัติงาน ส่งให้ HD:
  - อุปสมบท → ใบรับรองการอุปสมบทลงนามโดยเจ้าอาวาสหรือรองเจ้าอาวาส
  - ฮัจญ์ → ใบรับรองการร่วมพิธีฮัจญ์จากสำนักจุฬาราชมนตรี + boarding pass
  - ปฏิบัติธรรม → ใบรับรองการปฏิบัติธรรมจากสถานที่ปฏิบัติธรรม

### 4.7 การลาเข้ารับการตรวจเลือก หรือเข้ารับการเตรียมพล

- **ได้รับเงินเดือนหรือค่าจ้าง** และ**ขยายระยะเวลาสัญญาจ้าง**ตามระยะเวลาที่ได้รับอนุญาต
- ผู้ได้รับหมายเรียกรายงานการลาต่อผู้บริหาร หัวหน้าทีม และ HD **ไม่น้อยกว่า 2 วัน** นับแต่เวลารับหมายเรียก
  แล้วไปตามวันเวลาในหมายเรียกได้**โดยไม่ต้องรอคำสั่งอนุญาต**
- กลับมาแล้วรายงานตัวกลับเข้าปฏิบัติงานต่อผู้บังคับบัญชาภายใน **7 วัน**
  (ผู้มีอำนาจขยายเวลาได้ แต่รวมแล้ว**ไม่เกิน 15 วัน**)

## หมวด 5 ระเบียบวินัยและการลงโทษ

### 5.1 ระเบียบวินัยที่ต้องปฏิบัติตาม (14 ข้อ: 5.1.1–5.1.14)

| ข้อ | สาระสำคัญ |
| --- | --- |
| 5.1.1 | รักษาวินัยตามข้อบังคับ มช. ว่าด้วยการบริหารงานบุคคล (วินัยและการรักษาวินัย) และข้อบังคับ มช. ว่าด้วยประมวลจริยธรรมผู้บริหารและผู้ปฏิบัติงาน |
| 5.1.2 | ปฏิบัติตามประกาศฯ หลักเกณฑ์บริหารงานบุคคลและสวัสดิการพนักงานอย่างเคร่งครัด |
| 5.1.3 | ให้ความร่วมมือและปฏิบัติตามคำสั่งโดยชอบของผู้บังคับบัญชา |

| 5.1.5 | ไม่หยุดงาน ละทิ้งหน้าที่ หรือขาดงานโดยไม่ได้รับอนุญาตจากหัวหน้าทีมหรือผู้บริหาร |
| 5.1.6 | ออกจากสำนักงานไปทำธุระส่วนตัวต้องขออนุญาตทุกครั้ง มิเช่นนั้น**ถือเป็นความผิดขั้นร้ายแรง** |
| 5.1.7 | ไม่กระทำการขัดต่อระเบียบ หรือทำให้หน่วยงาน/ผู้อื่นได้รับความเสียหายหรือเดือดร้อน |
| 5.1.8 | ปฏิบัติงานโดยยึดหลักความปลอดภัยทั้งของตนเองและผู้ร่วมงาน |
| 5.1.9 | ใช้อุปกรณ์และเครื่องใช้สำนักงานด้วยความระมัดระวัง รักษาให้พร้อมใช้ และแจ้งผู้รับผิดชอบโดยเร็วเมื่อเสียหาย |
| 5.1.10 | ไม่เสพสิ่งมึนเมา และ/หรือเล่นเกมการพนันทุกชนิดระหว่างปฏิบัติหน้าที่ |
| 5.1.11 | ไม่นำยาเสพติด สิ่งผิดกฎหมาย หรืออาวุธทุกชนิดเข้ามาในบริเวณสำนักงานหรือสถานที่ปฏิบัติงาน |
| 5.1.12 | ไม่เรียกร้อง รับ หรือยอมรับผลประโยชน์จากผู้อื่นอันทำให้เสียความเที่ยงธรรมในหน้าที่ หรือใช้ตำแหน่งหน้าที่แสวงหาผลประโยชน์ส่วนตัว |
| 5.1.13 | ไม่ทุจริต ฉ้อโกง หรือแสวงหาประโยชน์โดยมิชอบ หรือแสดงเจตนาทำให้เสื่อมเสียต่อหน้าที่และหน่วยงาน |
| 5.1.14 | **รักษาข้อมูลทุกอย่างของอุทยานฯ รวมทั้งข้อมูลของลูกค้าเป็นความลับ ห้ามนำออกไปเผยแพร่โดยไม่ได้รับอนุญาตจากผู้บริหาร — ความผิดขั้นร้ายแรง** |

ผู้ไม่ปฏิบัติตามถือว่ามีความผิดทางวินัย จะถูกดำเนินการและลงโทษตามข้อ 5.2

### 5.2 การลงโทษ

อุทยานฯ พิจารณาลงโทษได้**โดยไม่ต้องเรียงลำดับก่อนหลัง**

- **โทษทางวินัย** (ผู้กระทำผิดวินัยตามข้อ 5.1): ภาคทัณฑ์ · ตัดเงินเดือน · ลดเงินเดือน · ปลดออก · ไล่ออก
- **การกระทำในลักษณะอื่นนอกเหนือข้อ 5.1 ซึ่งอาจทำให้อุทยานฯ เสียหาย:** เตือนด้วยวาจา · เตือนด้วยลายลักษณ์อักษร

## หมวด 6 การลาออก

- แจ้งให้อุทยานฯ ทราบล่วงหน้าและยื่น**ใบลาออกเป็นลายลักษณ์อักษร**
  · แจ้งหัวหน้าทีมหรือผู้บริหารด้วยวาจา แล้วแจ้งทีมพัฒนาศักยภาพบุคลากรเพื่อดำเนินการตามขั้นตอน
- **ต้องมีจำนวนวันตั้งแต่วันที่กรอกใบลาออกถึงวันที่ต้องการพ้นสภาพพนักงานอย่างน้อย 30 วัน**
- HD เสนอหัวหน้าทีมและผู้บริหารทบทวนและพิจารณาอนุมัติตามขั้นตอน เมื่อได้รับอนุมัติแล้วจึงถือว่าลาออกได้
- อ้างอิงประกาศ มช. เรื่องวิธีการลาออก การอนุญาตให้ลาออก และการยับยั้งการลาออกของพนักงานมหาวิทยาลัย

## หมวด 7 การพ้นจากการเป็นพนักงานอุทยานฯ

พนักงานและผู้บริหารสาย S พ้นสภาพเมื่อ:

1. ครบกำหนดระยะเวลาการปฏิบัติงานหรือการจ้าง
2. สิ้นสุดการเป็นพนักงานตามเงื่อนไขที่กำหนดไว้ในสัญญาจ้าง
3. ตาย
4. ต้องคำพิพากษาถึงที่สุดให้จำคุก ยกเว้นความผิดที่ได้กระทำโดยประมาท หรือความผิดลหุโทษ
5. เป็นบุคคลล้มละลาย หรือถูกศาลมีคำสั่งให้พิทักษ์ทรัพย์เด็ดขาด
6. ลาออก
7. ถูกสั่งให้ออก

กรณีอื่น ๆ นอกเหนือจากที่กำหนด ให้ผู้บริหารพิจารณาตามความเหมาะสมเป็นรายกรณี

## ข้อ 5.1.14 — ฐานภายในของกติกาข้อมูลใน repository

## Guardrails เมื่อ AI ตอบเรื่องนี้

1. **ตอบอัตราและจำนวนวันจากเอกสารนี้ได้ พร้อมอ้างเลขข้อเสมอ** — แต่ถ้าเป็นการคำนวณสิทธิของผู้ใช้รายคน
   (เหลือวันลากี่วัน เคสนี้เบิกได้เท่าไหร่) ให้ชี้ไป HD เพราะต้องใช้ข้อมูลการจ้างและประวัติการลารายบุคคล
2. แยก **"พนักงานและผู้บริหารสาย S"** ออกจาก **"ผู้บริหารสาย L"** ทุกครั้งที่สรุปสิทธิ
   และแยก **ทดลองปฏิบัติงาน / โครงการ / ประจำ** เมื่อเรื่องนั้นให้สิทธิไม่เท่ากัน
   จุดที่พลาดบ่อย: **ลากิจ** — ทดลองงานไม่มีสิทธิ์ · **เบี้ยขยัน** — ทดลองงานไม่ได้ ·
   **ลาพักผ่อน / กองทุนสำรองเลี้ยงชีพ / ลาอุปสมบท** — เฉพาะพนักงานประจำและสาย S ·
   **เบี้ยเลี้ยงในประเทศ** — สาย L และที่ปรึกษาอาวุโสไม่ได้รับ
3. ฉบับนี้บังคับใช้ **1 ตุลาคม 2569** — เหตุการณ์หรือสิทธิที่เกิดก่อนวันนั้นอยู่ภายใต้ฉบับ 2566 ให้ระบุวันที่ของเรื่องก่อนตอบ
4. ถ้าผู้ใช้อ้างเลขข้อจากเอกสารเก่า (เช่น "ข้อ 5.1.16") ให้ทักว่าเลขข้อเปลี่ยนในฉบับ 2569 ก่อนตอบต่อ
5. การประเมินผลงานรายบุคคล การพิจารณาทางวินัย และการลงโทษ เป็น human-only ตาม [`manifest/authority.yaml`](../manifest/authority.yaml) → `hr-performance-evaluation`
   AI สรุปว่าประกาศกำหนดโทษอะไรไว้ได้ แต่ไม่ชี้ว่าใครควรได้รับโทษระดับไหน
6. การผ่อนผันระเบียบเป็น `policy-waiver` ไม่ใช่สิ่งที่ AI ตีความให้ได้ — หลายข้อจบด้วย
   "ให้ผู้อำนวยการพิจารณาตามความเหมาะสมเป็นรายกรณี" ซึ่งแปลว่า **ไม่มีคำตอบตายตัว ห้าม AI เดาแทน**
7. วงเงินค่ารักษาพยาบาล (3.11.3) เงินชดเชยคอมพิวเตอร์ (3.8) ค่าโทรศัพท์รายเดือน (3.6) และอัตราเบี้ยเลี้ยงต่างประเทศ (3.13.1)
   อยู่ในประกาศฯ หรือแนวปฏิบัติแยกที่ยังไม่ลงทะเบียน — **ห้ามเดาตัวเลข** ให้บอกว่าต้องเปิดเอกสารนั้นจาก HD
8. ถ้าพบฉบับแก้ไขใหม่กว่านี้ ให้ปรับ `documents.yaml` และดัชนีนี้พร้อมกัน
