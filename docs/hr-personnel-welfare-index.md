## คำนิยามที่ใช้ทั้งฉบับ (ข้อ 4)

| คำ | ความหมายตามประกาศ |
| --- | --- |
| อุทยานฯ | อุทยานวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยเชียงใหม่ |
| ผู้บริหาร | ผู้อำนวยการ รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป |
| ผู้บริหารสาย L | ผู้อำนวยการ รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป ที่**ไม่ได้**เลื่อนขั้นมาจากพนักงาน |
| ผู้บริหารสาย S | รองผู้อำนวยการ ผู้ช่วยผู้อำนวยการ และผู้จัดการทั่วไป ที่**เลื่อนขั้นมาจากพนักงาน** |
| ที่ปรึกษาอาวุโส | บุคลากรที่อุทยานฯ ว่าจ้างให้เป็นที่ปรึกษาในการบริหารงาน |
| หัวหน้าทีม / รองหัวหน้าทีม / ผู้ช่วยหัวหน้าทีม | พนักงานประจำที่ผู้อำนวยการแต่งตั้งหรือมอบหมายตามโครงสร้างองค์กร |
| พนักงานประจำ | บุคลากรที่จ้างให้ปฏิบัติงานประจำของอุทยานฯ |
| พนักงานโครงการ | บุคลากรที่จ้างให้ปฏิบัติงาน **ไม่เกิน 1 ปี** โดยมีสิทธิ์ได้รับการประเมินเป็นพนักงานประจำ (จัดเป็นพนักงานชั่วคราวตามข้อบังคับ มช. พ.ศ. 2555) |
| พนักงานทดลองการปฏิบัติงาน | บุคลากรที่จ้างให้ทดลองปฏิบัติงานให้อุทยานฯ |
| พนักงาน | พนักงานประจำ + พนักงานโครงการ + พนักงานทดลองปฏิบัติงาน |
| ปีงบประมาณ | 1 ตุลาคม ของปีปัจจุบัน – 30 กันยายน ของปีถัดไป |

ข้อสังเกตสำหรับ AI:

1. สิทธิและเงื่อนไขหลายข้อใช้คำว่า **"พนักงานและผู้บริหารสาย S"** ซึ่ง**ไม่รวมผู้บริหารสาย L**
2. ฉบับนี้แยก **พนักงานทดลองปฏิบัติงาน / พนักงานโครงการ / พนักงานประจำ** ออกจากกันในหลายสิทธิ
   (เช่น การลากิจ การลาพักผ่อน รอบจ่ายเงินเดือน) — สถานะการจ้างเปลี่ยนคำตอบ
3. ถ้าผู้ใช้ไม่ระบุสถานะการจ้าง **ให้ถามก่อน อย่าสรุปสิทธิแทน**

## ดัชนีหัวข้อ

### หมวด 1 ระเบียบการจ้างงาน

เกณฑ์การคัดเลือก · เส้นทางการจ้าง **ทดลองปฏิบัติงาน → พนักงานโครงการ → พนักงานประจำ** โดยแต่ละช่วงผูกกับผลการประเมิน ·
รอบสัญญาจ้างพนักงานประจำ · การนับอายุงาน (เริ่มจากวันเริ่มเป็นพนักงานทดลองปฏิบัติงาน) ·
หน้าที่แจ้งเปลี่ยนแปลงข้อมูลทะเบียนประวัติเป็นลายลักษณ์อักษรภายในกรอบเวลาที่กำหนด

| 4.7 | **การลาเข้ารับการตรวจเลือก หรือเข้ารับการเตรียมพล** — การขยายสัญญาจ้าง, การรายงานตัวกลับ |

### หมวด 5 ระเบียบวินัยและการลงโทษ

- **5.1 ระเบียบวินัยที่ต้องปฏิบัติตาม (14 ข้อ: 5.1.1–5.1.14)**
  ครอบคลุมการรักษาวินัยตามข้อบังคับ มช. และประมวลจริยธรรม · การปฏิบัติตามคำสั่งโดยชอบ ·
  การบันทึกเวลาด้วยตนเองผ่านระบบที่หน่วยงานกำหนด (เช่น สแกนใบหน้า/ลายนิ้วมือ) และห้ามบันทึกแทนกัน ·
  การไม่ละทิ้งหน้าที่ · การขออนุญาตออกนอกสำนักงาน · ความปลอดภัย · การดูแลอุปกรณ์ ·
  ข้อห้ามเรื่องสิ่งมึนเมา การพนัน ยาเสพติดและอาวุธ · การไม่เรียกรับผลประโยชน์ · การไม่ทุจริต ·
  และ **5.1.14 การรักษาความลับข้อมูลของอุทยานฯ และลูกค้า**
- **5.2 การลงโทษ** — อุทยานฯ พิจารณาลงโทษได้โดยไม่ต้องเรียงลำดับก่อนหลัง
  - **โทษทางวินัย:** ภาคทัณฑ์ · ตัดเงินเดือน · ลดเงินเดือน · ปลดออก · ไล่ออก
  - **การกระทำนอกเหนือข้อ 5.1 ที่อาจทำให้อุทยานฯ เสียหาย:** เตือนด้วยวาจา · เตือนด้วยลายลักษณ์อักษร

### หมวด 6 การลาออก

ต้องแจ้งล่วงหน้าและยื่นใบลาออกเป็นลายลักษณ์อักษร · แจ้งหัวหน้าทีมหรือผู้บริหารด้วยวาจา แล้วแจ้งทีมพัฒนาศักยภาพบุคลากร ·
มีกรอบจำนวนวันขั้นต่ำระหว่างวันที่ยื่นกับวันที่ต้องการพ้นสภาพ · ผ่านการทบทวนและอนุมัติตามขั้นตอน ·
อ้างอิงประกาศ มช. เรื่องวิธีการลาออก การอนุญาตให้ลาออก และการยับยั้งการลาออกของพนักงานมหาวิทยาลัย

### หมวด 7 การพ้นจากการเป็นพนักงานอุทยานฯ

เงื่อนไขการพ้นสภาพของพนักงานและผู้บริหารสาย S: ครบกำหนดระยะเวลาการปฏิบัติงานหรือการจ้าง ·
สิ้นสุดตามเงื่อนไขในสัญญาจ้าง · ตาย · ต้องคำพิพากษาถึงที่สุดให้จำคุก (ยกเว้นความผิดที่กระทำโดยประมาทหรือลหุโทษ) ·
เป็นบุคคลล้มละลายหรือถูกศาลสั่งพิทักษ์ทรัพย์เด็ดขาด · ลาออก · ถูกสั่งให้ออก
กรณีอื่นให้ผู้บริหารพิจารณาตามความเหมาะสมเป็นรายกรณี

## สิ่งที่เปลี่ยนจากฉบับ พ.ศ. 2566

สรุประดับโครงสร้างและหัวข้อ เพื่อให้ผู้ดูแลรู้ว่าต้องไล่แก้อะไรต่อ
**ไม่ใช่การเทียบข้อความเต็มของทั้งสองฉบับ** — การตีความผลทางสิทธิต้องเปิดฉบับจริงทั้งสองฉบับประกอบ

| เรื่อง | ฉบับ 2566 | ฉบับ 2569 |
| --- | --- | --- |
| จำนวนหมวด | 5 หมวด | **7 หมวด** (เพิ่มหมวด 6 การลาออก และหมวด 7 การพ้นสภาพ) |
| ประเภทการลา | 4.1–4.6 | **4.1–4.8** (เพิ่มลาตรวจเลือก/เตรียมพล และลากิจพิเศษ) |
| ข้อ 4.6 | ลาอุปสมบท / ฮัจญ์ | เพิ่ม **ลาปฏิบัติธรรม** |
| Career Path | เอกสารแนบท้ายของประกาศหลัก | **แยกเป็นประกาศเอกเทศ** |
| สถานะการจ้าง | พนักงานประจำ / พนักงานโครงการ | เพิ่ม **พนักงานทดลองการปฏิบัติงาน** และนิยาม "พนักงาน" ให้ครอบคลุมทั้งสามสถานะ |
| นิยามพนักงานโครงการ | จ้างตามโครงการ/เฉพาะกิจ | จ้าง **ไม่เกิน 1 ปี** มีสิทธิ์ได้รับการประเมินเป็นพนักงานประจำ |
| ข้อวินัย | 5.1.1–5.1.16 (16 ข้อ) | **5.1.1–5.1.14 (14 ข้อ)** |
| ข้อรักษาความลับ | 5.1.16 | **5.1.14** |
| การลงโทษ | 3 ขั้นเรียงจากเตือนวาจา → ลายลักษณ์อักษร → ตัดเงินเดือน/เลิกจ้าง | แยกเป็น **โทษทางวินัย 5 ระดับ** (ภาคทัณฑ์ · ตัดเงินเดือน · ลดเงินเดือน · ปลดออก · ไล่ออก) และ **การเตือน 2 ระดับ** สำหรับการกระทำนอกเหนือข้อ 5.1 |
| ฐานอำนาจ | ข้อ 18 + มติ 2/2565 (6 ธ.ค. 2565) | **ข้อ 18, 30, 32** + มติ **1/2569 (21 พ.ค. 2569)** |

## Guardrails เมื่อ AI ตอบเรื่องนี้

1. ใช้ดัชนีนี้เพื่อชี้ว่าเรื่องอยู่หมวดใดข้อใด แล้วให้ผู้ใช้เปิดฉบับจริงยืนยัน — **ห้ามตอบตัวเลขวันลา เงินเดือน วงเงินสวัสดิการ หรือกรอบเวลาขออนุมัติจากความจำ**
2. การประเมินผลงานรายบุคคล การพิจารณาทางวินัย และการลงโทษ เป็น human-only ตาม [`manifest/authority.yaml`](../manifest/authority.yaml) → `hr-performance-evaluation`
3. การผ่อนผันระเบียบเป็น `policy-waiver` ไม่ใช่สิ่งที่ AI ตีความให้ได้
4. แยก **"พนักงานและผู้บริหารสาย S"** ออกจาก **"ผู้บริหารสาย L"** ทุกครั้งที่สรุปสิทธิ และแยก **ทดลองปฏิบัติงาน / โครงการ / ประจำ** เมื่อเรื่องนั้นให้สิทธิไม่เท่ากัน
5. ฉบับนี้บังคับใช้ **1 ตุลาคม 2569** — เหตุการณ์หรือสิทธิที่เกิดก่อนวันนั้นอยู่ภายใต้ฉบับ 2566 ให้ระบุวันที่ของเรื่องก่อนตอบ
6. ถ้าผู้ใช้อ้างเลขข้อจากเอกสารเก่า (เช่น "ข้อ 5.1.16") ให้ทักว่าเลขข้อเปลี่ยนในฉบับ 2569 ก่อนตอบต่อ
7. ถ้าพบฉบับแก้ไขใหม่กว่านี้ ให้ปรับ `documents.yaml` และดัชนีนี้พร้อมกัน
