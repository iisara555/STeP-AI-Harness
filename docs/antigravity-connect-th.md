# เชื่อม Gemini ผ่าน Antigravity ใน STeP Desktop (คู่มือพนักงาน)

ใช้ได้ทั้ง Windows และ Mac ไม่ต้องติดตั้งโปรแกรมเอง ไม่ต้องใช้ API key และไม่ต้องมีสิทธิ์ผู้ดูแลเครื่อง (admin) เพราะ STeP ติดตั้ง Antigravity CLI ของ Google ไว้ในโฟลเดอร์ข้อมูลของแอปเอง

## ขั้นตอน (ทำครั้งเดียว)

1. เปิด STeP Desktop แล้วไปที่ **ตั้งค่าพื้นที่ทำงาน → การเชื่อมต่อ AI**
2. เลือก **Gemini via Antigravity** แล้วกดปุ่ม **เชื่อมต่อ Antigravity**
3. ครั้งแรก STeP จะดาวน์โหลด Antigravity CLI ของ Google (Windows ประมาณ 190 MB) รอให้แถบสถานะขึ้นว่าติดตั้งเรียบร้อย
4. **เบราว์เซอร์จะเปิดหน้าลงชื่อ Google เอง** เลือกบัญชี แล้วกด **อนุญาต (Allow)**
5. หน้าเว็บ Antigravity จะแสดง **รหัส (authorization code)** ให้กดคัดลอก แล้วกลับมาวางในช่อง **รหัสจากหน้าเว็บ** ที่ STeP เปิดรอไว้ กด **ยืนยัน** (ทำข้อ 4–5 ให้เสร็จภายใน 1 นาที ถ้าไม่ทัน STeP จะเปิดหน้าลงชื่อให้ใหม่)
6. รอจนขึ้นว่า **ผ่านการเชื่อมต่อและรับคำตอบบนเครื่องนี้แล้ว** เป็นอันเสร็จ

บน Windows ช่องวางรหัสใน STeP ยังใช้ไม่ได้ STeP จะเปิดหน้าต่างลงชื่อ (หน้าต่างสีดำ) แทน ดูหัวข้อถัดไป

## ถ้ามีหน้าต่างสีดำ (หน้าต่างคำสั่ง) เปิดขึ้นมาแทน

บน Windows หรือเมื่อลงชื่อผ่านเบราว์เซอร์ไม่สำเร็จ 3 ครั้ง STeP จะเปิดหน้าต่างลงชื่อของ Antigravity ให้แทน

1. ในหน้าต่างนั้นจะมีคำว่า *Select login method* และ *1. Google OAuth* ถูกเลือกไว้แล้ว ให้ **กด Enter หนึ่งครั้ง**
2. เบราว์เซอร์จะเปิดหน้าลงชื่อ Google ให้เลือกบัญชี แล้วกดอนุญาต
3. หน้าเว็บจะแสดงรหัส ให้กดคัดลอก กลับมาที่หน้าต่างสีดำ แล้ววางรหัส (Windows: คลิกขวา หรือ Ctrl+V / Mac: Command+V) แล้วกด **Enter**
4. บน Windows หน้าต่างจะปิดเอง บน Mac ปิดหน้าต่าง Terminal ได้เลยหลัง STeP ขึ้นว่าเชื่อมต่อแล้ว

## ปัญหาที่พบบ่อย

| อาการ | ทำอย่างไร |
|---|---|
| ขึ้นว่าดาวน์โหลด Antigravity CLI ไม่สำเร็จ | ตรวจอินเทอร์เน็ต ถ้าใช้เครือข่ายองค์กรที่บล็อก `storage.googleapis.com` ให้ลองเครือข่ายอื่น แล้วกดเชื่อมต่อใหม่ |
| ลงชื่อแล้ว STeP ยังรออยู่นาน | ตรวจว่าวางรหัสจากหน้าเว็บแล้ว ถ้ายังค้าง กดยกเลิก แล้วกดเชื่อมต่อใหม่ ระบบจะตรวจว่าลงชื่อแล้วและข้ามไปทดสอบเลย |
| หน้าเว็บขึ้นรหัส แต่ไม่มีที่ให้วาง | ใช้ STeP 0.5.17 ขึ้นไป (0.5.16 ไม่มีช่องวางรหัส) หรือรอให้ STeP เปิดหน้าต่างสีดำแล้ววางรหัสในนั้น |
| Google ไม่ให้ใช้บัญชีที่เลือก | บัญชีองค์กรบางแห่งอาจยังไม่เปิดให้ใช้ Antigravity ลองบัญชี Gmail ส่วนตัว แล้วแจ้งผู้ดูแล STeP |
| Mac เปิด STeP Desktop ไม่ได้ในครั้งแรก หรือมีปุ่ม Move to Trash | อย่ากด Move to Trash เปิดไฟล์ **อ่านก่อนเปิดครั้งแรก.html** ในหน้าต่าง DMG แล้วทำตาม (หรือดู README หัวข้อ macOS) |

การกด **เลิกเชื่อมต่อ** ใน STeP ไม่ได้ออกจากบัญชี Google ใน Antigravity บัญชียังลงชื่ออยู่บนเครื่องนั้น
