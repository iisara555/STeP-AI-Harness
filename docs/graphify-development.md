# Graphify developer workflow

The project-local Codex skill is installed under `.codex/skills/graphify/`. The verified local CLI is the official `graphifyy` package, version 0.9.23. Use the existing installation; do not install similarly named packages.

Run from the repository root:

```sh
node scripts/graphify-local.js build
node scripts/graphify-local.js query "queryStepRouter evaluateActionGate"
node scripts/graphify-local.js explain "getNextOutputPath"
node scripts/graphify-local.js affected "queryStepRouter"
```

The wrapper disables query logging and only builds code ASTs. It never enables semantic extraction or an LLM backend. Full code rebuilds avoid stale/deleted nodes observed with the installed version's incremental raw-extraction path. Clustering disables model-generated labels.

`.graphifyignore` allows first-party code only. Employee data, registries, documents, rules, skills, dependencies and vendored parsers are excluded. Output is ignored by Git. Graphify is not part of employee startup, runtime or installation. No Git hooks or watchers are enabled.
