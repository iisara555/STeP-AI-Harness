# ความรู้ขององค์กร STeP

โฟลเดอร์นี้เก็บเฉพาะ **ความรู้ขององค์กร** ที่ AI ใช้ตอบคำถามเรื่อง STeP เช่น ระเบียบ สวัสดิการ วันลา ทีม ผู้บริหาร เอกสาร ISO และแนวปฏิบัติงาน AFP เมื่อพนักงานถามเรื่องเหล่านี้ STeP Desktop และ STeP Skills จะค้นจากเอกสารชุดนี้ก่อนเสมอ ไม่ตอบแบบทั่วไป

เอกสารวิธีพัฒนา harness, คู่มือผู้ใช้ และผลทดสอบอยู่นอกโฟลเดอร์นี้ ดู [แผนที่เอกสาร](../README.md)

## กติกาของโฟลเดอร์นี้

- เก็บเฉพาะข้อมูลที่เผยแพร่ได้ หรือดัชนีและสาระสำคัญที่เจ้าของเอกสารอนุญาต repository นี้เป็น public ห้ามใส่ข้อมูลส่วนบุคคล เบอร์โทร หรือเอกสารภายในฉบับเต็ม ดู [Knowledge Policy](../knowledge-policy.md) และ [Repository Data Boundary](../repository-data-boundary.md)
- ทุกเอกสารต้องลงทะเบียนใน [`manifest/documents.yaml`](../../manifest/documents.yaml) ระบุเจ้าของ แหล่งที่มา และวันที่ตรวจล่าสุด AI ค้นและอ้างอิงจากทะเบียนนั้น
- เอกสารใหม่ให้วางในโฟลเดอร์นี้ แล้วเพิ่ม path ในทะเบียน ใน `package.json` (`files`) และใน `src/modules/role-resolver.js` ถ้าต้องติดตั้งไปกับชุด Skills จากนั้นรัน `npm run validate` และ `node scripts/build-claude-plugin.mjs`
- เมื่อข้อมูลเปลี่ยน ให้แก้ที่นี่ที่เดียว ห้ามคัดลอกเนื้อหาไปไว้ใน Skill
