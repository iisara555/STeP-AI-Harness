## 1. วัตถุประสงค์

เพื่อใช้เป็นกระบวนการปฏิบัติงานเกี่ยวกับการยืมเงิน เคลียร์เงินยืมโครงการ/กิจกรรม และการสำรองเงินจ่ายล่วงหน้าของพนักงานอุทยานวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยเชียงใหม่

## 2. ขอบเขต

กระบวนการปฏิบัติงานนี้คลอบคลุมตั้งแต่กระบวนการยืมเงิน เคลียร์เงินยืมโครงการ/กิจกรรม และการสำรองเงินจ่ายล่วงหน้าทุกประเภท และรวบรวมเอกสารทางการเงินที่ได้รับอนุมัติจากผู้บังคับบัญชาสูงสุดของหน่วยงาน

## 4. ขั้นตอนและวิธีปฏิบัติ

เอกสารหลักฐานต่างๆที่นำส่งให้กับงานการเงิน จะต้องเป็นเอกสารฉบับจริงเท่านั้น

- การยืมเงินโครงการ
- การเคลียร์เงินยืมโครงการ
  - กรณีที่ 1 เบิกเงินเพิ่ม
  - กรณีที่ 2 มีเงินเหลือคืน
  - กรณีที่ 3 ใช้เงินเท่ากับเงินยืม
- การสำรองเงินจ่ายล่วงหน้า
  - a. ขออนุมัติสำรองเงินจ่ายล่วงหน้า
  - b. ขอเบิกสำรองเงินจ่ายล่วงหน้า

### 4.1 การยืมเงินโครงการ (สัญญายืมเงิน FM-AF-001)

1. พนักงานที่มีความประสงค์จะยืมเงินโครงการ จะต้องจัดเตรียมเอกสาร ดังนี้
   - 1.1 ใบขออนุมัติจัดโครงการและเดินทางไปปฏิบัติงาน (FM-AF-002)
   - 1.2 ข้อเสนอโครงการ การวางแผนการดำเนินงาน (FM-AF-003)
   - 1.3 สัญญายืมเงิน (FM-AF-001)

   เมื่อกรอกเอกสารเรียบร้อยแล้ว ให้พนักงานเสนอเอกสารให้ผู้มีอำนาจลงนามอนุมัติ พร้อมทั้งส่งเอกสารและลง Log Book ให้กับงานการเงิน
2. เมื่อพนักงานการเงินได้รับเรื่องเรียบร้อยแล้ว จะดำเนินการดังนี้
   - 2.1 ตรวจสอบความถูกต้องของเอกสารและเนื้อหาทั้งหมด รวมถึงสถานะการยืม-คืนเงินของพนักงาน หากสัญญายืมเงินฉบับก่อนหน้าครบกำหนดการใช้คืนแล้ว แต่พนักงานยังไม่ได้คืน พนักงานการเงินจะแจ้งให้คืนเงินให้เรียบร้อยก่อน จึงจะสามารถยืมเงินได้
   - 2.2 กรอกข้อมูลเงินยืม ใน Share Sheet "สัญญายืมเงินและขออนุมัติ-เบิกเงินสำรองจ่าย" ในส่วนของสำหรับผู้ยืมเงิน และบันทึกบัญชีในระบบบัญชี 3 มิติของมหาวิทยาลัยเชียงใหม่ โดยทำการบันทึกตั้งหนี้-ตัดจ่ายค่าใช้จ่ายให้ครบถ้วนถูกต้อง
   - 2.3 กรณีพนักงานระบุเงื่อนไขการรับเงินในสัญญายืมเงินโครงการ (เงินโอน/เงินสด) พนักงานการเงินจะดำเนินการดังนี้

     **ประสงค์รับเป็นเงินโอน**
     - จัดทำใบสำคัญจ่าย (Payment Voucher) และจัดทำ text file การโอนเงิน พร้อมทั้งตรวจสอบความถูกต้อง
     - Upload text file การโอนเงินเข้าในระบบ Internet banking และจัดทำรายงานสถานะการทำธุรกรรม (Transaction Status Report)
     - เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมอนุมัติข้อมูลที่ Upload ในระบบ
     - เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ ให้พิมพ์รายงานการโอนเงินแนบกับชุดเอกสารพร้อมส่งต่อให้งานบัญชี
     - แจ้งสถานะการจ่ายเงินให้กับพนักงานรับทราบทาง e-mail

     **ประสงค์รับเป็นเงินสด**
     - จัดทำใบสำคัญจ่าย (Payment Voucher) เช็ค (Cheque) และใบเสนอเช็ค พร้อมทั้งตรวจสอบความถูกต้อง
     - เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมลงนามอนุมัติการจ่ายเช็ค
     - เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ จะนำเช็ค (Cheque) ต้นฉบับไปขึ้นเงิน และแจ้งให้พนักงานมารับเงินสดพร้อมลงนามในใบสำคัญจ่าย (Payment Voucher)
     - ส่งต่อเอกสารให้งานบัญชี

### 4.2 การเคลียร์เงินยืมโครงการ ข้อ a. ระบบตรวจสอบใบเสร็จรับเงินใน MIS STeP

**a. ระบบตรวจสอบใบเสร็จรับเงิน**

เมื่อพนักงานได้จ่ายเงินให้กับผู้ขาย/ผู้ให้บริการเรียบร้อยแล้ว จะต้องสแกน/ถ่ายรูปใบเสร็จรับเงินพร้อมเอกสารที่เกี่ยวข้อง (ใบสำคัญรับเงิน (FM-AF-014), ใบรับรองแทนใบเสร็จ/ใบรับรองการจ่ายเงิน (FM-AF-035, FM-AF-036), ใบเซ็นชื่อเข้าร่วมอบรม กิจกรรม ประชุม (FM-AF-015), ใบรายชื่อเข้าร่วมเลี้ยงรับรอง (FM-AF-019), บันทึกข้อความ (ถ้ามี), เอกสารที่เกี่ยวข้องอื่น ๆ) เข้าสู่ระบบการตรวจสอบใบเสร็จรับเงิน ที่ MIS STeP ทุกครั้งที่ได้รับใบเสร็จรับเงิน เพื่อให้พนักงานการเงินตรวจสอบความถูกต้อง

หากไม่ถูกต้อง พนักงานการเงินจะกดในระบบว่า ไม่อนุมัติ และจะเขียนคอมเมนท์ถึงข้อผิดพลาดและวิธีการแก้ไข ซึ่งระบบตรวจสอบใบเสร็จรับเงินจะมีการแจ้งเตือนไปยัง E-mail ของพนักงานโดยตรง หากถูกต้อง พนักงานการเงินจะกดในระบบว่า อนุมัติ ซึ่งระบบตรวจสอบใบเสร็จรับเงินจะมีการแจ้งเตือนไปยัง E-mail ของพนักงาน ให้พนักงานที่จะถึงกำหนดการชดใช้เงินยืม/ต้องการเคลียร์เงินยืม ดำเนินการดังนี้

1. รวบรวมเอกสารทั้งหมดฉบับจริงที่ผ่านการตรวจสอบในระบบเรียบร้อยแล้ว
2. จัดทำใบขอเบิกค่าใช้จ่ายการจัดโครงการและเดินทางไปปฏิบัติงาน (FM-AF-002)
3. แนบเอกสารตาม ข้อ 4.1 การยืมเงินโครงการ ข้อ 1.

เมื่อพนักงานได้รับการกดอนุมัติในระบบเรียบร้อยแล้ว ให้เสนอเอกสารทั้งหมดต่อผู้มีอำนาจลงนาม จากนั้นให้ส่งเอกสารและลง Log Book ให้กับงานการเงิน

### 4.2 การเคลียร์เงินยืมโครงการ ข้อ b. ตรวจสอบเอกสาร 3 กรณี (เบิกเพิ่ม เงินเหลือคืน ใช้เท่ากับเงินยืม)

**b. ตรวจสอบเอกสารการเคลียร์เงินยืม**

เมื่อพนักงานการเงินได้รับเรื่องเรียบร้อยแล้ว จะตรวจสอบความถูกต้องของเอกสารและเนื้อหาทั้งหมด ก่อนจะแยกประเภทการเคลียร์เงินยืม โดยแบ่งประเภทของการเคลียร์เงินยืม เป็น 3 กรณี ดังนี้

**กรณีที่ 1 เบิกเงินเพิ่ม** คือ เอกสารที่นำมาเคลียร์เงินยืมมียอดค่าใช้จ่ายจริงที่สามารถเบิกได้มากกว่าเงินยืม พนักงานการเงินจะดำเนินการ ดังนี้

ประสงค์รับเป็นเงินโอน
- จัดทำใบสำคัญจ่าย (Payment Voucher) และจัดทำ text file การโอนเงิน พร้อมทั้งตรวจสอบความถูกต้อง
- Upload text file การโอนเงินเข้าในระบบ Internet banking และจัดทำรายงานสถานะการทำธุรกรรม (Transaction Status Report)
- เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมอนุมัติข้อมูลที่ Upload ในระบบ
- เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ ให้พิมพ์รายงานการโอนเงินแนบกับชุดเอกสารพร้อมส่งต่อให้งานบัญชี
- แจ้งสถานะการจ่ายเงินให้กับพนักงานรับทราบทาง e-mail

ประสงค์รับเป็นเงินสด
- จัดทำใบสำคัญจ่าย (Payment Voucher) เช็ค (Cheque) และใบเสนอเช็ค พร้อมทั้งตรวจสอบความถูกต้อง
- เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมลงนามอนุมัติการจ่ายเช็ค
- เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ จะนำเช็ค (Cheque) ไปขึ้นเงิน และแจ้งให้พนักงานมารับเงินสดพร้อมลงนามในใบสำคัญจ่าย (Payment Voucher)
- ส่งต่อเอกสารให้งานบัญชี

**กรณีที่ 2 มีเงินเหลือคืน** คือ เอกสารที่นำมาเคลียร์เงินยืมมียอดค่าใช้จ่ายที่สามารถเบิกได้น้อยกว่าเงินยืม พนักงานการเงินจะดำเนินการ ดังนี้

1. ตรวจสอบความถูกต้องของเอกสารอีกครั้ง เพื่อกระทบยอดเงินที่จะต้องเรียกเงินคืนจากพนักงาน
2. แจ้งพนักงานเพื่อให้โอนเงินที่เหลือคืนเข้ายังบัญชีเงินฝากธนาคารของอุทยานฯ
3. จัดทำใบสำคัญทั่วไป (Journal Voucher) และออกใบเสร็จรับเงินให้กับพนักงานตามยอดเงินที่โอน
4. เสนอเอกสารให้ผู้มีอำนาจลงนาม
5. ส่งต่อเอกสารให้งานบัญชี

**กรณีที่ 3 ใช้เงินเท่ากับเงินยืม** คือ เอกสารที่นำมาเคลียร์เงินยืมมียอดค่าใช้จ่ายที่สามารถเบิกได้เท่ากับเงินยืม พนักงานการเงินจะดำเนินการ ดังนี้

1. ตรวจสอบความถูกต้องของเอกสารอีกครั้ง เพื่อกระทบยอดเงิน
2. จัดทำใบสำคัญทั่วไป (Journal Voucher)
3. เสนอเอกสารให้ผู้มีอำนาจลงนาม
4. ส่งต่อเอกสารให้งานบัญชี

### 4.3 การสำรองเงินจ่ายล่วงหน้า (ขออนุมัติและขอเบิกสำรองเงินจ่าย)

**a. ขออนุมัติสำรองเงินจ่ายล่วงหน้า**

1. พนักงานที่มีความประสงค์จะสำรองเงินจ่ายล่วงหน้า จะต้องจัดเตรียมเอกสาร ดังนี้
   - 1.1 ใบขอเบิกค่าใช้จ่ายการจัดโครงการและเดินทางไปปฏิบัติงาน (FM-AF-002)
   - 1.2 ข้อเสนอโครงการ การวางแผนการดำเนินงาน (FM-AF-003)
   - 1.3 เมื่อกรอกเอกสารเรียบร้อยแล้ว ให้พนักงานเสนอเอกสารให้ผู้มีอำนาจลงนาม พร้อมทั้งส่งเอกสารและลง Log Book ให้กับงานการเงิน
2. เมื่อพนักงานการเงินได้รับเรื่องเรียบร้อยแล้ว จะดำเนินการดังนี้
   - 2.1 ตรวจสอบความถูกต้องของเอกสารและเนื้อหาทั้งหมด
   - 2.2 กรอกข้อมูลสำรองเงินจ่ายล่วงหน้า ใน Share Sheet "สัญญายืมเงินและขออนุมัติ-เบิกเงินสำรองจ่าย" ในส่วนของเบิกสำรองเงินจ่าย
   - 2.3 เสนอเอกสารให้ผู้มีอำนาจลงนาม
   - 2.4 แจ้งพนักงานให้มารับเอกสารคืน

**b. ขอเบิกสำรองเงินจ่ายล่วงหน้า**

1. ดำเนินการตามข้อ 4.2 การเคลียร์เงินยืมโครงการ a. ระบบตรวจสอบใบเสร็จรับเงิน แต่ไม่ต้องแนบเอกสารตามข้อ 4.1 การยืมเงินโครงการ ข้อ 1.
2. แนบเอกสารตามข้อ 4.3 การสำรองเงินจ่ายล่วงหน้า a. ขออนุมัติสำรองเงินจ่ายล่วงหน้า ข้อ 1.
3. กรณีที่พนักงานมีความประสงค์ให้ดำเนินการเกี่ยวกับเงินโอน/เงินสด ที่จะได้รับ พนักงานการเงินจะดำเนินการ ดังนี้

   **ประสงค์รับเป็นเงินโอน**
   - จัดทำใบสำคัญจ่าย (Payment Voucher) และจัดทำ text file การโอนเงิน พร้อมทั้งตรวจสอบความถูกต้อง
   - Upload text file การโอนเงินเข้าในระบบ Internet banking และจัดทำรายงานสถานะการทำธุรกรรม (Transaction Status Report)
   - เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมอนุมัติข้อมูลที่ Upload ในระบบ
   - เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ ให้พิมพ์รายงานการโอนเงินแนบกับชุดเอกสารพร้อมส่งต่อให้งานบัญชี
   - แจ้งสถานะการจ่ายเงินให้กับพนักงานรับทราบทาง e-mail

   **ประสงค์รับเป็นเงินสด**
   - จัดทำใบสำคัญจ่าย (Payment Voucher) เช็ค (Cheque) และใบเสนอเช็ค พร้อมทั้งตรวจสอบความถูกต้อง
   - เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมลงนามอนุมัติการจ่ายเช็ค
   - เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ จะนำเช็ค (Cheque) ไปขึ้นเงิน และแจ้งให้พนักงานมารับเงินสดพร้อมลงนามในใบสำคัญจ่าย (Payment Voucher)
   - ส่งต่อเอกสารให้งานบัญชี
