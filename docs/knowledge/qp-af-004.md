## 1. วัตถุประสงค์

เพื่อใช้เป็นกระบวนการปฏิบัติงานเกี่ยวกับการจ่ายเงินของอุทยานวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยเชียงใหม่

## 2. ขอบเขต

กระบวนการปฏิบัติงานนี้คลอบคลุมกระบวนการจ่ายเงิน (สวัสดิการค่ารักษาพยาบาล ค่ายานพาหนะส่วนตัว บุคคลธรรมดา นิติบุคคล เงินอุดหนุนโครงการ เงินอุดหนุนมหาวิทยาลัยเครือข่าย เงินการกุศล ค่าสาธารณูปโภค และการขอคืนเงินประกันสัญญา)

## 4. ขั้นตอนและวิธีปฏิบัติ

ในการทำเรื่องขอเบิกจ่าย เอกสารหลักฐานต่างๆที่นำส่งให้กับงานการเงิน จะต้องเป็นเอกสารฉบับจริงเท่านั้น

(ถอดจากตารางในต้นฉบับ: ตารางมี 3 คอลัมน์ คือ การเบิกจ่าย | วิธีปฏิบัติของพนักงาน | วิธีปฏิบัติของพนักงานการเงิน โดยช่องพนักงานการเงินเป็นช่องเดียวที่ใช้ร่วมกับการเบิกจ่ายทุกประเภท 1–7 จึงแยกไว้ในหัวข้อสุดท้ายของข้อ 4)

### 4.1–4.3 วิธีปฏิบัติของพนักงานเมื่อส่งเบิก: สวัสดิการ ยานพาหนะส่วนตัว และจ่ายบุคคลธรรมดา/นิติบุคคล

**1. สวัสดิการค่ารักษาพยาบาล**

1. พนักงานประจำ ผู้บริหาร และที่ปรึกษาอาวุโส กรอกข้อมูลและแนบใบเสร็จรับเงิน ใบรับรองแพทย์ หรือหลักฐานอื่น ๆ ที่เกี่ยวข้องผ่านระบบ HD e-System STeP เพื่อให้พนักงานการเงินตรวจสอบ
2. เมื่อได้รับอนุมัติในระบบแล้ว ให้พิมพ์ใบเบิกเงินสวัสดิการเกี่ยวกับการรักษาพยาบาลออกจากระบบ
3. นำส่งเอกสารและลง Log Book ให้กับงานการเงิน
4. กรณีใบเสร็จรับเงินไม่ครบองค์ประกอบ : จัดทำใบรับรองแทนใบเสร็จ/ใบรับรองการจ่ายเงิน (สำหรับพนักงาน) (FM-AF-035), จัดทำใบรับรองแทนใบเสร็จ/ใบรับรองการจ่ายเงิน (สำหรับผู้บริหาร) (FM-AF-036)

**2. ค่ายานพาหนะส่วนตัว**

พนักงานกรอกข้อมูลและแนบเอกสารที่เกี่ยวข้อง ดังนี้
- ใบขออนุมัติและใบเบิกการใช้ยานพาหนะส่วนตัว (FM-AF-005)
- รายงานการใช้ยานพาหนะส่วนตัว (FM-AF-006)

จากนั้นเสนอเอกสารให้ผู้มีอำนาจลงนาม เมื่อลงนามเรียบร้อยแล้ว ให้นำส่งเอกสารและลง Log Book ให้กับงานการเงิน

**3. บุคคลธรรมดา/ นิติบุคคล**

เมื่อสิ้นสุดการดำเนินการจัดซื้อจัดจ้าง (QP-AF-001) พนักงานพัสดุนำส่งเอกสารและลง Log Book ให้กับงานการเงิน

### 4.5–4.7 วิธีปฏิบัติของพนักงาน: เงินการกุศล ค่าสาธารณูปโภค เงินประกันสัญญา (ขอคืนเงินประกัน FM-AF-009)

**5. เงินการกุศล**

พนักงานจัดเตรียมเอกสารที่เกี่ยวข้อง ดังนี้
- บันทึกข้อความ/หนังสือจากคณะ หน่วยงานภายในหรือภายนอกมหาวิทยาลัยที่เชิญร่วมทำบุญ
- หลักฐานการอนุมัติจากผู้อำนวยการผ่านระบบ CMU e-document
- Book Bank ของผู้รับเงิน

จากนั้น นำส่งเอกสารและลง Log Book ให้กับงานการเงิน

**6. ค่าสาธารณูปโภค**

พนักงานจัดเตรียมเอกสารที่เกี่ยวข้อง ดังนี้
- บันทึกข้อความ/หนังสือจากคณะ หน่วยงานภายในหรือภายนอกมหาวิทยาลัย
- หลักฐานการอนุมัติจากผู้อำนวยการผ่านระบบ CMU e-document

- Book Bank ของผู้รับเงิน

จากนั้น นำส่งเอกสารและลง Log Book ให้กับงานการเงิน

**7. เงินประกันสัญญา**

พนักงานกรอกและจัดเตรียมเอกสารที่เกี่ยวข้อง ดังนี้
- แบบฟอร์มขอคืนเงินประกัน (FM-AF-009)
- ใบเสร็จรับเงิน (ตัวจริง) ที่อุทยานฯ ออกให้ หากสูญหายให้ใช้หนังสือแจ้งความได้
- สัญญา หรือ เอกสารอื่นที่เกี่ยวข้องกับการวางเงินประกัน
- หนังสือขอคืนเงินประกัน ต้นฉบับ (ถ้ามี)
- หลักฐานการอนุมัติจากผู้อำนวยการผ่านระบบ CMU e-document
- Book Bank ของผู้รับเงิน
- บันทึกการส่งคืนพื้นที่ อุปกรณ์ และระบบวิศวกรรม (ถ้ามี)

จากนั้น นำส่งเอกสารและลง Log Book ให้กับงานการเงิน

### วิธีปฏิบัติของพนักงานการเงิน (ใช้กับการเบิกจ่ายทุกประเภท): ใบสำคัญจ่าย ภาษีหัก ณ ที่จ่าย และการจ่ายเงินโอน เช็ค เงินสด

1. เมื่อพนักงานการเงินได้รับเอกสารการขอเบิกจ่ายในแต่ละเรื่องเรียบร้อยแล้ว จะดำเนินการดังนี้
   - 1.1. ตรวจสอบความถูกต้องของเอกสาร
   - 1.2. จัดทำใบสำคัญจ่าย (Payment Voucher)
   - 1.3. กรณีจ่ายบุคคลธรรมดา : จัดทำหนังสือรับรองภาษีหัก ณ ที่จ่าย (ภงด.3) และใบสำคัญรับเงิน (FM-AF-014)
   - 1.4. กรณีจ่ายนิติบุคคล : จัดทำหนังสือรับรองภาษีหัก ณ ที่จ่าย (ภงด.53)
   - 1.5. กรณีเงินอุดหนุนโครงการ/เงินอุดหนุนมหาวิทยาลัยเครือข่าย/เงินการกุศล/ค่าสาธารณูปโภค/เงินประกันสัญญา : จัดทำบันทึกข้อความ/หนังสือตราครุฑ
2. พนักงานการเงินจ่ายเงินตามความประสงค์ของผู้รับเงิน โดยแบ่งเป็น 3 กรณี ดังนี้

**กรณีที่ 1 : ประสงค์รับเป็นเงินโอน**
1. จัดทำ text file การโอนเงิน พร้อมทั้งตรวจสอบความถูกต้อง
2. Upload text file การโอนเงินเข้าในระบบ Internet banking และจัดทำรายงานสถานะการทำธุรกรรม (Transaction Status Report)
3. เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมอนุมัติข้อมูลที่ Upload ในระบบ
4. เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ ให้พิมพ์รายงานการโอนเงินแนบกับชุดเอกสารพร้อมส่งต่อให้งานบัญชี
5. แจ้งสถานะการจ่ายเงินให้กับผู้รับเงินรับทราบทาง e-mail

**กรณีที่ 2: ประสงค์รับเป็นเช็ค**
1. จัดทำเช็ค (Cheque) และใบเสนอเช็ค พร้อมทั้งตรวจสอบความถูกต้อง
2. เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมลงนามอนุมัติการจ่ายเช็ค
3. เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ จะทำการสำเนาเช็คและแจ้งให้ผู้รับเงินมารับเช็คที่อุทยานฯ พร้อมลงนามในใบสำคัญจ่าย (Payment Voucher)
4. ส่งต่อเอกสารให้งานบัญชี

**กรณีที่ 3: ประสงค์รับเป็นเงินสด**
1. จัดทำเช็ค (Cheque) และใบเสนอเช็ค พร้อมทั้งตรวจสอบความถูกต้อง
2. เสนอผู้มีอำนาจ ทบทวนความถูกต้องของเอกสารทางการเงิน พร้อมลงนามอนุมัติการจ่ายเช็ค
3. เมื่อพนักงานการเงินได้รับเอกสารคืนจากผู้มีอำนาจ จะทำการสำเนาเช็ค และนำเช็ค (Cheque) ไปขึ้นเงิน รวมถึงแจ้งให้พนักงาน (PM) มารับเงินสดพร้อมลงนามในใบสำคัญจ่าย (Payment Voucher)
4. ส่งต่อเอกสารให้งานบัญชี
