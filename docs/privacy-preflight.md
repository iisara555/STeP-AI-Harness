# ตรวจไฟล์บนเครื่องก่อนแนบให้ AI

เปิด `Check-Privacy-STeP-AI.bat` (Windows) หรือ `Check-Privacy-STeP-AI.command` (macOS) ในชุดติดตั้ง แล้วเลือกไฟล์บนเครื่อง **ก่อนแนบให้ AI** ต้องติดตั้ง STeP AI ให้เสร็จก่อน ตัวตรวจจะไม่ดาวน์โหลด runtime เอง

ตัวตรวจอ่านข้อความ UTF-8, text layer ของ PDF และข้อความ Word ใน DOCX บนเครื่อง ไม่มี OCR ไม่มีการเรียก model และไม่มีการส่งไฟล์ออก ไม่เขียนข้อความที่สกัดได้ลงไฟล์ชั่วคราวหรือ log การเปิดไฟล์แนบให้ Claude/ChatGPT อ่านก่อนถือว่าช้าเกินไป: STeP ไม่ได้ดักการอัปโหลดของโปรแกรมเหล่านั้น

## อ่านผลอย่างไร

| ผล | สิ่งที่ต้องทำ |
| --- | --- |
| `pass` | ไม่พบรูปแบบที่รู้จักในข้อความ ตรวจเนื้อหาและสิทธิ์ต้นทางต่อ |
| `auto-mask` | ปิดบังเฉพาะรูปแบบที่รู้จัก ตรวจชื่อหรือข้อมูลที่หลุดและสิทธิ์ก่อนส่ง |
| `human-confirm` | ต้องให้คนตรวจ เช่น ตารางชื่อ ไฟล์ PDF/DOCX หรือไฟล์ที่อ่านไม่ได้ |
| `block-external` | หยุดส่งออก: พบ credential หรือข้อมูลอ่อนไหวร่วมกับตัวระบุบุคคล |

`canSendToExternalAI` เป็น `false` ทุกกรณี เพราะ scanner ไม่มีอำนาจอนุมัติการส่งออก ใช้ผู้รับผิดชอบข้อมูลและช่องทางที่องค์กรอนุมัติแยกจากผลตรวจ ถ้าต้องการความช่วยเหลือ ติดต่อ **STeP AI Geek** ตาม [SUPPORT.md](../SUPPORT.md)

## สำหรับผู้ดูแลหรือผู้ใช้ CLI

จากโฟลเดอร์ชุดติดตั้ง ใช้ Node ที่ติดตั้งอยู่ หรือคำสั่ง `step-ai` หากมีใน PATH:

```text
node bin/step-ai.js privacy --file "เอกสาร.pdf"
node bin/step-ai.js privacy --file "เอกสาร.docx" --json
node bin/step-ai.js privacy --file "เอกสาร.docx" --redact
```

- `--json` คืนเฉพาะ metadata: hash ของไฟล์ ระดับความเสี่ยง จำนวนชนิดข้อมูลที่พบ และข้อจำกัด ไม่มีข้อความดิบ ชื่อไฟล์ หรือรายละเอียด exception จาก parser
- `--redact` สร้าง `ชื่อไฟล์.redacted.txt` ข้างต้นฉบับ **สำหรับตรวจด้วยคน** เท่านั้น ไม่แก้ PDF/DOCX ไม่รักษารูปแบบ และไม่ปิดบังภาพในต้นฉบับ ไม่เขียนทับไฟล์เดิม
- เมื่อพบตารางชื่อ ข้อมูลที่ยังระบุไม่ได้ ความเสี่ยงสูง หรืออ่านได้เพียงบางส่วน จะไม่สร้างสำเนาข้อความ เพราะอาจทำให้เข้าใจผิดว่าปิดบังครบแล้ว
- สำเนาข้อความอาจยังมีข้อมูลที่ไม่ตรง pattern ให้ตรวจและตัดส่วนไม่จำเป็นก่อนใช้ และลบสำเนาเมื่อหมดความจำเป็น
- exit code: `0` = ไม่พบ pattern ในข้อความ (ไม่ใช่อนุญาตส่ง), `2` = ต้องตรวจ/อ่านไม่ได้/เขียนสำเนาไม่ได้, `3` = block external
- `--ocr` ยังไม่รองรับ และคืนสถานะต้องตรวจด้วยคน

## ขอบเขตและข้อจำกัด

- PDF อ่านเฉพาะ text layer; ภาพ ลายเซ็น annotation ไฟล์ซ้อน และ metadata ไม่ได้รับการตรวจ หากมีหน้าที่ไม่มีข้อความหรือ parser เตือน จะระบุ `partial`/`unavailable`
- DOCX อ่าน document, header, footer, footnote, endnote และ comments รวมข้อความในตารางและข้อความที่ถูกลบแต่ยังอยู่ใน XML; ไม่ครอบคลุมภาพ วัตถุฝัง metadata หรือ layout
- รูปภาพและ XLSX ยังไม่รองรับ ห้ามถือว่าอ่านไม่ได้เท่ากับไม่มีข้อมูลส่วนบุคคล
- ตรวจชื่อที่มี label/คำนำหน้า เลขประจำตัว เบอร์ อีเมล บัญชี ที่อยู่ passport ใบขับขี่ Line ID วันเกิด บัตรที่ผ่าน Luhn และคำอ่อนไหวไทย/อังกฤษแบบกำหนดไว้ ไม่ใช่การจำแนกชื่อบุคคลทุกแบบ
- ตารางชื่อและ label ที่ยังจับค่าไม่ได้ให้ `human-confirm`; ใช้การหยุดให้คนตรวจทั้งส่วน ไม่อ้างว่าปิดบังทุกเซลล์แล้ว
- ไฟล์สูงสุด 25 MiB, PDF 200 หน้า, ข้อความ 1 ล้านอักขระ, XML ที่แตกจาก DOCX รวมไม่เกิน 8 MiB, archive ไม่เกิน 1,000 entries; worker จำกัดเวลา 20 วินาทีและ V8 old-generation heap 256 MiB (ไม่ใช่เพดาน RAM ของ OS)
- cache ในหน่วยความจำเก็บ hash+metadata แบบ LRU สูงสุด 256 รายการ ไม่เก็บข้อความต้นฉบับ ไม่สร้างฐานข้อมูล cache บนดิสก์

ยังไม่มี corpus เอกสารราชการที่ติดป้ายกำกับเพื่อวัด recall จึงไม่ระบุเปอร์เซ็นต์ความครอบคลุม การผ่าน regression tests ไม่ได้รับรองว่าเอกสารจริงปลอดภัยหรือระบบสอดคล้องกฎหมายครบถ้วน

## การดูแล parser

runtime และ license ที่ตรึงไว้ใน `src/vendor/privacy/` ทำให้ ZIP ใช้งานได้โดยไม่ต้อง `npm install` บนเครื่องพนักงาน PDF.js 4.10.38 ใช้สำหรับ text extraction บน Node 20+ โดยปิด eval/rendering และใช้ CMaps/fonts ที่อยู่ในชุดเท่านั้น รุ่นนี้ไม่ใช่ PDF.js major ล่าสุด; ตรวจ advisory และทดสอบ compatibility ก่อนอัปเกรดทุกครั้ง

ผู้ดูแลใช้ `npm ci --prefix scripts/privacy-vendor --ignore-scripts --omit=optional`, `npm audit --prefix scripts/privacy-vendor --omit=dev` และ `node scripts/vendor-privacy.mjs` เพื่อสร้าง runtime ซ้ำจาก lockfile ตรวจ hash ของทุกไฟล์ด้วย `test/privacy-documents.test.js` License ของ `@nodable/entities` ที่แพ็กเกจไม่ได้แนบมานำจาก [upstream LICENSE](https://github.com/nodable/val-parsers/blob/main/LICENSE) และเก็บไว้พร้อม source สำหรับ rebuild
