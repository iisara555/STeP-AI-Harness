# คู่มือการใช้งาน STeP AI สำหรับพนักงาน

เอกสารนี้เป็นคู่มือฉบับเต็มสำหรับพนักงานที่ติดตั้ง STeP AI แล้ว หากยังไม่ได้ติดตั้ง ให้เริ่มจาก [README.md](../README.md) หรือ [START-HERE.md](../START-HERE.md)

## สรุปวิธีใช้ใน 30 วินาที

- เปิดโปรแกรม AI ที่องค์กรอนุมัติ แล้วเปิดโฟลเดอร์ STeP AI
- พิมพ์งานภาษาไทยตามที่ต้องการ ไม่ต้องจำชื่อ Skill หรือคำสั่งพิเศษ
- แนบเฉพาะไฟล์และข้อมูลที่จำเป็นต่อคำถาม
- อ่านผลลัพธ์และตรวจข้อมูลสำคัญก่อนนำไปใช้จริง
- ถ้าเป็นการส่ง อนุมัติ ลงนาม หรือการตัดสินใจที่มีผลผูกพัน ให้หยุดรอมนุษย์ยืนยัน

## ติดตั้งและเปิด workspace

### ดาวน์โหลด

รับชุดติดตั้งจาก Shared Drive หรือช่องทางภายในที่ทีมใช้อยู่และได้รับการแจ้งว่าเป็นชุดติดตั้งขององค์กร หากเข้าแหล่งภายในไม่ได้ ให้ดู [STeP AI Support](../SUPPORT.md) และแจ้งหัวหน้าทีมหรือผู้ประสานงานทีม **อย่าใช้ Public GitHub Release เป็นช่องทางสำรองสำหรับพนักงาน**

อย่าใช้ไฟล์จากแหล่งอื่นที่ไม่ทราบที่มา

### Windows

1. แตกไฟล์ ZIP
2. ดับเบิลคลิก `Install-STeP-AI.bat`
3. เลือกเครื่องมือที่องค์กรอนุมัติและเลือกทีมหลักของคุณ
4. เปิดโฟลเดอร์ที่แตกไฟล์ไว้ด้วยโปรแกรม AI นั้น

ถ้าเครื่องยังไม่พร้อมหรือสคริปต์แจ้งข้อผิดพลาด ให้หยุด ถ่ายภาพหน้าจอ และทำตาม [STeP AI Support](../SUPPORT.md) ไม่ต้องติดตั้ง Node.js หรือ Git เอง

### macOS

1. แตกไฟล์ ZIP
2. คลิกขวา `Install-STeP-AI.command` แล้วเลือก **Open**
3. หาก macOS แจ้งเตือนผู้พัฒนา ให้ไปที่ **System Settings → Privacy & Security → Open Anyway**
4. เลือกเครื่องมือที่องค์กรอนุมัติและเลือกทีมหลักของคุณ
5. เปิดโฟลเดอร์ที่แตกไฟล์ไว้ด้วยโปรแกรม AI นั้น

ตัวติดตั้ง macOS จะเตรียม runtime เฉพาะใน workspace เมื่อจำเป็น ไม่ต้องติดตั้งระบบเอง

## เลือกโปรแกรม AI (รุ่นฟรีก็ใช้ได้)

STeP AI ต้องใช้โปรแกรม AI ที่**ติดตั้งในเครื่องและเปิดโฟลเดอร์ได้** เพราะ AI ต้องอ่านวิธีทำงานและระเบียบในโฟลเดอร์ STeP AI เอง องค์กรไม่ได้จัดบัญชีให้ ใช้บัญชีของตัวเองได้ทั้งรุ่นฟรีและรุ่นเสียเงิน รุ่นฟรีได้ขั้นตอนของ STeP AI ครบเท่ารุ่นเสียเงิน ต่างกันที่โควตาการใช้งาน

| โปรแกรม | บัญชีที่ใช้ | วิธีเปิดโฟลเดอร์ |
| --- | --- | --- |
| Cursor | บัญชี Cursor รุ่นฟรี | File → Open Folder |
| OpenCode | ไม่ต้องสมัครสำหรับโมเดลฟรี | เปิดในโฟลเดอร์ STeP AI แล้วเลือกโมเดลฟรี |
| Gemini CLI หรือ Antigravity | บัญชี Google รวมบัญชีที่ได้สิทธิ์นักศึกษา | เปิดในโฟลเดอร์ STeP AI แล้วเลือก Trust folder |
| VS Code + GitHub Copilot | บัญชี GitHub รุ่นฟรี | File → Open Folder แล้วใช้โหมด Agent ใน Copilot Chat |

- แชท AI บนเว็บ เช่น ChatGPT หรือ Gemini ในเบราว์เซอร์ เปิดโฟลเดอร์ไม่ได้ จึงใช้ขั้นตอนของ STeP AI ไม่ได้ ให้ติดตั้งโปรแกรมในตารางแทน
- ขั้นตอนติดตั้งและล็อกอินทีละขั้นของแต่ละโปรแกรมอยู่ใน [ติดตั้งโปรแกรม AI](ai-app-setup.md)
- ถ้าโควตารุ่นฟรีหมดกลางงาน ให้รอรอบถัดไปของโปรแกรมนั้น หรือสลับไปใช้โปรแกรมอื่นในตาราง
- เงื่อนไขและชื่อรุ่นของแต่ละโปรแกรมเปลี่ยนได้ ถ้าไม่แน่ใจให้ถาม STeP AI Geek
- บัญชี AI ส่วนตัวไม่ใช่เครื่องมือที่องค์กรอนุมัติสำหรับข้อมูลลับ ห้ามแนบข้อมูลระดับ Restricted/Sensitive ตาม [กติกาข้อมูล](../rules/data-classification.md) ตรวจไฟล์ด้วย `Check-Privacy-STeP-AI` ก่อนแนบ และถ้าโปรแกรมมีตัวเลือกปิดการเก็บข้อมูล (privacy mode) ให้เปิดไว้

## First Run

พิมพ์:

> เริ่มใช้งาน STeP AI

ระบบอาจถามชื่อเรียก รูปแบบการคุย และทีมที่ทำงานอยู่ ข้ามได้ทุกข้อและเริ่มงานจริงทันที หากคุณมีงานอยู่แล้ว ให้บอกงานนั้นก่อน ไม่จำเป็นต้องทำ onboarding ให้เสร็จก่อน

First Run จะอ่านเฉพาะไฟล์เริ่มต้นและข้อมูลผู้ใช้ที่จำเป็น ไม่ไล่อ่าน Skills, Rules หรือ Manifest ทั้งหมดตั้งแต่เปิด workspace

## วิธีเขียนคำถามให้ได้ผล

บอก 4 อย่างเท่าที่มี:

1. ต้องการผลลัพธ์อะไร
2. ใช้ข้อมูลหรือไฟล์ใด
3. ต้องใช้กับใครหรือทีมใด
4. มีวันครบกำหนด รูปแบบ หรือข้อจำกัดอะไร

ตัวอย่าง:

> ช่วยตรวจ TOR ฉบับนี้ก่อนส่ง AFP สรุปจุดที่ต้องแก้ แยกสิ่งที่เป็นข้อเท็จจริงกับข้อมูลที่ต้องให้เจ้าของงานยืนยัน และอย่าเลือกผู้ชนะให้

ถ้าไม่รู้ว่าต้องใช้ทักษะใด ไม่เป็นไร ระบบจะเลือกบริบทตามงานให้เอง

## ตัวอย่างงาน 6 กลุ่ม

### ตรวจเอกสารก่อนส่ง

> ช่วยตรวจเอกสารนี้ก่อนส่ง สรุปจุดที่ขาด ความเสี่ยง และสิ่งที่ฉันต้องแก้เอง

### สรุปประชุมและ Action Plan

> สรุปการประชุมนี้ แยกมติ งานที่ต้องทำ ผู้รับผิดชอบ วันครบกำหนด และเรื่องที่ยังรอยืนยัน

### ร่างหนังสือหรือข้อความ

> ร่างหนังสือขอความอนุเคราะห์ใช้สถานที่ด้วยภาษาสุภาพ กระชับ และให้ฉันตรวจทานก่อนส่ง

### TOR และงานจัดซื้อ

> ช่วยตรวจ TOR นี้ แยก Rule, Evidence, Assumption และ Judgment พร้อมระบุสิ่งที่ต้องให้เจ้าของงานยืนยัน

### โครงการและ Timeline/Gantt

> เอา TOR นี้มาแตกกิจกรรม milestone dependency และระยะเวลา แล้วเตรียมโครงสำหรับทำ Gantt

### Privacy

> ช่วยตรวจเอกสารนี้ว่ามีข้อมูลส่วนบุคคลหรือ credential ที่ไม่ควรส่งต่อหรือไม่ และเสนอจุดที่ควรปิดบัง

ตัวอย่างเฉพาะฝ่ายและทีมอยู่ใน [docs/teams.md](teams.md), [docs/afp-demo-start.md](afp-demo-start.md) และ [docs/quality-pilot-smoke-test.md](quality-pilot-smoke-test.md)

## งานหลายขั้น

คุณสามารถขอผลลัพธ์หลายช่วงในข้อความเดียวได้ เช่น:

> สรุปประชุมนี้ แยก action plan ใส่ผู้รับผิดชอบและวันครบกำหนด แล้วเตรียม timeline สำหรับทำเป็น Sheet

ระบบจะทำทีละขั้นและส่งบริบทที่จำเป็นต่อขั้นถัดไป ไม่โหลดข้อมูลทุกอย่างพร้อมกัน และควรแจ้งสถานะเมื่อเครื่องมือที่ต้องใช้ยังไม่พร้อม

สำหรับงาน TOR → Project Plan:

- ใช้หนึ่ง TOR ต่อหนึ่ง Run
- แยก TOR Fact ออกจาก Planning Assumption
- ไม่กระจายวงเงินรวมเป็นงบรายกิจกรรมเอง
- ถ้าสร้าง Sheet หรือไฟล์จริงไม่ได้ ต้องแจ้งตามจริงและไม่ claim ว่าสร้างสำเร็จ

## ขอบเขตอำนาจ

### AI ทำได้ทันที

- สรุป ตรวจความครบถ้วน เปรียบเทียบ และจัดหมวดข้อมูล
- ร่างเอกสาร หนังสือ ตาราง แผนงาน และข้อความ
- เตรียมรายการช่องแบบฟอร์มและหลักฐานให้ตรวจทาน
- เสนอทางเลือกโดยแยกข้อเท็จจริง สมมติฐาน และคำแนะนำ

### ต้องรอการยืนยันจากผู้ใช้

- กด Submit ส่งอีเมล หรือเผยแพร่ข้อความจริง
- จองทรัพยากรหรือทำ action ที่มีผลต่อระบบภายนอก
- สร้างไฟล์ส่งมอบที่ผู้ใช้ต้องตรวจเนื้อหาก่อน

### มนุษย์เท่านั้น

- อนุมัติงบ สั่งจ่าย หรือเปลี่ยนวงเงิน
- เลือกผู้ชนะหรือวินิจฉัยผลจัดซื้อ
- ลงนามเอกสารหรือให้ความเห็นทางกฎหมายที่มีผลผูกพัน
- ประกาศใช้/ยกเลิกเอกสารควบคุม หรือรับรองผล QMS

ดูรายละเอียดเพิ่มเติมที่ [Action Verification](action-verification.md) และ [Roles & Ownership](roles-and-ownership.md)

## ความปลอดภัยข้อมูล

จำ 3 ข้อ:

1. ใช้เฉพาะ AI และช่องทางที่องค์กรอนุมัติ
2. ส่งเฉพาะข้อมูลที่จำเป็น ห้ามส่ง password, token, cookie, MFA หรือ secret
3. ถ้าระบบแจ้งความเสี่ยงสูง ให้หยุดและติดต่อเจ้าของข้อมูลหรือผู้รับผิดชอบงานนั้นตามปกติ

ข้อมูล Restricted หรือ Sensitive ต้องใช้ช่องทางที่องค์กรอนุมัติ หากไม่แน่ใจให้จัดเป็น Restricted ก่อน

ก่อนแนบเอกสาร เปิด `Check-Privacy-STeP-AI.bat` หรือ `Check-Privacy-STeP-AI.command` แล้วเลือกไฟล์บนเครื่อง อ่าน [คู่มือตรวจก่อนแนบ](privacy-preflight.md) สำหรับข้อจำกัด PDF/DOCX และการตรวจด้วยคน ตัวตรวจไม่ดักไฟล์ที่แนบตรงให้ AI ไม่มี OCR และไม่อนุญาตส่งออกจากผล auto-mask

อ่านกติกาเต็มได้ที่ [Data Classification & Privacy Gate](../rules/data-classification.md)

## ไฟล์งานและการอัปเดต

ไฟล์ที่สร้างใหม่อยู่ใต้ `output/` ตามทีม/ปี/เดือน/ประเภท และควรมีเลขเวอร์ชันเพื่อป้องกันการเขียนทับ:

```text
output/<TEAM>/<YYYY>/<MM>/<TYPE>/YYYYMMDD_TEAM_TYPE_TITLE_vNN.ext
```

อัปเดตด้วย:

- Windows: `Update-STeP-AI.bat`
- macOS: `Update-STeP-AI.command`

Updater จะสำรองรุ่นเดิมและรักษา `USER.md`, `MEMORY.md`, `output/` และไฟล์ที่ผู้ใช้แก้เองตามที่ระบบติดตามไว้ หากอัปเดตไม่ผ่าน ให้ทำตาม [STeP AI Support](../SUPPORT.md)

## แจ้งปัญหาและของานเพิ่ม

### AI ตอบไม่ถูก

พิมพ์ในแชท:

> เมื่อกี้ตอบไม่ถูก ช่วยแจ้งทีม STeP AI ให้หน่อย

หรือดับเบิลคลิก `Feedback-STeP-AI.bat` / `Feedback-STeP-AI.command` เลือกแจ้งปัญหา กรอก `FEEDBACK.md` แล้วส่งตาม [STeP AI Support](../SUPPORT.md) ผ่านช่องทางภายในของทีม

### อยากให้ AI ช่วยงานใหม่

พิมพ์:

> อยากให้ STeP AI ช่วยงานนี้: …

หรือเปิดปุ่ม Feedback เลือกของานเพิ่ม กรอก `REQUEST_NEW_TASK.md` แล้วส่งตาม [STeP AI Support](../SUPPORT.md) ผ่านหัวหน้าทีมหรือผู้ประสานงานทีม

### ติดตั้งไม่สำเร็จ

ถ่ายภาพหน้าจอพร้อมข้อความผิดพลาด แล้วทำตาม [STeP AI Support](../SUPPORT.md) และอย่าแก้ไฟล์ `skills/`, `rules/` หรือ `manifest/` เอง
