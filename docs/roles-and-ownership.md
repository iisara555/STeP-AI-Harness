# Roles and Ownership

| Role | ขอบเขต | เจ้าของ Skill ที่ควรมี |
|---|---|---|
| Creative | Brief, concept, artwork, presentation, event | หัวหน้าหรือผู้แทน Creative |
| PM | TOR, แผนงาน, ประชุม, การส่งมอบ | PM Lead |
| Developer | ระบบ, GitHub, deployment, incident | Technical Lead |
| AI Admin | Governance, review, version, adoption | ผู้ดูแลอย่างน้อย 2 คน |

ทุก Skill ต้องมีผู้รับผิดชอบเชิงเนื้อหา แม้ชื่อเจ้าของจะไม่ได้เขียนอยู่ในไฟล์ Skill โดยตรง ให้บันทึก ownership ในระบบจัดการงานหรือ CODEOWNERS ของ repository

### ข้อควรระวัง

- **GA, NMCO, LINC, PubSec กำกับร่วมกันโดยเจตนา** (ช่วยกันดู) ผู้ดูแลยืนยันแล้ว 2026-09-20 — ไม่ใช่ข้อมูลซ้ำที่ต้องแก้ และไม่ต้องบังคับเลือกผู้กำกับคนเดียว ให้ส่งต่อตามเรื่องที่แต่ละคนรับผิดชอบ
- ผังนี้บอก **การกำกับดูแล** ไม่ได้บอกว่าผู้กำกับอนุมัติแทนผู้มีอำนาจตาม [`manifest/authority.yaml`](../manifest/authority.yaml) ได้
- ไม่เก็บเบอร์โทร Line หรืออีเมลส่วนบุคคลใน repository ตาม [Knowledge Policy](knowledge-policy.md)
- ตำแหน่ง **ผู้จัดการโครงการ** ของ ดร.กรพินธุ์ จิระพงษ์ และ ดร.ณัฐธิดา เตชะบุญ ยืนยันแล้ว 2026-09-20 — ไฟล์ทำเนียบปี 2565 ที่ระบุเป็น "ผู้จัดการทั่วไป" ถือว่าล้าสมัย
