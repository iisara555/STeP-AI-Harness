# Knowledge Policy

## เก็บได้

- วิธีทำงานที่ใช้ซ้ำได้
- Checklist และเกณฑ์ตรวจงาน
- รูปแบบเอกสารที่เผยแพร่หรืออนุมัติให้ใช้ภายในแล้ว
- บทเรียนจากปัญหาที่ตัดข้อมูลระบุตัวบุคคลและข้อมูลโครงการอ่อนไหวออกแล้ว

## ห้ามเก็บ

- Credential และ Secret ทุกชนิด
- เลขประจำตัว ที่อยู่ เบอร์โทร อีเมลส่วนบุคคล หรือข้อมูลสุขภาพ
- เอกสารจัดซื้อ สัญญา งบประมาณ หรือข้อเสนอที่ยังไม่อนุมัติให้แชร์
- ไฟล์ลูกค้าและข้อมูลผู้ประกอบการที่มีข้อจำกัด
- Transcript ทั้งบทสนทนาโดยไม่คัดกรอง

## Lifecycle

1. Contributor ร่าง Learning พร้อมระบุบริบทและขอบเขต
2. เจ้าของงานตรวจความถูกต้องและลบข้อมูลอ่อนไหว
3. AI Admin หรือผู้ตรวจคนที่สองอนุมัติก่อน merge
4. เมื่อใช้ซ้ำและเสถียร ให้ยกระดับเป็น Skill, Rule หรือ Doc
5. ทบทวนทุก 90 วัน; archive เมื่อหมดอายุหรือไม่มีเจ้าของ

## ค่าเริ่มต้น Pilot

- Recall: ปิด
- Session prompt sharing: ไม่เปิด
- Usage report: ปิด
- เปิดเฉพาะหลังผ่านการประเมิน Privacy และได้รับอนุมัติจากหน่วยงาน
