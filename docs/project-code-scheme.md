## 8. ข้อควรระวังเมื่อ AI ใช้รหัสนี้

1. รหัสนี้ใช้ **อ้างอิงและจัดหมวด** เท่านั้น ไม่ใช่การยืนยันว่าโครงการได้รับอนุมัติหรือมีงบประมาณจริง
2. การผูกรหัสกับการเบิกจ่ายหรือรายงานการเงินเป็นอำนาจของ AFP (`manifest/authority.yaml` → `budget-allocation`)
3. ทะเบียน Stakeholder (รหัส 3 ตัวอักษร) มีชื่อบริษัทคู่สัญญาและผู้ประกอบการที่บ่มเพาะ **ห้ามนำเข้า repo สาธารณะ** ให้เปิดจากไฟล์ต้นทางของทีมเท่านั้น
4. ถ้าผู้ใช้ขอให้ "สร้างรหัสโครงการ" ให้ประกอบจากค่าที่ผู้ใช้ยืนยัน อย่าเดารหัสแหล่งทุนหรือแผนงานเอง
