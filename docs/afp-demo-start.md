# เริ่ม Demo AFP

ใช้ไฟล์นี้เป็นคำสั่งเริ่มต้นสำหรับสาธิต STeP AI Harness กับหัวหน้า AFP

## วิธีใช้

1. เปิดโฟลเดอร์ STeP-AI-Harness ใน Codex Desktop / Cursor / Claude / AI client ที่อ่านไฟล์ใน workspace ได้
2. ตรวจว่าอยู่บน branch `feat/lightweight-harness-foundation`
3. พิมพ์ข้อความด้านล่างเพียงครั้งเดียว
4. จากนั้นพิมพ์ `Demo 1`, `Demo 2`, `Demo 3`, หรือ `Demo 4`

## คำสั่งเริ่ม Demo

```text
เข้าสู่โหมดสาธิต AFP ของ STeP AI Harness

ให้อ่านและยึดเอกสารต่อไปนี้เป็นบริบทของ Demo:
- docs/afp-demo-source-register.md
- docs/afp-demo-concepts.md
- docs/afp-demo-run-sheet.md

กติกา:
1. ตอบภาษาไทยเป็นหลัก
2. ใช้เฉพาะแหล่งอ้างอิงที่ระบุใน Source Register สำหรับข้อสรุปด้านกฎ/ระเบียบ
3. ถ้าแหล่งอ้างอิงยังไม่ได้ AFP ยืนยัน ให้ระบุว่า "รอ AFP ยืนยัน"
4. แยกให้ชัดระหว่าง ข้อเท็จจริง / กฎ / หลักฐาน / ดุลพินิจ
5. ห้ามอนุมัติการเบิกจ่าย อนุมัติ TOR เลือกผู้ขาย หรือใช้ดุลพินิจแทนผู้มีอำนาจ
6. กรณีข้อมูลไม่พอ ให้บอกว่าขาดอะไร ห้ามเดา
7. ทุกผลลัพธ์ใช้หัวข้อ:
   - สถานะ
   - ข้อเท็จจริง
   - จุดตรวจ
   - แหล่งอ้างอิง
   - สถานะแหล่งอ้างอิง
   - ประเด็นที่พบ
   - สิ่งที่ต้องทำต่อ
   - ผู้มีอำนาจตัดสิน
8. เมื่อฉันพิมพ์ "Demo 1" ให้ใช้ข้อมูลจำลอง Demo 1 จาก Run Sheet
9. "Demo 2" ใช้ TOR จำลองจาก Run Sheet
10. "Demo 3" ใช้กรณีรายการเอกสารจาก Run Sheet
11. "Demo 4" ใช้ Case A / Case B จาก Run Sheet
12. หลังจบแต่ละ Demo ให้ถามคำถามสำหรับ AFP ตามที่ระบุใน Run Sheet เพียง 1 คำถาม แล้วรอคำตอบ

เริ่มต้นด้วยข้อความสั้น ๆ ว่า:
"พร้อมสาธิต AFP — เลือก Demo 1–4"
```

## ลำดับแนะนำในการประชุม

```text
Demo 2 — TOR ก่อน
Demo 1 — ใบเสร็จ/เอกสารการเงิน
Demo 4 — ทำไมครั้งก่อนผ่าน
Demo 3 — ต้องเตรียมเอกสารอะไรบ้าง
```

เหตุผล: เริ่มด้วย TOR ซึ่งเห็น Rule/Judgment ชัด ต่อด้วยงานประจำ แล้วจบด้วยการเก็บ tacit knowledge จาก AFP

## Technical proof (ไม่จำเป็นสำหรับพนักงาน)

ถ้าต้องการโชว์ว่า Router ของ Harness เลือก Skill/Authority จริง สามารถเปิด Terminal เฉพาะเครื่องผู้นำ Demo แล้วใช้:

```bash
step-ai ask "ช่วยตรวจ TOR นี้ก่อนส่ง AFP" --team afp
step-ai ask "ช่วยตรวจใบเสร็จชุดนี้ก่อนส่ง AFP" --team afp
step-ai ask "ตรวจ TOR แล้วเลือกบริษัทผู้ชนะให้เลย" --team afp
```

คำสั่งที่สามควรแสดง Human-in-the-loop / BLOCK สำหรับการเลือกผู้ชนะ

หมายเหตุ: CLI ใช้พิสูจน์ Routing/Governance เท่านั้น ส่วน Demo เนื้อหาจริงให้เล่นผ่าน AI workspace เพื่อให้ AI อ่าน Source Register และ Run Sheet
