## สิ่งที่ประกาศกำหนดแต่ไม่เก็บใน repository

ประกาศฉบับจริงระบุค่าเหล่านี้รายขั้น — **ห้ามคัดเข้า repository และห้าม AI ตอบจากความจำ**

- เงินเดือนต่ำสุด / เงินเดือนสูงสุด ของแต่ละกลุ่มตำแหน่ง
- ค่าความเชี่ยวชาญ / ค่าตำแหน่ง (บาท/เดือน) ของแต่ละขั้น
- สัดส่วนต่อจำนวนพนักงานทั้งหมดของแต่ละกลุ่ม

## Guardrails เมื่อ AI ตอบเรื่องนี้

1. ตอบได้เฉพาะ **โครงสร้างขั้น ชื่อตำแหน่ง และผู้มีอำนาจอนุมัติ** — ตัวเลขเงินเดือนและค่าตำแหน่งให้เปิดฉบับจริงเท่านั้น
2. แยก **สาย S** ออกจาก **สาย L** ทุกครั้ง — เส้นทาง เงื่อนไข และผู้มีอำนาจแต่งตั้งไม่เหมือนกัน
3. การเลื่อนขั้น การประเมิน และการแต่งตั้ง เป็น human-only ตาม [`manifest/authority.yaml`](../manifest/authority.yaml) → `hr-performance-evaluation`
   AI จัดเตรียมข้อมูลประกอบได้ แต่ไม่ชี้ว่าใครควรได้เลื่อนขั้น
4. ขั้นที่ต้องผ่าน **คณะกรรมการอำนวยการอุทยานฯ** หรือ **อธิการบดี/สภามหาวิทยาลัย** ห้ามสรุปว่า "ผู้อำนวยการอนุมัติได้เอง"
5. อัตราเงินเดือนตามประกาศนี้ถูกอ้างถึงใน [ประกาศฯ หลักเกณฑ์บริหารงานบุคคลฯ 2569](hr-personnel-welfare-index.md) ข้อ 3.1 — ถ้าผู้ใช้ถามเรื่องอัตราเงินเดือน ให้ชี้ไปทั้งสองฉบับ
6. ถ้าพบฉบับแก้ไขใหม่กว่านี้ ให้ปรับ `documents.yaml` และดัชนีนี้พร้อมกัน
