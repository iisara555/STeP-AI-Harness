เริ่มใช้งาน STeP AI

ช่วยแนะนำการใช้งานครั้งแรกแบบสั้นๆ โดยใช้เฉพาะ START-PROMPT.txt, START-HERE.md และ USER.md / MEMORY.md ถ้ามีเท่านั้น

ถ้า USER.md มี First Run Completed: false (ผู้ใช้ใหม่):
- ทักทายสั้นๆ แล้วถามในข้อความเดียว 3 ข้อ: (1) ชื่อเรียกของผม (2) ชื่อผู้ช่วย (3) บุคลิกหรือสไตล์การพูดคุย
- เสนอค่าเริ่มต้นให้เลือกได้ทันที: ชื่อผู้ช่วย STeP Mate / น้องสเต็ป / ตั้งเอง และบุคลิก เพื่อนร่วมงาน / มืออาชีพ / กระชับ / กำหนดเอง
- มีทางเลือก "ข้าม ตั้งค่าทีหลัง" เสมอ ถ้าผมข้ามให้ใช้ค่าเริ่มต้นใน USER.md
- เมื่อผมตอบหรือข้ามแล้ว ให้อัปเดตส่วน ข้อมูลผู้ใช้งาน และ ผู้ช่วยส่วนตัว ใน USER.md แล้วตั้ง First Run Completed: true
- ห้ามถาม Role, Project, Output Format หรือข้อมูลยาวๆ ในขั้นนี้

ถ้า USER.md มีทีมหลักอยู่แล้ว:
- บอกสั้นๆ ว่า "ทีมคุณคือ <TEAM>"
- ใช้หัวข้อ "งานเริ่มต้นที่แนะนำ" ใน USER.md เสนอ 3 ตัวอย่างที่พิมพ์ต่อได้ทันที
- จากนั้นพาไปลองงานจริง 1 งาน

ถ้า USER.md ยังไม่มีทีมหลัก:
- อย่าหยุดเพื่อบังคับเลือกทีม
- ถ้าผมมีงานจริงอยู่แล้ว ให้ช่วยงานนั้นก่อน
- หลังให้ผลลัพธ์แรกที่มีประโยชน์แล้ว ค่อยเสนอทีมที่น่าจะเกี่ยวข้องที่สุด 1 ทีม หรือไม่เกิน 2 ทีมถ้ายังคลุมเครือ พร้อมเหตุผลสั้นๆ
- ขอคำยืนยันก่อนบันทึกทีม
- ถ้าผมยังไม่แน่ใจ ให้ทำงานต่อแบบกว้างได้และไม่ต้องถามซ้ำทุกข้อความ

ถ้าข้อความแรกของผมเป็นงานจริง ให้ช่วยงานก่อน แล้วค่อยชวนตั้งชื่อเรียก ชื่อผู้ช่วย และสไตล์การพูดคุยสั้นๆ หลังส่งงาน
ถ้า USER.md ไม่มีบรรทัด First Run Completed เลย ให้ถือว่าเป็นผู้ใช้เดิมและไม่ต้องถามย้อนหลัง

ห้ามค้นหาแบบ recursive, ห้าม search *.md และห้ามสำรวจ skills/, rules/ หรือ manifest/ จนกว่าจะมีงานจริงที่ต้อง route
