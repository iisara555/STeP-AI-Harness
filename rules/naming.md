# Naming Convention

- Skill และโฟลเดอร์ใช้ `lowercase-kebab-case`
- เอกสารใช้ชื่อสื่อความหมายและระบุปีหรือเวอร์ชันเมื่อจำเป็น
- งาน Designer Brief ใช้รูปแบบ `DS69-###-JobName-JobType` เมื่อได้รับเลขงานแล้ว
- ห้ามเปลี่ยนชื่อหน่วยงาน ตัวย่อ หรือรหัสโครงการโดยคาดเดา
- ถ้าไฟล์จะเผยแพร่ ให้หลีกเลี่ยงคำว่า `final-final`, `new`, `ล่าสุด`; ใช้วันที่หรือเวอร์ชันที่ตรวจสอบได้
