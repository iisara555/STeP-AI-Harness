# Data Classification

จัดข้อมูลก่อนส่งให้ AI หรือเก็บใน repository:

- **Public:** เผยแพร่แล้ว ใช้งานได้ตามปกติ
- **Internal:** ใช้ภายในได้ แต่ไม่ควรเผยแพร่ภายนอกโดยไม่มีการตรวจ
- **Restricted:** ข้อมูลส่วนบุคคล การเงิน สัญญา การจัดซื้อ ข้อเสนอที่ยังไม่ประกาศ ข้อมูลลูกค้า หรือข้อมูลรับรองตัวตน ห้ามใส่ใน TeamAI repository

เมื่อไม่แน่ใจ ให้จัดเป็น Restricted และขอเจ้าของข้อมูลยืนยันก่อน
