# STeP AI

**ให้ AI ช่วยเตรียมงาน แล้วคุณตรวจและตัดสินใจขั้นสุดท้าย**

สรุปประชุม ร่างหนังสือ เตรียม TOR จัดตาราง ตรวจใบเสร็จก่อนส่ง AFP และถามเรื่องระเบียบหรือสวัสดิการของ STeP โดยเริ่มจากข้อมูลหรือต้นเรื่องที่คุณมี แล้วแก้ร่างและส่งออกในพื้นที่ทำงานเดียว

[ดาวน์โหลด Windows / Mac](https://github.com/iisara555/STeP-AI-Harness/releases/tag/desktop-v0.5.34) · [เริ่มใช้งาน](#เริ่มใช้งานใน-3-ขั้นตอน) · [ขอความช่วยเหลือ](SUPPORT.md)

![พื้นที่ทำงาน STeP Desktop พร้อมบทสนทนาและผลงาน](docs/images/gui/02-workspace.png)

**STeP Desktop** คือหน้าจอทำงานหลักของ STeP AI สำหรับพนักงาน STeP / RSP North ใช้ภาษาไทยได้ ไม่ต้องจำชื่อ Skill หรือพิมพ์คำสั่งติดตั้งเอง ภาพในหน้านี้ใช้ข้อมูลตัวอย่าง หน้าจอจริงอาจต่างตามรุ่นและการตั้งค่าขององค์กร

## ทำอะไรได้บ้าง

| งานที่คุณมี | สิ่งที่ AI ช่วยเตรียม |
| --- | --- |
| คำถามเรื่อง STeP เช่น วันลา สวัสดิการ ระเบียบ AFP ทีม หรือเอกสาร ISO | คำตอบจาก **เอกสารขององค์กร** พร้อมบอกว่ามาจากเอกสารใด |
| บันทึกหรือข้อความจากการประชุม | สาระสำคัญ มติ งานที่ต้องทำ และเรื่องที่ยังรอยืนยัน |
| หนังสือ บันทึกข้อความ หรือโครงการ | ร่างจากข้อมูลของคุณและแม่แบบ เพื่อแก้ไขต่อใน Word |
| TOR ที่ต้องตรวจหรือร่างใหม่ | ขอบเขตงาน เกณฑ์ตรวจรับ ข้อมูลที่ขาด และประเด็นที่ต้องให้เจ้าของงานยืนยัน |
| ข้อมูลที่ต้องจัดเป็นตารางหรือสไลด์ | ไฟล์ Excel และ PowerPoint สำหรับเปิดตรวจและปรับต่อ |
| ใบเสร็จที่ต้องส่ง AFP | ข้อมูลในฟอร์ม ประเภทเอกสาร หมวดเบิกที่แนะนำ และข้อสังเกตก่อนส่ง |
| เอกสารที่กำลังจะส่งต่อ | จุดที่ควรแก้ ข้อมูลที่ควรปิดบัง และหลักฐานที่ยังต้องหาเพิ่ม |
| งานสื่อที่มีรายละเอียดภาพแล้ว | ภาพใหม่จากข้อความผ่านบริการ API ที่รองรับ ให้คุณตรวจและเลือกใช้ |
| ข้อความที่ต้องแปล สรุป หรือตรวจคำผิด | ผลงานที่ตรวจได้ทันที ถ้าเนื้อหาเกี่ยวกับ STeP ระบบจะอ่านเอกสารองค์กรประกอบด้วย |

AI ช่วยทำร่างจากสิ่งที่ให้มา ข้อมูลที่ขาดยังต้องยืนยันกับเจ้าของเรื่อง เช่น เลขหนังสือ งบประมาณ ข้อกฎหมาย และผู้ลงนาม

## เริ่มใช้งานใน 3 ขั้นตอน

### 1. ติดตั้งและเชื่อมต่อ AI

สำหรับงานของหน่วยงาน ให้รับตัวติดตั้งจาก **Shared Drive หรือช่องทางภายใน** ที่ผู้ดูแลอนุมัติ

| เครื่อง | ไฟล์ |
| --- | --- |
| Windows | `STeP-Desktop-Setup-<รุ่น>.exe` |
| Mac ชิป M1 / M2 / M3 / M4 | `STeP-Desktop-<รุ่น>-arm64.dmg` |
| Mac Intel | `STeP-Desktop-<รุ่น>-x64.dmg` |

ตัวติดตั้งยังไม่มีใบรับรองจาก Microsoft และ Apple จึงอาจมีคำเตือนตอนเปิดครั้งแรก

- **Windows:** ถ้าขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
- **Mac:** ถ้าขึ้น "Apple could not verify…" ให้กด Done แล้วไปที่ **System Settings → Privacy & Security → Open Anyway** ดูวิธีอื่นในไฟล์ **อ่านก่อนเปิดครั้งแรก.html** ที่อยู่ใน DMG

ทั้งสองกรณีให้ทำเฉพาะไฟล์ที่ได้จากช่องทางขององค์กรเท่านั้น

เปิดแอป ทำ **Setup Wizard ครั้งแรก** (ชื่อเรียก ทีม ผู้ช่วย และโฟลเดอร์งาน) แล้วเลือก **เชื่อมต่อ AI** เมื่อทดสอบผ่านจึงเริ่มทำงาน

| บริการ AI | วิธีเชื่อมต่อ |
| --- | --- |
| **ChatGPT** | ลงชื่อด้วยบัญชี ChatGPT ผ่านเบราว์เซอร์ ใช้ตามสิทธิ์และโควตาของแพ็กเกจ |
| **Gemini ผ่าน Antigravity** | กดปุ่มเดียว แอปติดตั้งโปรแกรมที่ต้องใช้ แล้วให้ลงชื่อด้วยบัญชี Google (ยังเป็นช่องทางทดลอง) |
| **Gemini API** | ใช้คีย์จาก Google AI Studio มีโควตาและค่าใช้จ่ายแยกจากแพ็กเกจ Google |
| **Claude** | ใช้ API หรือ Claude Console ส่วนแพ็กเกจ Claude Pro / Max ผ่าน Claude Code เปิดได้เฉพาะเครื่องที่ผู้ดูแลอนุญาต |
| **บริการอื่น** | เช่น GitHub Copilot, OpenRouter, Qwen, MiniMax หรือบริการ API ที่องค์กรอนุมัติ |

ดูรายละเอียดแต่ละบริการใน [คู่มือ STeP Desktop](desktop/README.md#เริ่มใช้งาน)

### 2. บอกงาน หรือเลือกเครื่องมือร่างเอกสาร

กด **เริ่มงานใหม่** แล้วพิมพ์สิ่งที่ต้องการให้ช่วย แนบต้นเรื่องได้เมื่อมีสิทธิ์ส่งข้อมูลนั้น พิมพ์ด้วยเสียงได้ หากต้องการร่างตามชนิดเอกสาร ให้เปิด **เครื่องมือร่างเอกสาร** แล้วกรอกฟอร์ม

ลองเริ่มด้วยข้อความเหล่านี้:

> ช่วยตรวจเอกสารนี้ก่อนส่ง สรุปจุดที่ขาดและสิ่งที่ฉันต้องแก้เอง

> สรุปการประชุมนี้ แยกมติ งานที่ต้องทำ ผู้รับผิดชอบ วันครบกำหนด และเรื่องที่ยังรอยืนยัน

> ร่างหนังสือขอความอนุเคราะห์ใช้สถานที่ด้วยภาษาสุภาพ กระชับ และให้ฉันตรวจทานก่อนส่ง

> ช่วยตรวจ TOR นี้ แยกข้อเท็จจริง ความเสี่ยง และข้อมูลที่ต้องให้เจ้าของงานยืนยันก่อนส่ง AFP

> เอา TOR นี้มาแตกกิจกรรม ระยะเวลา milestone และ dependency แล้วเตรียมแผนสำหรับทำ Gantt

> ช่วยตรวจเอกสารนี้ว่ามีข้อมูลส่วนบุคคลหรือ credential ที่ไม่ควรส่งต่อหรือไม่ และเสนอจุดที่ควรปิดบัง

> พนักงานลาพักร้อนได้กี่วันต่อปี และต้องยื่นล่วงหน้ากี่วัน

### 3. ตรวจร่าง แก้ไข แล้วส่งออก

เปิดแถบ **ผลงาน** ตรวจชื่อ วันที่ ตัวเลข แหล่งข้อมูล และส่วนที่รอยืนยัน แก้ข้อความหรือตาราง ดูรุ่นก่อนหน้าของร่าง แล้วส่งออกเป็น `DOCX`, `PDF`, `MD`, `XLSX` หรือ `PPTX`

เริ่มงานใหม่เมื่อเปลี่ยนเรื่อง เพื่อแยกบทสนทนาและต้นเรื่องของแต่ละงาน

## ถามเรื่องของ STeP

คำถามเกี่ยวกับ STeP เช่น วันลา สวัสดิการ เส้นทางความก้าวหน้า ระเบียบการเงินและพัสดุ ผู้บริหาร ทีม หรือเอกสาร ISO จะถูกตอบจาก **เอกสารขององค์กร** เสมอ ไม่ใช่ความรู้ทั่วไปของ AI กติกานี้ใช้กับงานแปล สรุป และตรวจคำผิดที่มีเนื้อหาเกี่ยวกับ STeP ด้วย

ถ้าไม่พบเอกสารที่ตอบได้ AI จะบอกว่าไม่มีแหล่งข้อมูล และแนะนำให้ถามทีมเจ้าของเรื่อง ดูรายการเอกสารที่ AI ใช้ได้ใน [ความรู้ขององค์กร](docs/knowledge/README.md)

## ร่างเอกสารตามแบบที่ต้องใช้

เลือกชนิดเอกสาร → กรอกข้อมูลหรือแนบต้นเรื่อง → ให้ AI ร่าง → แก้ไขและส่งออก

| เครื่องมือ | ข้อมูลที่ใช้เริ่มร่าง |
| --- | --- |
| **ร่าง TOR** | วัตถุประสงค์ ขอบเขตงาน คุณสมบัติ และเกณฑ์ตรวจรับ |
| **ร่างบันทึกข้อความ** | เรื่องที่ต้องการเสนอ เช่น ขออนุมัติ ขอความเห็นชอบ หรือรายงานผล |
| **ร่างหนังสือราชการ** | ผู้รับ จุดประสงค์ และข้อมูลสำหรับหนังสือภายนอก เชิญ ตอบกลับ หรือประสานงาน |
| **ร่างโครงการ** | หลักการและเหตุผล วัตถุประสงค์ กิจกรรม งบประมาณ และตัวชี้วัด |
| **ร่างรายงานการประชุม** | วาระ สาระสำคัญ มติ และผู้รับผิดชอบที่มีในต้นเรื่อง |

แต่ละเครื่องมือใช้ **Skill** ที่เกี่ยวข้องเป็นแนวทาง ทั้งโครงสร้าง กติกา และการตรวจข้อมูล ข้อมูลที่ยังขาด เช่น เลขหนังสือ งบประมาณ หรือข้อกฎหมาย จะคงไว้เป็นช่อง `[รอยืนยัน: …]` ให้คุณกรอกเอง แนบไฟล์ Word ที่มีรูปเป็นต้นเรื่องได้

- **DOCX** แก้ข้อความและตารางต่อได้ แบบร่างทั่วไปส่งออก PDF ได้ด้วย
- **ตราครุฑ** บันทึกข้อความสูง **1.5 ซม.** หนังสือภายนอก **3 ซม.** เฉพาะหน้าแรก เลือกไม่ใส่ได้ ส่วน TOR โครงการ และรายงานประชุมไม่ใส่อัตโนมัติ
- **แม่แบบจาก MIS** สำหรับบันทึก หนังสือ โครงการ และรายงานประชุม เลือกแม่แบบ DOCX แล้วแอปจะใช้รูปแบบต้นฉบับ ติดตั้งฟอนต์ตามแบบและตรวจทุกหน้าใน Word ก่อนเสนอ TOR ใช้แบบ 16 หัวข้อเดิม ดู [วิธีใช้แม่แบบ](desktop/README.md#ใช้แม่แบบจาก-mis)

## ตรวจใบเสร็จก่อนส่ง AFP

เปิด **ตรวจใบเสร็จ AFP** เพื่อให้ระบบช่วยอ่านและเติมข้อมูลในฟอร์ม พร้อมแสดงประเภทเอกสาร ความครบถ้วน หมวดเบิกที่แนะนำ และขั้นตอนถัดไป

![หน้าตรวจใบเสร็จ AFP ใช้ข้อมูลตัวอย่าง](docs/images/gui/04-receipt-afp.png)

การอ่านใบเสร็จมี 3 ทาง ใช้ร่วมกันได้

1. **OCR ในเครื่อง** อ่านภาษาไทยโดยไม่ส่งภาพออกนอกเครื่อง เมื่อติดตั้งส่วนเสริมแล้ว
2. **ให้ AI อ่านภาพ** ด้วย ChatGPT, Gemini หรือ Claude (ยังไม่รองรับ Gemini ผ่าน Antigravity) หลังคุณยินยอมส่งภาพ และเมื่อองค์กรเปิดให้ใช้ เหมาะกับใบเขียนมือหรือภาพไม่ชัด
3. **AI กรอง OCR อีกชั้น** เมื่อ OCR อ่านได้หลายค่าที่ขัดกัน AI ช่วยเลือกจากค่าที่อ่านไว้ ไม่เดาค่าใหม่

คุณเทียบข้อมูลกับต้นฉบับ แก้ส่วนที่ผิด แล้ว **ยืนยันฟอร์มครั้งเดียว** ก่อนบันทึกร่างหรือให้ AI ตรวจทานต่อ เมื่อแก้ค่าหรืออ่านใหม่ต้องยืนยันอีกครั้ง คำแนะนำหมวดเบิกยังต้องเทียบกฎและสิทธิ์จริง ไม่ใช่การอนุมัติเบิก การอ่านยังเป็นฟังก์ชันทดลองและต้องตรวจเทียบต้นฉบับทุกช่อง

อ่าน [วิธีเริ่มตรวจใบเสร็จ](desktop/README.md#ตรวจใบเสร็จก่อนส่ง-afp) ก่อนใช้งานครั้งแรก

## รู้จักพื้นที่ทำงาน

- **แถบซ้าย — งานและเครื่องมือ:** เริ่มงานใหม่ ค้นงานเก่า เปิดเครื่องมือร่างเอกสาร ศูนย์รวม Skill หรือหน้าตรวจใบเสร็จ
- **ตรงกลาง — คุยกับ AI:** บอกงาน แนบต้นเรื่อง และถามต่อในงานเดิม
- **แถบขวา — ผลงาน:** ตรวจและแก้ร่าง ดูรุ่นก่อนหน้า แล้วส่งออกไฟล์

**Skill คือแนวทางสำหรับงานแต่ละประเภท** เช่น ตรวจ TOR สรุปประชุม หรือเตรียม ISO audit เลือกได้จาก **ศูนย์รวม Skill** หรือพิมพ์ `/` โดยไม่ต้องจำชื่อทั้งหมด การเลือกให้อัตโนมัติขึ้นกับการตั้งค่าขององค์กร

ส่วนอื่นที่ควรรู้

| ส่วน | ใช้ทำอะไร |
| --- | --- |
| **ทัวร์แนะนำ** | ทัวร์ 2 ส่วน คือพื้นฐานการเริ่มงาน และเครื่องมือช่วยงาน เปิดดูซ้ำได้จากการตั้งค่า |
| **สไตล์การพูด** | เลือกน้ำเสียงของผู้ช่วย เช่น ภาษาเหนือ Ob-Oon หรือ Witty ในการตั้งค่า > ทั่วไป |
| **กล่องบทเรียน** | AI เสนอบทเรียนจากงานที่ถูกแก้ คุณตรวจและอนุมัติก่อนนำไปใช้ และดูได้ว่าบทเรียนช่วยงานจริงหรือไม่ |
| **การใช้งาน AI** | ดูโควตา เครดิต และการใช้งานของแต่ละบัญชี หรือพิมพ์ `/usage` |
| **มีอะไรใหม่** | สรุปสิ่งที่เปลี่ยนหลังอัปเดต เปิดซ้ำได้จาก Ctrl+K |
| **ภาษาของแอป** | เปลี่ยนหน้าจอเป็นภาษาไทยหรือ English ได้ในการตั้งค่า |

## ใช้ข้อมูลให้ถูกที่ และตรวจงานก่อนส่ง

ประวัติงานและร่างเก็บในเครื่อง เมื่อใช้บริการ AI ออนไลน์ ข้อมูลที่จำเป็นจะส่งไปยังบริการที่เลือก การอ่านภาพใบเสร็จด้วย AI ส่งภาพจริง ส่วนการส่งออกไฟล์ทำในเครื่องและไม่เรียก AI เพิ่ม

ใช้เฉพาะโปรแกรม AI และช่องทางที่องค์กรอนุมัติ แอปไม่ได้ตรวจหรือปิดบังข้อมูลอ่อนไหวให้ทุกครั้ง การตรวจอัตโนมัติขึ้นกับ [การตั้งค่าขององค์กร](docs/desktop-policy.md)

**ห้ามใส่รหัสผ่าน, token, cookie, MFA หรือ secret** ถ้าระบบแจ้งข้อมูลความเสี่ยงสูง ให้หยุดและตรวจสิทธิ์กับเจ้าของข้อมูลก่อนดำเนินการ

AI ช่วยเตรียมงานให้ตรวจต่อ ส่วน **อนุมัติเบิกเงินจริง** การ **เลือกผู้ชนะจัดซื้อ** การลงนาม และการรับรอง ต้องเป็นการตัดสินใจของผู้มีอำนาจ

## อัปเดตแอป

แอปตรวจรุ่นใหม่ให้เอง เลขรุ่นและสถานะอัปเดตอยู่ใต้ชื่อของคุณ กดที่เลขรุ่นเพื่อตรวจทันที เมื่อพร้อมให้กด **รีสตาร์ทเพื่ออัปเดต** หลังบันทึกงานที่ทำอยู่ ใช้ได้ทั้ง Windows และ Mac (Mac ตั้งแต่รุ่น 0.5.18) ประวัติงานและร่างยังอยู่ครบ ดู [วิธีอัปเดต](desktop/README.md#อัปเดตแอป)

## เมื่อทำงานต่อไม่ได้

| สิ่งที่พบ | ลองทำต่อแบบนี้ |
| --- | --- |
| ยังไม่เชื่อมต่อ AI หรือทดสอบไม่ผ่าน | เปิดการเชื่อมต่อ AI แล้วลองทดสอบบัญชีเดิมอีกครั้ง |
| คำตอบบอกว่าไม่มีแหล่งข้อมูล หรือร่างมีช่องรอยืนยัน | แนบต้นเรื่องที่มีสิทธิ์ส่ง หรือให้เจ้าของงานยืนยันข้อมูลก่อน |
| อ่านใบเสร็จไม่ได้หรือกรอกผิด | ลองให้ AI อ่านภาพ แล้วเทียบต้นฉบับและแก้ในฟอร์มก่อนยืนยัน |
| AI แจ้งว่าโควตาหมดหรือบริการไม่ว่าง | ดู **การใช้งาน AI** รอสักครู่ หรือเปลี่ยนไปบัญชีอื่นที่เชื่อมไว้ |
| งานใหม่ปนกับเรื่องเก่า | กดเริ่มงานใหม่เมื่อเปลี่ยนเรื่อง |
| อัปเดตไม่สำเร็จ | กดลองอัปเดตอีกครั้งในแอป หรือดู [วิธีอัปเดต](desktop/README.md#อัปเดตแอป) |

หากยังมีปัญหา **ถ่ายภาพหน้าจอพร้อมข้อความผิดพลาด** ปิดบังข้อมูลอ่อนไหว และแจ้งรุ่นแอป ระบบปฏิบัติการ และบริการ AI ที่ใช้ผ่าน [STeP AI Support](SUPPORT.md)

## ถ้ามีโปรแกรม AI ที่ใช้อยู่แล้ว

ใช้ **STeP Skills** ใน Claude, Codex หรือ Google Antigravity ได้ โดยติดตั้งแนวทางงาน กติกา และความรู้ขององค์กรชุดเดียวกันลงในโปรแกรมที่มีอยู่ ดู [วิธีติดตั้ง STeP Skills](plugins/step/README.md) ส่วนหน้าตรวจใบเสร็จ ฟอร์มร่างเอกสาร และแถบผลงาน ใช้ได้เฉพาะใน STeP Desktop
