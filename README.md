# STeP AI

**ให้ AI ช่วยเตรียมงาน แล้วคุณตรวจและตัดสินใจขั้นสุดท้าย**

สรุปประชุม ร่างหนังสือ เตรียม TOR จัดตารางงาน และตรวจใบเสร็จก่อนส่ง AFP เริ่มจากข้อมูลหรือต้นเรื่องที่คุณมี แล้วแก้ร่างและส่งออกในพื้นที่ทำงานเดียว

[ดูตัวติดตั้ง Windows / Mac](https://github.com/iisara555/STeP-AI-Harness/releases/tag/desktop-v0.5.33) · [เริ่มใช้งาน](desktop/README.md#เริ่มใช้งาน) · [ขอความช่วยเหลือ](SUPPORT.md)

![พื้นที่ทำงาน STeP Desktop พร้อมบทสนทนาและผลงาน](docs/images/gui/02-workspace.png)

**STeP Desktop** คือหน้าจอทำงานหลักของ STeP AI สำหรับพนักงาน STeP / RSP North ใช้ภาษาไทยได้ ไม่ต้องจำชื่อ Skill หรือใช้คำสั่งติดตั้งเอง ภาพในหน้านี้ใช้ข้อมูลตัวอย่าง หน้าจออาจต่างตามรุ่นและการตั้งค่า

## เริ่มจากงานที่อยู่ตรงหน้า

| งานที่คุณมี | สิ่งที่ AI ช่วยเตรียม |
| --- | --- |
| บันทึกหรือข้อความจากการประชุม | สาระสำคัญ มติ งานที่ต้องทำ และเรื่องที่ยังรอยืนยัน |
| หนังสือ บันทึกข้อความ หรือโครงการ | ร่างจากข้อมูลของคุณและแม่แบบ เพื่อแก้ไขต่อใน Word |
| TOR ที่ต้องตรวจหรือร่างใหม่ | ขอบเขตงาน เกณฑ์ตรวจรับ ข้อมูลที่ขาด และประเด็นที่ต้องให้เจ้าของงานยืนยัน |
| ข้อมูลที่ต้องจัดเป็นตารางหรือสไลด์ | ไฟล์ Excel และ PowerPoint สำหรับเปิดตรวจและปรับต่อ |
| งานสื่อที่มีรายละเอียดภาพแล้ว | ภาพใหม่จากข้อความผ่านบริการ API ที่รองรับ เพื่อให้คุณตรวจและเลือกใช้ |
| ใบเสร็จที่ต้องส่ง AFP | ข้อมูลในฟอร์ม ประเภทเอกสาร หมวดเบิกที่แนะนำ และข้อสังเกตก่อนส่ง |
| เอกสารที่กำลังจะส่งต่อ | จุดที่ควรแก้ ข้อมูลที่ควรปิดบัง และหลักฐานที่ยังต้องหาเพิ่ม |

AI ช่วยทำร่างจากสิ่งที่ให้มา ข้อมูลที่ขาดยังต้องยืนยันกับเจ้าของเรื่อง เช่น เลขหนังสือ งบประมาณ ข้อกฎหมาย และผู้ลงนาม

## เริ่มใช้งานใน 3 ขั้นตอน

### 1. ติดตั้งและเชื่อมต่อ AI

สำหรับงานของหน่วยงาน ให้รับตัวติดตั้งจาก **Shared Drive หรือช่องทางภายใน** ที่ผู้ดูแลอนุมัติ เปิดแอป ทำ **Setup Wizard ครั้งแรก** แล้วเลือก **เชื่อมต่อ AI** เมื่อทดสอบผ่านจึงเริ่มทำงาน

ดูวิธีเลือกไฟล์ Windows / Mac และเชื่อมบัญชีที่มีอยู่ใน [คู่มือ STeP Desktop](desktop/README.md#เริ่มใช้งาน)

### 2. บอกงาน หรือเลือกเครื่องมือร่างเอกสาร

กด **เริ่มงานใหม่** แล้วพิมพ์สิ่งที่ต้องการให้ช่วย แนบต้นเรื่องได้เมื่อมีสิทธิ์ส่งข้อมูลนั้น หากต้องการร่างตามชนิดเอกสาร ให้เปิด **เครื่องมือร่างเอกสาร** แล้วกรอกฟอร์ม

ลองเริ่มด้วยข้อความเหล่านี้:

> ช่วยตรวจเอกสารนี้ก่อนส่ง สรุปจุดที่ขาดและสิ่งที่ฉันต้องแก้เอง

> สรุปการประชุมนี้ แยกมติ งานที่ต้องทำ ผู้รับผิดชอบ วันครบกำหนด และเรื่องที่ยังรอยืนยัน

> ร่างหนังสือขอความอนุเคราะห์ใช้สถานที่ด้วยภาษาสุภาพ กระชับ และให้ฉันตรวจทานก่อนส่ง

> ช่วยตรวจ TOR นี้ แยกข้อเท็จจริง ความเสี่ยง และข้อมูลที่ต้องให้เจ้าของงานยืนยันก่อนส่ง AFP

> เอา TOR นี้มาแตกกิจกรรม ระยะเวลา milestone และ dependency แล้วเตรียมแผนสำหรับทำ Gantt

> ช่วยตรวจเอกสารนี้ว่ามีข้อมูลส่วนบุคคลหรือ credential ที่ไม่ควรส่งต่อหรือไม่ และเสนอจุดที่ควรปิดบัง

### 3. ตรวจร่าง แก้ไข แล้วส่งออก

เปิดแถบ **ผลงาน** ตรวจชื่อ วันที่ ตัวเลข แหล่งข้อมูล และส่วนที่รอยืนยัน แก้ข้อความหรือตารางได้ก่อนส่งออกเป็น `DOCX`, `PDF`, `MD`, `XLSX` หรือ `PPTX`

เริ่มงานใหม่เมื่อเปลี่ยนเรื่อง เพื่อแยกบทสนทนาและต้นเรื่องของแต่ละงาน

## ร่างเอกสารตามแบบที่ต้องใช้

เลือกชนิดเอกสาร → กรอกข้อมูลหรือแนบต้นเรื่อง → ให้ AI ร่าง → แก้ไขและส่งออก

| เครื่องมือ | ข้อมูลที่ใช้เริ่มร่าง |
| --- | --- |
| **ร่าง TOR** | วัตถุประสงค์ ขอบเขตงาน คุณสมบัติ และเกณฑ์ตรวจรับ |
| **ร่างบันทึกข้อความ** | เรื่องที่ต้องการเสนอ เช่น ขออนุมัติ ขอความเห็นชอบ หรือรายงานผล |
| **ร่างหนังสือราชการ** | ผู้รับ จุดประสงค์ และข้อมูลสำหรับหนังสือภายนอก เชิญ ตอบกลับ หรือประสานงาน |
| **ร่างโครงการ** | หลักการและเหตุผล วัตถุประสงค์ กิจกรรม งบประมาณ และตัวชี้วัด |
| **ร่างรายงานการประชุม** | วาระ สาระสำคัญ มติ และผู้รับผิดชอบที่มีในต้นเรื่อง |

แต่ละเครื่องมือใช้ **Skill** ที่เกี่ยวข้องเป็นแนวทาง ทั้งโครงสร้าง กติกา และการตรวจข้อมูล กติกากำหนดให้ใช้ข้อมูลจากต้นทาง และคงช่อง `[รอยืนยัน: …]` สำหรับเลขหนังสือ งบประมาณ ข้อกฎหมาย หรือข้อมูลอื่นที่ยังขาด ให้คุณตรวจต่อ

DOCX เก็บข้อความและตารางให้แก้ไขได้ แบบร่างทั่วไปส่งออก PDF ได้ด้วย และบันทึกข้อความมีตราครุฑสูง **1.5 ซม.** และหนังสือภายนอก **3 ซม.** เฉพาะหน้าแรก เลือกไม่ใส่ตราได้ ส่วน TOR โครงการ และรายงานประชุมไม่ใส่อัตโนมัติ

สำหรับบันทึก หนังสือ โครงการ และรายงานประชุม เลือกแม่แบบ DOCX ที่ดาวน์โหลดจาก MIS แล้วกรอกข้อมูลของงานใหม่ ส่งออกโดยใช้รูปแบบต้นฉบับ ติดตั้งฟอนต์ตามแบบและตรวจทุกหน้าใน Word ก่อนเสนอ TOR ใช้แบบ 16 หัวข้อเดิม ดู [วิธีใช้แม่แบบ](desktop/README.md#ใช้แม่แบบจาก-mis)

## ตรวจใบเสร็จก่อนส่ง AFP

เปิด **ตรวจใบเสร็จ AFP** เพื่อให้ระบบช่วยอ่านและเติมข้อมูลในฟอร์ม พร้อมแสดงประเภทเอกสาร ความครบถ้วน หมวดเบิกที่แนะนำ และขั้นตอนถัดไป

คุณเทียบข้อมูลกับต้นฉบับ แก้ส่วนที่ผิด แล้ว **ยืนยันฟอร์มครั้งเดียว** ก่อนบันทึกร่างหรือให้ AI ตรวจทานต่อ เมื่อแก้ค่าหรืออ่านใหม่ต้องยืนยันอีกครั้ง คำแนะนำหมวดเบิกยังต้องเทียบกฎและสิทธิ์จริง ไม่ใช่การอนุมัติเบิก

OCR อ่านในเครื่องเมื่อได้ติดตั้งส่วนเสริม ส่วน AI ที่รองรับภาพช่วยอ่านได้อีกทางหลังยินยอมส่งภาพ หากมีตัวเลือกที่อ่านขัดกัน ใช้ **AI กรอง OCR อีกชั้น** ให้ช่วยเลือกจากค่าที่อ่านไว้ การอ่านยังเป็นฟังก์ชันทดลองและต้องตรวจเทียบต้นฉบับทุกช่อง

อ่าน [วิธีเริ่มตรวจใบเสร็จ](desktop/README.md#ตรวจใบเสร็จก่อนส่ง-afp) ก่อนใช้งานครั้งแรก

## รู้จักพื้นที่ทำงาน

- **แถบซ้าย — งานและเครื่องมือ:** เริ่มงานใหม่ ค้นงานเก่า เปิดเครื่องมือร่างเอกสาร ศูนย์รวม Skill หรือหน้าตรวจใบเสร็จ
- **ตรงกลาง — คุยกับ AI:** บอกงาน แนบต้นเรื่อง และถามต่อในงานเดิม
- **แถบขวา — ผลงาน:** ตรวจและแก้ร่าง ดูรุ่นก่อนหน้า แล้วส่งออกไฟล์

**Skill คือแนวทางสำหรับงานแต่ละประเภท** เช่น ตรวจ TOR สรุปประชุม หรือเตรียม ISO audit เลือกได้จาก **ศูนย์รวม Skill** หรือพิมพ์ `/` โดยไม่ต้องจำชื่อทั้งหมด การเลือกให้อัตโนมัติขึ้นกับการตั้งค่าขององค์กร

## ใช้ข้อมูลให้ถูกที่ และตรวจงานก่อนส่ง

ประวัติงานและร่างเก็บในเครื่อง เมื่อใช้บริการ AI ออนไลน์ ข้อมูลที่จำเป็นจะส่งไปยังบริการที่เลือก การอ่านภาพใบเสร็จด้วย AI ส่งภาพจริง ส่วนการส่งออกไฟล์ทำในเครื่องและไม่เรียก AI เพิ่ม

ใช้เฉพาะโปรแกรม AI และช่องทางที่องค์กรอนุมัติ แอปไม่ได้ตรวจหรือปิดบังข้อมูลอ่อนไหวให้ทุกครั้ง การตรวจอัตโนมัติขึ้นกับ [การตั้งค่าขององค์กร](docs/desktop-policy.md)

**ห้ามใส่รหัสผ่าน, token, cookie, MFA หรือ secret** ถ้าระบบแจ้งข้อมูลความเสี่ยงสูง ให้หยุดและตรวจสิทธิ์กับเจ้าของข้อมูลก่อนดำเนินการ

AI ช่วยเตรียมงานให้ตรวจต่อ ส่วน **อนุมัติเบิกเงินจริง** การ **เลือกผู้ชนะจัดซื้อ** การลงนาม และการรับรอง ต้องเป็นการตัดสินใจของผู้มีอำนาจ

## เมื่อทำงานต่อไม่ได้

| สิ่งที่พบ | ลองทำต่อแบบนี้ |
| --- | --- |
| ยังไม่เชื่อมต่อ AI หรือทดสอบไม่ผ่าน | เปิดการเชื่อมต่อ AI แล้วลองทดสอบบัญชีเดิมอีกครั้ง |
| ร่างมีช่องรอยืนยัน หรือบอกว่าไม่มีแหล่งข้อมูล | แนบต้นเรื่องที่มีสิทธิ์ส่ง หรือให้เจ้าของงานยืนยันข้อมูลก่อน |
| อ่านใบเสร็จหรือกรอกผิด | เทียบต้นฉบับและแก้ในฟอร์มก่อนยืนยัน |
| งานใหม่ปนกับเรื่องเก่า | กดเริ่มงานใหม่เมื่อเปลี่ยนเรื่อง |
| อัปเดตไม่สำเร็จ | กดลองอัปเดตอีกครั้งในแอป หรือดู [วิธีอัปเดต](desktop/README.md#อัปเดตแอป) |

หากยังมีปัญหา **ถ่ายภาพหน้าจอพร้อมข้อความผิดพลาด** ปิดบังข้อมูลอ่อนไหว และแจ้งรุ่นแอป ระบบปฏิบัติการ และบริการ AI ที่ใช้ผ่าน [STeP AI Support](SUPPORT.md)

## ถ้ามีโปรแกรม AI ที่ใช้อยู่แล้ว

ใช้ **STeP Skills** ใน Claude, Codex หรือ Google Antigravity ได้ โดยติดตั้งแนวทางงานและกติกาชุดเดียวกันลงในโปรแกรมที่มีอยู่ เหมาะกับผู้ที่ต้องการทำงานผ่านโปรแกรมนั้นต่อ

ดู [วิธีติดตั้ง STeP Skills](plugins/step/README.md) ส่วนหน้าตรวจใบเสร็จ ฟอร์มร่างเอกสาร และแถบผลงาน ใช้ผ่าน STeP Desktop
