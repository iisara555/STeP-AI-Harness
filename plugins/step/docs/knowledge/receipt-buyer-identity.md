# ข้อมูลผู้ซื้อ STeP สำหรับตรวจใบเสร็จ

แหล่งที่มา: ผู้ดูแลโครงการแจ้งค่าที่ต้องใช้ตรวจใบเสร็จในบทสนทนา วันที่ **20 ตุลาคม 2569** (Asia/Bangkok)

สถานะ: **ข้อมูลอ้างอิงผู้ซื้อที่ผู้ใช้ระบุให้ตรวจ** ไม่ใช่นโยบายเบิกจ่ายหรือผลตรวจทะเบียนผู้เสียภาษีจากหน่วยงานภายนอก

- ชื่อผู้ซื้อ: **อุทยานวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยเชียงใหม่**
- เลขประจำตัวผู้เสียภาษี: **0-9940-00423-17-9**
- เลขประจำตัวผู้เสียภาษีแบบไม่ใส่ขีด: **0994000423179** (13 หลัก เก็บเป็นข้อความเพื่อรักษาเลขศูนย์นำหน้า)
- ที่อยู่ผู้ซื้อ: **เลขที่ 155 หมู่ 2 ตำบลแม่เหียะ อำเภอเมือง จังหวัดเชียงใหม่ 50100**

## ขอบเขตการนำไปตรวจ

ใช้เทียบข้อมูล **ผู้ซื้อ/ผู้รับบริการ** บนใบเสร็จแยกจากข้อมูลผู้ขาย/ผู้ออกเอกสาร ชื่อ ที่อยู่ หรือเลขภาษีในช่องผู้ขายไม่ใช้ยืนยันว่าข้อมูลผู้ซื้อถูกต้อง

การเว้นวรรค ขีดคั่นเลขภาษี ตัวเลขไทย/อารบิก และคำย่อที่ชัดเจน เช่น ต./ตำบล อ./อำเภอ จ./จังหวัด ไม่ถือเป็นความต่างทางเนื้อหาโดยตัวมันเอง ต้องเทียบเลขที่ หมู่ ตำบล อำเภอ จังหวัด และรหัสไปรษณีย์ครบ ไม่ใช้ fuzzy match ยอมรับเลขที่หรือเลขภาษีที่ผิดหนึ่งหลัก

ถ้าข้อมูลอ่านไม่ชัดหรือ OCR อ่านต่างกัน ให้ตรวจต้นฉบับก่อนระบุว่าผิด ห้ามนำค่าอ้างอิงไปเติมช่องที่เอกสารไม่มีแล้วสรุปว่าเอกสารถูกต้อง การมีเลขภาษีตรงหรือ checksum ถูกไม่ใช่ผลยืนยันทะเบียนภาษีหรือสิทธิเบิกจ่าย

ชื่อย่อ/ชื่อภาษาอังกฤษ สาขา/สำนักงานใหญ่ รูปแบบผู้ซื้อกรณีพิเศษ และข้อกำหนดว่าประเภทใดต้องแสดงข้อมูลใด **ยังไม่ได้รับข้อมูลเพิ่มในคำสั่งนี้** ให้ใช้ source ที่เกี่ยวข้องหรือรอ AFP ยืนยันตามกรณี ใบกำกับภาษีอย่างย่อที่ไม่มีช่องผู้ซื้อไม่ถูกตัดสินว่าผิดตามข้อกำหนดเต็มรูปโดยอัตโนมัติ

ข้อมูลนี้ใช้เป็นค่าอ้างอิงในการออกแบบระบบตรวจใบเสร็จ การเชื่อมเข้าระบบ OCR ใหม่และการพิจารณาชุดเบิกจ่ายต้องเป็นไปตามเกณฑ์ปัจจุบันที่ใช้กับรายการนั้น
