# STeP Context

- หน่วยงาน: อุทยานวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยเชียงใหม่ (STeP) และ Regional Science Park North
- งานหลักใน Pilot: งานสื่อสารสร้างสรรค์ งานออกแบบและนิทรรศการ งานบริหารโครงการ/TOR และระบบดิจิทัลภายใน
- ผู้รับสารมีทั้งผู้บริหาร เจ้าหน้าที่ นักวิจัย ผู้ประกอบการ คู่ค้า และสาธารณะ
- ผลลัพธ์ต้องคงความน่าเชื่อถือของหน่วยงาน ใช้งานได้จริง และมีเจ้าของงานตรวจอนุมัติ

เอกสารนี้เป็นบริบทระดับกว้าง ไม่ใช่แหล่งอ้างอิงแทนเว็บไซต์ทางการ ระเบียบ มติ หรือเอกสารโครงการล่าสุด

ข้อมูลทั่วไปที่ตรวจจากแหล่งสาธารณะทางการแล้ว (การจัดตั้ง พันธกิจ สายบริการ ที่อยู่ ช่องทางติดต่อ ดัชนี OIT) อยู่ที่ [STeP Public Profile](step-public-profile.md)
