# STeP Skills

**ให้ AI ที่คุณใช้อยู่ รู้แนวทางทำงานของ STeP**

เพิ่มแนวทางสำหรับสรุปประชุม ร่างหนังสือ ตรวจ TOR เตรียมงาน AFP และงานของแต่ละทีม ลงใน Claude, Codex หรือ Google Antigravity เริ่มจากต้นเรื่องของคุณ แล้วให้ AI ใช้ขั้นตอนและกติกาที่เกี่ยวข้องช่วยทำร่าง

[ดู STeP AI](https://github.com/iisara555/STeP-AI-Harness) · [ใช้ผ่าน STeP Desktop](https://github.com/iisara555/STeP-AI-Harness/blob/main/desktop/README.md)

## เหมาะกับคุณเมื่อมีโปรแกรม AI อยู่แล้ว

| โปรแกรมที่ใช้ | บัญชีที่โปรแกรมรองรับ |
| --- | --- |
| Claude Code / Claude Desktop | Claude Pro, Max, Team หรือ Enterprise |
| Codex | ChatGPT Plus, Pro, Business หรือ Enterprise |
| Google Antigravity | บัญชี Google ที่มีสิทธิ์ รวม Google AI Plus/Pro ตามเงื่อนไขของผู้ให้บริการ |

Skills ช่วยกำหนดโครงสร้างงาน วิธีตรวจต้นเรื่อง และกติกาการเขียน ข้อมูลที่ขาดต้องรอยืนยัน คุณยังเป็นผู้ตรวจร่าง และผู้มีอำนาจเป็นผู้อนุมัติงานจริง สิทธิ์เครื่องมือ การส่งข้อมูล และโควตาขึ้นกับโปรแกรม AI ที่ใช้

**ถ้าใช้ STeP Desktop อยู่แล้ว ไม่ต้องติดตั้งชุดนี้เพิ่ม** Desktop มี Skills ชุดเดียวกัน พร้อมฟอร์มร่างเอกสาร หน้าตรวจใบเสร็จ และแถบผลงาน ส่วนชุดนี้เพิ่มแนวทางลงในโปรแกรม AI ที่คุณมี ไม่ได้ติดตั้งหน้าจอหรือเครื่องมือของ Desktop

## เริ่มใช้ด้วยไฟล์ติดตั้งเดียว

1. ติดตั้งโปรแกรม AI ที่ต้องการและเปิดอย่างน้อยหนึ่งครั้ง
2. ติดตั้ง [Node.js รุ่น LTS](https://nodejs.org) ถ้ายังไม่มี แนะนำ Node 24 สำหรับชุดนี้
3. เปิด [repository](https://github.com/iisara555/STeP-AI-Harness) กด **Code → Download ZIP** แล้วแตกไฟล์
4. ดับเบิลคลิก **Setup-STeP-Skills.bat** บน Windows หรือ **Setup-STeP-Skills.command** บน Mac
5. ตอบชื่อเรียก ทีม ชื่อผู้ช่วย และสไตล์การคุย ข้ามได้ด้วย Enter แล้วเริ่มแชตใหม่

ตัวติดตั้งลง Skills ให้โปรแกรมที่พบในเครื่อง โปรแกรมที่ไม่มีจะถูกข้าม คุณรันซ้ำเพื่ออัปเดตหรือแก้โปรไฟล์ได้ โปรไฟล์ใช้ร่วมกับ STeP Desktop แต่ไม่ควรใส่เลขบัตร เบอร์โทร หรือรหัสผ่าน

ลองเริ่มงานด้วย:

> สรุปการประชุมนี้ แยกมติ งานที่ต้องทำ และเรื่องที่ยังรอยืนยัน

> ช่วยตรวจ TOR นี้ว่าขอบเขตงานและเกณฑ์ตรวจรับยังขาดอะไร

> ร่างหนังสือราชการจากต้นเรื่องนี้ เว้นข้อมูลที่ยังไม่มีให้ฉันยืนยัน

## ติดตั้งเฉพาะโปรแกรมที่ใช้

ใช้วิธีนี้เมื่อเลือกติดตั้งทีละโปรแกรมแทนไฟล์ Setup ด้านบน

### Claude

ใน Claude Code พิมพ์:

```text
/plugin marketplace add iisara555/STeP-AI-Harness
/plugin install step@step-ai
```

เริ่มแชตใหม่และบอกงานตามปกติ หรือเลือก Skill เอง เช่น `/step:meeting-summary` อัปเดตด้วย `/plugin marketplace update step-ai` แล้วเริ่มแชตใหม่

### Codex

```text
codex plugin marketplace add iisara555/STeP-AI-Harness
codex plugin add step@step-ai
```

Codex ไม่รัน hook ของ plugin จึงต้องเพิ่มกติกาอีกครั้งเดียว จากโฟลเดอร์ repository ที่ดาวน์โหลดมา:

```text
node scripts/install-agent-skills.mjs codex
```

อัปเดตด้วย `codex plugin marketplace upgrade` หากไม่มี Node.js ใช้เนื้อหา `session-brief.md` วางท้าย `~/.codex/AGENTS.md` ได้

### Google Antigravity

จากโฟลเดอร์ repository ที่ดาวน์โหลดมา:

```text
node scripts/install-agent-skills.mjs antigravity
```

ปิดแล้วเปิด Antigravity ใหม่ ติดตั้งครั้งเดียวใช้ได้ทุกโฟลเดอร์งาน หากต้องการเฉพาะโฟลเดอร์เดียว ให้ระบุโฟลเดอร์ต่อท้ายคำสั่ง ใช้แบบใดแบบหนึ่งเพื่อไม่ให้ Skills ซ้ำ

อัปเดตด้วยการดาวน์โหลด source ใหม่แล้วรันคำสั่งเดิม Skills ของคุณเองจะไม่ถูกแตะ ชุดนี้ใช้ Antigravity สำหรับบัญชี Google ส่วนตัว ไม่ใช้ Gemini CLI ที่หยุดรองรับบัญชีเหล่านั้น

## แก้โปรไฟล์หรือถอนการติดตั้ง

แก้ชื่อ ทีม ผู้ช่วย และสไตล์จากโฟลเดอร์ repository ด้วย:

```text
node scripts/install-agent-skills.mjs profile
```

ถอนด้วย **Uninstall-STeP-Skills.bat** หรือ **Uninstall-STeP-Skills.command** ระบบถอนเฉพาะ Skills กติกา และโปรไฟล์ที่ Setup เขียนไว้ ไม่ลบข้อความที่คุณเขียนเองหรือไฟล์ผลงาน และถามก่อนลบโปรไฟล์ที่ใช้ร่วมกับ Desktop

## ก่อนใช้กับงานจริง

ใช้ข้อมูลที่มีสิทธิ์ส่งให้โปรแกรม AI นั้น ตรวจร่าง ตัวเลข และแหล่งข้อมูลก่อนใช้ การกำหนดกติกาใน Skills ไม่ได้รับรองว่าโปรแกรม AI จะบังคับจุดยืนยันทุกแบบเหมือน Desktop เครื่องมือ Excel / PowerPoint ต้องมีให้ใช้ในโปรแกรมนั้น ไม่ได้ติดตั้งพร้อม Skills

Repository นี้เป็น public ห้ามเก็บเอกสารจริง ข้อมูลส่วนบุคคล ผล OCR จากใบเสร็จจริง หรือ credentials ในโฟลเดอร์ repository เอกสารควบคุมใช้จากช่องทางภายในที่ได้รับอนุญาต

รุ่น Skills / Harness **0.7.6** แยกจากรุ่น Desktop Claude/Codex marketplace อัปเดตจาก `main` ส่วนสคริปต์ใช้ source ที่ดาวน์โหลดมา ต้องอัปเดตการติดตั้งแล้วเริ่มแชตใหม่จึงใช้ชุดใหม่
