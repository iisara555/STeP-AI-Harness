# Direction Framework — Principles, Brief Gate & 6-Layer Engine

คู่มือวิธีคิดสำหรับ `creative-art-director` เพื่อกำหนดทิศทางงานก่อนลงมือผลิตหรือออกแบบรายละเอียด

---

## 1. หลักคิดกลาง 4 ประการ

1. **Intent ก่อน Style:** อย่าเริ่มจากคำว่า Minimal, Futuristic, Luxury, Notion, Swiss หรือ Photorealistic เริ่มจาก: (1) งานนี้ต้องช่วยอะไร (2) ผู้ชมคือใคร (3) หลังเห็นแล้วควรเข้าใจ/รู้สึก/ทำอะไร (4) ข้อจำกัดจริงคืออะไร Style เป็นผลลัพธ์ของเหตุผล ไม่ใช่จุดเริ่มต้น
2. **Form Follows Feeling:** Visual form ต้องสร้างอารมณ์ที่เหมาะกับงาน เช่น งานบริการองค์กร = ชัดเจน เข้าถึงง่าย; Deep Tech = แม่นยำ มีน้ำหนักทางเทคนิค; Startup = มีพลัง คล่องตัว; Community / Lanna = จริงใจ มีบริบท ไม่ตกแต่งผิวเผิน; Executive = สงบ แม่น กระชับ มีลำดับความสำคัญ
3. **ความเรียบง่ายคือการเลือก ไม่ใช่การตัดของ:** ลดองค์ประกอบที่ไม่ช่วย Intent โดยไม่ลดข้อมูลที่จำเป็นต่อการใช้งาน
4. **Consistency ≠ Uniformity:** รักษา Brand DNA และเหตุผลร่วมกัน แต่ปรับ Art Direction ตามผู้ชม บริบท และช่องทาง

---

## 2. Five Questions Before Direction (ตอบจากข้อมูลที่มี ห้ามถามซ้ำ)

1. **Outcome — งานนี้ต้องทำให้เกิดอะไร?** (สมัครโครงการ, เชื่อถือเทคโนโลยี, เข้าใจบริการ, เดินเข้างาน, จำแบรนด์)
2. **Audience State — ผู้ชมมาในสภาพไหน?** (รีบ, สงสัย, ยังไม่รู้จัก, ต้องการข้อมูลอนุมัติ, เดินสำรวจ)
3. **Target Feeling — หลังเห็นงานควรรู้สึกอย่างไร?** เลือก 1 ความรู้สึกหลัก + 1 ความรู้สึกรอง
4. **Personality — ถ้างานนี้เป็นคน จะมีบุคลิก 3 คำว่าอะไร?** ใช้ตัดสิน Color, Type, Layout, Image และ Material
5. **Core Scene — ช่วงเวลาหรือภาพจำที่สำคัญที่สุดคืออะไร?** คิดเป็น scene หรือ action

*(หากขาดเฉพาะรายละเอียดที่ไม่เปลี่ยนแนวคิด ให้เดินหน้าด้วยสมมติฐานที่ติดป้าย `รอยืนยัน`; หากขาดแกนหลักให้ถามเพียง 1–3 คำถามที่เปลี่ยน Direction จริง)*

---

## 3. Brief Gate

- **ข้อมูลขั้นต่ำ:** Objective/Outcome · Audience · Key Message / สิ่งที่อยากให้จำ · Format/Context (Poster, Booth, Presentation, Campaign)
- **ข้อมูลเสริม:** Existing CI / Partner CI · Reference · Budget / Material / Venue constraints · Mandatory content · What to avoid

---

## 4. Direction Engine (6 ชั้น)

1. **Layer A — Design Intent:** สรุป 1 ประโยค `"เราจะทำให้งานนี้รู้สึก ______ เพื่อให้ ______"` เชื่อม Feeling กับ Outcome
2. **Layer B — Visual Tension:** Low (สงบ เป็นระบบ น่าเชื่อถือ), Medium (มีพลังแต่อ่านง่าย), High (ดึงสายตา แข่งกับสภาพแวดล้อม เช่น Event/Campaign)
3. **Layer C — Information Density:** Sparse / Balanced / Dense ตามเวลาที่ผู้ชมมองจริง
4. **Layer D — Visual Hammer:** Signature visual action ใน 1 ประโยคที่ขยายได้หลาย touchpoint (เช่น "หลายหน่วยรวมเป็นเส้นทางเดียว", "ข้อมูลซ้อนชั้นเปิดเผยทีละระดับ") — ไม่ใช่แค่ Logo, Pattern หรือสีลอย ๆ
5. **Layer E — Design Language:** Color role (foundation / anchor / signal), Typography character, Composition (centered / asymmetric / modular / layered / cinematic / spatial), Shape language, Image language, Material language
6. **Layer F — Brand Relationship (STeP):** STRONG (Official / Service / Internal), BALANCED (Campaign / Event / Innovation — ค่าเริ่มต้น), LIGHT (Cultural / Collaboration / Experimental)

---

## 5. Reference-Led Direction & Design Critique Mode

- **Reference-Led Direction:** ห้ามลอก appearance ตรง ๆ วิเคราะห์ 6 ด้าน (Composition, Hierarchy, Color relationship, Typography character, Material/Texture, Mood/Lighting/Rhythm) แล้วสรุปเป็น **KEEP** (หลักการที่เหมาะ) / **ADAPT** (ปรับเข้า STeP) / **AVOID** (identity ต้นฉบับที่ไม่ลอก)
- **Design Critique (ตรวจ 7 ข้อ):** 1) Intent Fit · 2) Hierarchy · 3) Feeling Fit · 4) Distinctiveness (Visual Hammer) · 5) Brand Fit · 6) Production Reality · 7) AI-Slop Risk → สรุปเป็น **Keep / Fix First (1–3 จุด) / Direction**
