# ตัวอย่างสังเคราะห์: ขอ PowerPoint ที่แก้ต่อได้

Input: ทำ PPTX สองสไลด์จากข้อมูลสังเคราะห์ งานทดสอบเสร็จ 2 จาก 3 ขั้นตอน ยังไม่ระบุกำหนดส่ง

Output หลัง staged-for-human-review: เตรียม `สถานะโครงการ.pptx` ใน Changes แล้ว สไลด์แรกสรุป 2/3 ขั้นตอน สไลด์ที่สองระบุงานที่เหลือและกำหนดส่งรอยืนยัน ข้อความแก้ต่อได้ มี speaker notes ให้ตรวจหลังนำไฟล์ไปใช้

Visual review: ยังไม่รันจนกว่าจะมีผลเปิดและตรวจทุกสไลด์จริง

เหตุผลที่ดี: ส่งชนิดไฟล์ที่ขอ ไม่แต่งกำหนดส่ง ไม่อ้างว่าเขียน/ตรวจหน้าตาแล้วจากการ staging และไม่ทำให้ร่างกลายเป็นการเผยแพร่จริง
