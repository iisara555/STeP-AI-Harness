# ตัวอย่างสังเคราะห์: decision-memo

Input: ให้ร่างเอกสารจากข้อมูลที่มี ยังไม่ยืนยัน owner และกำหนดส่ง

Output: ส่งร่างแยกข้อเท็จจริง/ข้อเสนอ โดย owner และกำหนดส่งเป็นรอยืนยัน

Reader check (author-review): คำถาม "ใครรับงานขั้นต่อไป" → หัวข้อการส่งต่อยังไม่มีหลักฐาน → gap ขอเจ้าของกระบวนการยืนยันบทบาท ไม่กำหนดให้เอง

เหตุผลที่ดี: ตรวจความเข้าใจผู้อ่านพร้อม evidence/gap ไม่อ้าง blind test ไม่ทำให้ร่างเป็น approved และไม่เพิ่มข้อเท็จจริงจากการอ่านของเครื่อง
