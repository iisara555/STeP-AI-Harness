# ตัวอย่างสังเคราะห์: reader evidence

ต้นทาง: ร่างเอกสารกล่าวว่า "ส่งข้อมูลให้ผู้ประสานงาน" แต่ไม่มีชื่อบทบาทหรือช่องทาง

Finding: หัวข้อการส่งต่อยังไม่พอให้ผู้อ่านทำซ้ำได้

Reader check (author-review): question="ส่งให้ใคร/ทางใด"; evidence="หัวข้อการส่งต่อ"; gap="ไม่มี role/channel"; owner action="ขอเจ้าของเอกสารยืนยันบทบาทและช่องทาง"

เหตุผลที่ดี: finding มีตำแหน่งและสิ่งที่ต้องแก้ ไม่อนุมานชื่อ/อำนาจ ไม่รับรอง compliance และไม่อ้างผล blind test
