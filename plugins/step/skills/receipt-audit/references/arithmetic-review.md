# ตรวจยอดจากหลักฐาน ไม่ใช้สูตรแทนสิทธิเบิก

เปิดเมื่อมี subtotal/VAT/total หรือใบเสนอราคาที่ต้องเทียบกับใบเสร็จ ใช้ [คู่มือวันที่และจำนวนเงิน](../../../docs/thai-data-formatting.md) สำหรับการจัดรูปแบบและ provenance

1. ระบุค่าที่อ่านตรงจากแต่ละเอกสาร แหล่ง และสถานะตรวจโดยคน อย่าเติมช่องภาษีที่ว่างด้วยการคำนวณ
2. ตรวจ quantity × unit price และ subtotal + VAT − discount = total เฉพาะองค์ประกอบที่เอกสารระบุ ถ้าส่วนลด/ฐานภาษีไม่ชัด ให้ NEED-INFO แทนการเลือกสูตรเอง
3. บันทึกสูตร ค่าที่ใช้ วิธีปัดเศษ และส่วนต่าง ใช้สตางค์หรือ decimal arithmetic ไม่สรุปว่าทุจริตจากส่วนต่าง
4. ถ้าอัตรา VAT/WHT หรือฐานที่ต้องใช้ยังไม่มี current verified source ให้ NEED-SOURCE แม้ยอดรวมบวกตรงกัน อย่าเลือก 7% หรือ 3% จากความจำ
5. เทียบชื่อ/รหัส/ยอดกับใบเสนอราคา PO และหลักฐานรับมอบเมื่อมี การตรงกันเป็นผลตรวจเฉพาะหลักฐาน ไม่ใช่การอนุมัติ

ตัวอย่างสังเคราะห์: เอกสารระบุฐาน 100.00, ภาษี 7.00, รวม 108.00 → 100.00 + 7.00 = 107.00 ส่วนต่าง 1.00 ให้ FLAG และเทียบต้นฉบับ อัตรา 7% ในตัวอย่างไม่ใช่กฎภาษีปัจจุบัน

หากค่าข้างต้นยังเป็น `EXTRACTED_UNVERIFIED` ให้รายงาน “หากค่าที่อ่านถูกต้อง พบส่วนต่าง 1.00” ไม่เปลี่ยนเป็น `DERIVED_FACT` ที่ยืนยันแล้ว ส่งข้อสงสัยกฎภาษี/สิทธิเบิกให้ AFP

ดู [ตัวอย่างเทียบยอด](../examples/arithmetic-review.md) สำหรับหลักฐานครบแต่กฎภาษียังขาด
