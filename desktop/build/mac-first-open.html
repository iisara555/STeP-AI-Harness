วิธีเปิด STeP Desktop ครั้งแรกบน Mac

ทำครั้งเดียวต่อเครื่อง หลังจากนี้เปิดและอัปเดตได้ตามปกติ

อย่ากด Move to Trash ถ้า macOS ถามตอนเปิดครั้งแรก STeP Desktop ยังไม่ได้ลงชื่อด้วยใบรับรองของ Apple macOS จึงบล็อกการเปิดครั้งแรกไว้ก่อน แอปไม่ได้เสียและไม่มีไวรัส

1. ย้ายแอปไปที่ Applications

ในหน้าต่างนี้ ลากไอคอน STeP Desktop ไปวางบนโฟลเดอร์ Applications

2. เปิดแอปจาก Applications

เปิด Finder → Applications แล้วดับเบิลคลิก STeP Desktop ถ้าแอปเปิดได้เลยก็เสร็จแล้ว ถ้าขึ้นหน้าต่างเตือน ให้ดูข้อความในหน้าต่างแล้วทำตามข้อ 3 หรือข้อ 4

3. ถ้าขึ้นว่า “Apple could not verify…” หรือ “cannot be opened”

  1. กด Done (หรือ OK) ปิดหน้าต่าง
  2. เปิด System Settings → Privacy & Security แล้วเลื่อนลงล่างสุด
  3. ตรงบรรทัด “STeP Desktop was blocked…” กด Open Anyway ใส่รหัสผ่านเครื่อง แล้วกด Open Anyway อีกครั้ง

4. ถ้าขึ้นว่า “is damaged and can’t be opened”

  1. กด Cancel (อย่ากด Move to Trash)
  2. เปิดแอป Terminal (กด Command + Space พิมพ์ Terminal แล้วกด Enter)
  3. คัดลอกคำสั่งนี้ไปวาง แล้วกด Enter xattr -cr "/Applications/STeP Desktop.app" คำสั่งนี้ลบป้าย “ไฟล์ที่ดาวน์โหลดจากอินเทอร์เน็ต” ออกจากแอป ไม่ได้เปลี่ยนอะไรอย่างอื่นในเครื่อง
  4. ดับเบิลคลิก STeP Desktop ใน Applications อีกครั้ง
ดาวน์โหลด STeP Desktop จากหน้า Release ของ STeP เท่านั้น ถ้าได้ไฟล์มาจากที่อื่น อย่าข้ามคำเตือนของ macOS ให้ถามผู้ดูแล STeP ก่อน
