# Profile pictures

`avatar-01.webp` to `avatar-36.webp` are the original bundled illustrations. Retired near-copies remain valid for existing selections.

`avatar-37.webp` to `avatar-56.webp` add 20 fictional office employees, requested on 2026-10-18. They match the original Notion-style black ink on white paper, with collared shirts, blazers and office clothing. Faces, hairstyles, glasses and age vary; these do not depict real employees.

Each new portrait was generated separately with the built-in imagegen tool, using `avatar-01` and `avatar-36` only as drawing-style and framing references. The originals were reviewed together with the existing set, then resized and encoded as 256px WebP assets for the picker. All images load from the app bundle.
