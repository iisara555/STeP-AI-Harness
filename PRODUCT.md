# STeP Desktop

An employee workspace for all STeP teams. Employees describe work in Thai, review an editable draft beside the conversation, and export usable files. Existing STeP routing, context minimization, privacy, and authority remain the source of truth.

The first release supports personal AI connections, local history, text editing and versioned exports on Windows and macOS. Organization-funded connections are a future extension. No external submission, budget approval, publishing, background automation, or cloud collaboration is included.

Success requires tested provider connections and real file validation. A preview or mock test never proves live provider access or another operating system's support.
