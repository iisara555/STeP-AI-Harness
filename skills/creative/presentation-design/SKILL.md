# Presentation Design

1. นิยามการตัดสินใจที่ต้องการจากผู้ชมและเวลานำเสนอ
2. สร้าง story arc: เหตุผล → หลักฐาน → แนวทาง → ผลลัพธ์ → สิ่งที่ขออนุมัติ
3. ให้หนึ่งสไลด์มีหนึ่งประเด็นหลักและหัวข้อเป็นข้อสรุป ไม่ใช่ชื่อหมวดกว้าง
4. ใช้ภาพ แผนภูมิ ตาราง หรือ diagram เฉพาะเมื่อช่วยให้เข้าใจเร็วกว่าเนื้อความ
5. คุม hierarchy, grid, spacing, contrast และขนาดตัวอักษรสำหรับระยะดูจริง
6. ทำ speaker note สำหรับข้อมูลสำคัญที่ไม่ควรอัดบนสไลด์
7. ตรวจตัวเลข ที่มา โลโก้ และคำขออนุมัติก่อนส่ง

ส่ง storyboard ก่อนลงรายละเอียดภาพ หากข้อมูลยังไม่พอให้ทำ placeholder ที่ระบุเจ้าของข้อมูลชัดเจน
