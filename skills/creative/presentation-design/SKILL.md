# การออกแบบ Presentation

1. กำหนดการตัดสินใจที่ต้องการจากผู้ชมและเวลานำเสนอ
2. สร้าง Story Arc: เหตุผล → หลักฐาน → แนวทาง → ผลลัพธ์ → สิ่งที่ขออนุมัติ
3. ให้หนึ่ง Slide มีหนึ่งประเด็นหลัก และหัวข้อเป็นข้อสรุป ไม่ใช่ชื่อหมวดกว้าง
4. ใช้ภาพ แผนภูมิ ตาราง หรือ Diagram เฉพาะเมื่อช่วยให้เข้าใจเร็วกว่าเนื้อความ
5. ควบคุม Hierarchy, Grid, Spacing, Contrast และขนาดตัวอักษรสำหรับระยะดูจริง
6. ทำ Speaker Note สำหรับข้อมูลสำคัญที่ไม่ควรใส่บน Slide
7. ตรวจตัวเลข แหล่งที่มา Logo และคำขออนุมัติก่อนส่ง

ส่ง Storyboard ก่อนลงรายละเอียดภาพ หากข้อมูลยังไม่พอให้ทำ Placeholder ที่ระบุเจ้าของข้อมูลชัดเจน
