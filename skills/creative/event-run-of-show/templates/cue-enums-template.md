# แม่แบบ Cue Enums

รหัสในเอกสารนี้ **ไม่ใช่มาตรฐานกลางของ STeP** เป็นข้อตกลงรายงานระหว่างทีมผู้จัดกับทีม AV ที่รับงานนั้น

หลักฐาน: ตัวอักษร A, B, C, D ถูกใช้ในเอกสาร sequence ของ STeP หลายฉบับด้วยความหมายที่ไม่ตรงกัน และบางงานยังเพิ่มรหัสเฉพาะกิจของตัวเอง เช่น รหัสที่ผูกกับชื่อ session นั้น ๆ

ดังนั้นทุกแถวเริ่มต้นที่ `รอยืนยัน` เสมอ **ห้ามใช้รหัสในตารางคิวหลักจนกว่าช่อง `ยืนยันโดย` จะมีชื่อจริง**

| --- | --- | --- | --- | --- | --- |
| A | สถานะพัก ไม่มีคนบนเวที จอขึ้น Key Visual | จอ, แสง | รอยืนยัน | | |
| B | พิธีกรหรือผู้พูดขึ้นเวที จอขึ้นชื่อและตำแหน่ง | จอ, แสง, เสียง | รอยืนยัน | | |

| D | ช่วงเนื้อหาพร้อมภาพสด จอข้างขึ้นภาพจากกล้อง | จอ | รอยืนยัน | | |

## Status ของคิว

enum นี้เป็นคำศัพท์กระบวนการขององค์กร ใช้ได้เลยโดยไม่ต้องรอยืนยัน

| ค่า | ความหมาย |
| --- | --- |
| `ยืนยันแล้ว` | เจ้าของงานยืนยันเนื้อหาและเวลาแล้ว |
| `รอยืนยัน` | ยังมีค่าที่ต้องให้คนยืนยัน |
| `ร่าง` | ยังไม่ผ่านการตรวจจากเจ้าของงาน |
| `ยกเลิก` | ตัดออกแล้ว เก็บแถวไว้เพื่อไม่ให้เลขคิวเลื่อน |

## สถานะของ lane

| ค่า | ความหมาย |
| --- | --- |
| `ใช้` | มีทีมรับผิดชอบและมีข้อมูลจริง |
| `ไม่ใช้ในงานนี้` | ตัดสินแล้วว่างานนี้ไม่มี lane นี้ ให้ลบคอลัมน์ออกจากตารางคิว |

lane ที่ปล่อยว่างโดยไม่ระบุสถานะ ถือเป็นข้อบกพร่องตามกฎ R5
