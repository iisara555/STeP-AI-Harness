# Project Plan

1. ระบุเป้าหมาย ขอบเขต สิ่งที่ไม่รวม และ Definition of Done
2. แตกงานตาม Deliverable ไม่แตกตามชื่อฝ่ายอย่างเดียว
3. กำหนด milestone จากวันใช้งานจริงย้อนกลับ รวมเวลาตรวจ แก้ ผลิต ขนส่ง และติดตั้ง
4. ระบุ Owner หนึ่งคนต่อ Action และผู้อนุมัติแต่ละ Gate
5. ทำ dependency และ critical path ให้เห็นชัด
6. จัด Risk register ด้วย Probability, Impact, Trigger, Mitigation และ Owner
7. กำหนดรูปแบบ status: Not started, In progress, Review/Fix, Done, Blocked

ส่งแผนที่นำเข้าเครื่องมือจัดการงานได้ โดยใช้วันที่จริงเมื่อมีหลักฐาน และใช้ relative timeline เมื่อยังไม่มีวันยืนยัน
