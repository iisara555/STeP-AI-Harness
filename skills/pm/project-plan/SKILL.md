# แผนโครงการ

1. ระบุเป้าหมาย ขอบเขต สิ่งที่ไม่รวม และ Definition of Done
2. แตกงานตาม Deliverable ไม่แตกตามชื่อฝ่ายเพียงอย่างเดียว
3. กำหนด Milestone โดยนับย้อนจากวันที่ใช้งานจริง รวมเวลาตรวจ แก้ ผลิต ขนส่ง และติดตั้ง
4. ระบุ Owner หนึ่งคนต่อ Action และผู้อนุมัติของแต่ละ Gate
5. ทำ Dependency และ Critical Path ให้เห็นชัด
6. จัด Risk Register ด้วย Probability, Impact, Trigger, Mitigation และ Owner
7. กำหนดรูปแบบ Status: Not Started, In Progress, Review/Fix, Done และ Blocked

ส่งแผนที่นำเข้าเครื่องมือจัดการงานได้ โดยใช้วันที่จริงเมื่อมีหลักฐาน และใช้ Relative Timeline เมื่อยังไม่มีวันที่ยืนยัน
