# ตัวอย่างข้อเสนอโครงการที่ข้อมูลยังไม่ครบ

ข้อมูลสังเคราะห์เท่านั้น ไม่ใช่ชื่อโครงการ งบ หรือหลักฐานอนุมัติจริง

ผู้ใช้ให้: โครงการทดลองทักษะดิจิทัล มีวัตถุประสงค์ให้ผู้เข้าร่วมฝึกจัดเอกสาร กิจกรรมเป็นการฝึกปฏิบัติ ยังไม่มีวงเงิน จำนวนคน วันที่ และค่าเป้าตัวชี้วัด

## ตรวจข้อมูล / ขั้นต่อไป

ข้อมูลชื่อ วัตถุประสงค์ และกิจกรรมมาจากผู้ใช้ ไม่ใช่หลักฐานว่ามีโครงการหรืองบอนุมัติแล้ว ยังไม่มีแบบหน่วยงานและเงื่อนไขแหล่งทุนที่ตรวจฉบับได้ ร่างนี้ใช้ working template ของ Skill ให้เจ้าของเรื่องเติมข้อมูลและ AFP ตรวจแหล่งงบก่อนเสนอผู้มีอำนาจ

เหตุผลที่ตัวอย่างนี้ใช้ได้: ส่งร่างข้อเสนอครบหัวข้อ ไม่แทนด้วย Gantt อย่างเดียว และไม่แต่งวงเงิน จำนวนคน วันที่ หรือเป้าตัวชี้วัดเพื่อให้ดูครบ
