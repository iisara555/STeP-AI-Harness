# TOR Review

1. แยกวัตถุประสงค์ ขอบเขต Deliverable Specification Timeline Acceptance Payment และผู้รับผิดชอบ
2. ทำ Traceability matrix ระหว่างวัตถุประสงค์ → งาน → ผลส่งมอบ → เกณฑ์ตรวจรับ
3. หาเลข ขนาด จำนวน วัน ชื่อรายการ หรือเงื่อนไขที่ขัดกัน
4. เปลี่ยนคำกำกวมเป็นเกณฑ์ที่วัดและตรวจรับได้ โดยไม่ล็อกยี่ห้อหรือผู้เสนอรายใดโดยไม่มีเหตุผล
5. ระบุ dependency จากเจ้าของโครงการ เช่น พื้นที่ ไฟฟ้า เนื้อหา โลโก้ การอนุมัติ และเวลาติดตั้ง
6. แยก `Critical`, `Major`, `Clarification` พร้อมข้อความแก้ที่เสนอ
7. แจ้งชัดว่านี่เป็นการตรวจเชิงโครงสร้าง ไม่ใช่คำวินิจฉัยกฎหมายหรือการอนุมัติจัดซื้อ
