# การตรวจ TOR

1. แยกวัตถุประสงค์ ขอบเขต ผลส่งมอบ คุณลักษณะเฉพาะ ระยะเวลา เกณฑ์ตรวจรับ การจ่ายเงิน และผู้รับผิดชอบ
2. ทำ Traceability Matrix ระหว่างวัตถุประสงค์ → งาน → ผลส่งมอบ → เกณฑ์ตรวจรับ
3. ตรวจหาเลข ขนาด จำนวน วัน ชื่อรายการ หรือเงื่อนไขที่ขัดกัน
4. เปลี่ยนคำกำกวมเป็นเกณฑ์ที่วัดและตรวจรับได้ โดยไม่ล็อกยี่ห้อหรือผู้เสนอรายใดโดยไม่มีเหตุผล
5. ระบุ Dependency จากเจ้าของโครงการ เช่น พื้นที่ ไฟฟ้า เนื้อหา Logo การอนุมัติ และเวลาติดตั้ง
6. แยก Critical, Major และ Clarification พร้อมข้อความแก้ที่เสนอ
7. แจ้งชัดว่านี่เป็นการตรวจเชิงโครงสร้าง ไม่ใช่คำวินิจฉัยกฎหมายหรือการอนุมัติจัดซื้อ
