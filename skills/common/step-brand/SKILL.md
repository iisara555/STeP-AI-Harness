# STeP Brand Review

## Purpose

ตรวจว่างานออกแบบที่เกี่ยวข้องกับ STeP สอดคล้องกับ Brand Source ที่ได้รับการยืนยันหรือไม่

Skill นี้มีหน้าที่ **ตรวจและชี้ความไม่สอดคล้อง**

ไม่ใช่สร้าง Brand Guideline ใหม่หรือกำหนด Creative Direction แทนเจ้าของ Brand

## Inputs

อาจได้รับ:

* Artwork
* Poster
* Social Media
* Presentation
* Booth / Exhibition
* Signage
* Document
* Website / UI
* Logo Asset
* Brand Guideline
* Template
* ตัวอย่างงานที่ได้รับอนุมัติ

## Reference Priority

ใช้หลักฐานตามลำดับนี้เมื่อมี:

1. Brand Guideline ที่ได้รับการยืนยัน
2. Official Logo / Brand Asset
3. Official Template
4. งานตัวอย่างที่ได้รับอนุมัติ
5. ข้อมูลที่ผู้ใช้ยืนยันในคำขอปัจจุบัน

หากแหล่งข้อมูลขัดกัน ให้รายงาน Conflict

ห้ามเลือกเองว่าข้อมูลใดถูก หากยังระบุ Source of Truth ไม่ได้

## Review

ตรวจเฉพาะรายการที่มีข้อมูลเพียงพอ เช่น:

* Logo usage
* Clear space
* Logo proportion
* Minimum size
* Brand hierarchy
* Color usage
* Contrast
* Typography
* Grid / alignment
* Readability
* Co-branding
* Sponsor placement
* การใช้งานบนขนาดและช่องทางจริง

ไม่จำเป็นต้องตรวจทุกหัวข้อ หากไม่มีหลักฐานหรือไม่เกี่ยวข้องกับงานนั้น

## Findings

แต่ละประเด็นต้องระบุ:

* ตำแหน่ง
* สิ่งที่พบ
* Brand Reference ที่เกี่ยวข้อง
* ผลกระทบ
* วิธีแก้
* ระดับความมั่นใจ

รูปแบบ:

| ตำแหน่ง | สิ่งที่พบ | หลักฐาน Brand | วิธีแก้ | Confidence |
| ------- | --------- | ------------- | ------- | ---------- |

## Classification

ใช้สถานะ:

* `สอดคล้อง`
* `ไม่สอดคล้อง`
* `รอยืนยัน`

ใช้ `รอยืนยัน` เมื่อ:

* ไม่มี Guideline รองรับ
* Asset ไม่สามารถยืนยันได้
* Brand hierarchy ไม่ชัด
* แหล่งข้อมูลขัดกัน
* Artwork อ่านหรือเห็นรายละเอียดไม่พอ

## Rules

* ห้ามสร้างกฎ Brand จากความชอบส่วนตัว
* ห้ามถือว่างานเก่าเป็น Brand Standard โดยอัตโนมัติ
* ห้ามเปลี่ยน Logo, สี หรือ Font เพียงเพราะดูดีกว่า
* ห้ามสรุป Brand hierarchy หากไม่มีหลักฐาน
* ห้ามถือว่า CMU และ STeP ใช้กฎเดียวกันทุกกรณี
* แยก `Brand requirement` ออกจาก `Design suggestion`
* หากเป็น Design suggestion ต้องติดป้ายว่าเป็นข้อเสนอ ไม่ใช่ข้อกำหนด Brand
* หากไม่มี Brand Source เพียงพอ ให้รายงานสิ่งที่ตรวจไม่ได้แทนการเดา
