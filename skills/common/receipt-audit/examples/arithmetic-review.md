# ตัวอย่างสังเคราะห์ — ยอดตรงแต่ยังไม่มีกฎภาษี

ค่าที่คนเทียบเอกสารแล้ว: subtotal 100.00, VAT 7.00, total 107.00 เป็น SOURCE_FACT จากเอกสารสังเคราะห์ R-001

| Check | Status | Evidence | Source | Next action |
|---|---|---|---|---|
| บวกยอด | PASS | 100.00 + 7.00 = 107.00 | R-001; DERIVED_FACT พร้อมสูตรจากค่าที่ตรวจแล้ว | เก็บหลักฐานสูตร |
| อัตรา/ฐานภาษีที่ใช้ได้ | NEED-SOURCE | ยังไม่มี current verified source | รอยืนยันจาก AFP | ขอ AFP ยืนยันกฎปัจจุบัน |
| สิทธิเบิก/งบโครงการ | NEED-INFO | ยังไม่มีหลักฐานอนุมัติโครงการ | รอยืนยันจากเจ้าของเรื่อง | แนบหลักฐานที่เกี่ยวข้อง |

Overall: NEEDS-CURRENT-SOURCE ยอดตรงกันไม่แปลว่าอนุมัติจ่ายได้ หากค่าต้นทางเป็น EXTRACTED_UNVERIFIED ต้องเปลี่ยนผลบวกยอดเป็นการตรวจแบบมีเงื่อนไข ไม่แสดงเป็น DERIVED_FACT ที่ยืนยันแล้ว

## ทำไมคำตอบนี้ดี

ตรวจเลขและ provenance ได้โดยไม่ถืออัตราในตัวอย่างเป็น current rule และส่งเรื่องที่ต้องตัดสินให้ AFP
