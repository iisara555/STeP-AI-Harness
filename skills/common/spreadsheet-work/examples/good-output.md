# ตัวอย่างสังเคราะห์

Input: สร้าง Excel รหัส 00123 ค่าใช้จ่าย 100 บาท และ 00007 ค่าใช้จ่าย 200 บาท พร้อมสูตรยอดรวม ไม่ได้แนบ template

Output หลัง tool คืน staged-for-human-review:

เตรียม `แผนสังเคราะห์.xlsx` ใน Changes แล้ว มี sheet แผนงาน รหัสเป็นข้อความเพื่อคงศูนย์นำหน้า และ B4 ใช้สูตร SUM(B2:B3) ยังต้องตรวจ preview และนำไปใช้ตาม permission mode

หลังเปิด Excel/LibreOffice ให้ recalculate และตรวจว่ายอดรวมเท่ากับ 300 บาทจากข้อมูลที่ให้มา ยังไม่ได้ตรวจตาม template องค์กรหรือรับรองสิทธิ์เบิก

เหตุผลที่ดี: ผูกสถานะกับ tool จริง รักษาชนิดข้อมูล ไม่อ้างว่าคำนวณแล้วหรือไฟล์ถูกนำไปใช้แล้ว และไม่สร้างอัตราหรือการอนุมัติขึ้นเอง
