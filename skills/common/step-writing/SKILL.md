# STeP Writing

1. ระบุผู้รับสาร วัตถุประสงค์ ช่องทาง และระดับความเป็นทางการจากคำขอ
2. ดึงชื่อเฉพาะ วันที่ ตัวเลข ผู้รับผิดชอบ และสิ่งที่ต้องดำเนินการจากต้นทาง ห้ามเติมเอง
3. ขึ้นต้นด้วยข้อสรุปหรือ action ที่สำคัญที่สุด
4. จัดเนื้อหาเป็น: บริบท → ประเด็นสำคัญ → สิ่งที่ต้องทำ → ผู้รับผิดชอบ/กำหนดเวลา
5. แยกสิ่งที่ยืนยันแล้วออกจากสมมติฐานและคำถามค้าง
6. ตรวจตาม `rules/step-writing.md`, `rules/data-classification.md` และ `rules/human-approval.md`

ส่งร่างที่คัดลอกไปใช้ต่อได้ทันที และปิดท้ายด้วยรายการข้อมูลที่ยังต้องยืนยันเฉพาะเมื่อมีจริง
