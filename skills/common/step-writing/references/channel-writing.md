# วิธีร่างข้อความตามช่องทางของ STeP

เลือกโครงตามผู้รับสารและข้อมูลที่มี ไม่ถือแนวทางนี้เป็น Brand CI หรือข้อจำกัดแพลตฟอร์มปัจจุบัน หากมี Brand CI ที่ยืนยันแล้ว ให้ใช้แหล่งนั้นก่อน

| ช่องทาง | โครงที่เสนอ |
|---|---|
| Facebook / ประกาศสาธารณะ | ประเด็นที่เกี่ยวข้องกับผู้รับสาร → รายละเอียดที่มีหลักฐาน → การกระทำถัดไป |
| Instagram | สาระสั้นที่ตรงภาพ/กิจกรรม → ข้อมูลสำคัญ → ช่องทางจากต้นเรื่อง ใช้ hashtag ที่เกี่ยวข้องเท่านั้น |
| LINE OA / ข้อความทีม | บอกเรื่องและสิ่งที่ต้องทำให้เร็ว → เงื่อนไข/กำหนดเวลาที่มี → วิธีติดต่อ |
| ประกาศกิจกรรม/ถ่ายทอดสด | เรื่อง → ผู้เข้าร่วม/บทบาท → วันเวลา/สถานที่ → ช่องทางเข้าร่วมที่ยืนยันแล้ว |

ขั้นตอน:
1. ทำรายการข้อเท็จจริงที่มี กับช่องที่ขาด ก่อนเขียน เช่น วัน เวลา สถานที่ คุณสมบัติ ค่าธรรมเนียม URL และผู้ติดต่อ
2. เขียนจากข้อมูลจริง หลีกเลี่ยงคำโฆษณารับรองผลและความเร่งด่วนที่ไม่มีแหล่ง เช่น “เหลือ 5 ที่สุดท้าย” “รับรองสำเร็จ” หรือ “ฟรี”
3. ข้อมูลขาดให้เว้น `[รอยืนยัน: ช่อง]` ในร่างเพื่อพิจารณา พร้อมรายการที่ต้องยืนยันก่อนเผยแพร่ ไม่แต่ง URL หรือใช้ลิงก์ตัวอย่างเป็นของจริง
4. เลือกความยาว emoji และ hashtag ตามบริบทและคำขอ ไม่เหมารวมอายุ/บุคลิกผู้รับสารจากแพลตฟอร์ม และไม่อ้างว่า hashtag กำลังเป็นกระแสโดยไม่ได้ตรวจ
5. หากมีข้อจำกัดอักขระจริง ให้ตรวจแพลตฟอร์มปัจจุบันหรือค่าที่ผู้ใช้ระบุ ไม่ใช้ตัวเลขจากตารางต้นทางเป็นกฎถาวร
6. ส่ง `brand-tone-of-voice` ตรวจน้ำเสียงเมื่อผู้ใช้ขอตรวจแบรนด์; ส่ง `thai-official-documents` หากเป็นประกาศ/หนังสือตามแบบราชการ และส่ง `thai-english-translation` เมื่อต้องแปลจากต้นฉบับ

AI ร่างและตรวจได้ การโพสต์/ส่งข้อความจริงอยู่ใต้ Human Authority ดู [ตัวอย่างสังเคราะห์](../examples/channel-announcement.md)

ดัดแปลงแนวทางเลือกโครงตามช่องทางจาก `thai-social-caption` (Boom-Vitt/claude-thai-skills, MIT) เปลี่ยนตัวอย่างเชิงขายเป็นงานองค์กร ไม่ใช้คำมั่นหรือข้อกำหนดแพลตฟอร์มจากต้นทาง
