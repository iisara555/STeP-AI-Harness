# แหล่งอ้างอิงงานเอกสารราชการไทย

ใช้แหล่งราชการเป็นลำดับแรก และตรวจฉบับที่มีผลใช้บังคับในวันที่ทำงานจริง ไม่คัดลอกข้อความจากคู่มือของหน่วยงานอื่นมาเป็นข้อบังคับสากลโดยไม่ตรวจฐานอำนาจ

## แหล่งหลัก

- [สำนักงานปลัดสำนักนายกรัฐมนตรี กองกฎหมายและระเบียบกลาง](https://www.opm.go.th/th/legal/home) — จุดเริ่มต้นสำหรับระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณและฉบับแก้ไขเพิ่มเติม
- [ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ (ฉบับที่ ๔) พ.ศ. ๒๕๖๔](https://www.opm.go.th/media1/temp/panidapa/File/OPM%20Law/T_0001.PDF) — ใช้ตรวจส่วนที่เกี่ยวกับสารบรรณอิเล็กทรอนิกส์ โดยต้องตรวจฉบับหรือประกาศที่ใหม่กว่าจาก OPM อีกครั้ง
- [การพิมพ์หนังสือราชการภาษาไทยด้วยโปรแกรมการพิมพ์](https://www.opm.go.th/th/itcenter/directory/12137/%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%9E%E0%B8%B4%E0%B8%A1%E0%B8%9E%E0%B9%8C%E0%B8%AB%E0%B8%99%E0%B8%B1%E0%B8%87%E0%B8%AA%E0%B8%B7%E0%B8%AD%E0%B8%A3%E0%B8%B2%E0%B8%8A%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%A0%E0%B8%B2%E0%B8%A9%E0%B8%B2%E0%B9%84%E0%B8%97%E0%B8%A2) — คำอธิบายการพิมพ์และตัวอย่างหนังสือราชการ
- [แบบฟอร์มหนังสือราชการ กระทรวงการท่องเที่ยวและกีฬา](https://secretary.mots.go.th/news/2683) — รวมลิงก์คำอธิบาย Template หนังสือภายนอก หนังสือภายใน หนังสือประทับตรา และฟอนต์มาตรฐาน
- [ฟอนต์หนังสือราชการ กระทรวงศึกษาธิการ](https://www.moe.go.th/%E0%B8%9F%E0%B8%AD%E0%B8%99%E0%B8%95%E0%B9%8C%E0%B8%AB%E0%B8%99%E0%B8%B1%E0%B8%87%E0%B8%AA%E0%B8%B7%E0%B8%AD%E0%B8%A3%E0%B8%B2%E0%B8%8A%E0%B8%81%E0%B8%B2%E0%B8%A3-%E0%B8%82%E0%B8%AD%E0%B8%87-%E0%B8%AA/) — ข้อมูลฟอนต์มาตรฐานราชการไทยและการใช้ TH Sarabun

## วิธีใช้แหล่งอ้างอิง

1. เปิดหน้า OPM เพื่อตรวจระเบียบและฉบับแก้ไขล่าสุดก่อนให้สถานะผ่าน
2. เปิดคำอธิบายการพิมพ์และ Template ของหน่วยงานเจ้าของเอกสารเพื่อเทียบระยะขอบ แบบหัวกระดาษ และส่วนลงชื่อ
3. ถ้าเป็น TOR ให้ตรวจประกาศ/คู่มือจัดซื้อจัดจ้างของหน่วยงานและเอกสารอำนาจที่เกี่ยวข้องแยกจากมาตรฐานหนังสือราชการ
4. เก็บ URL ชื่อเอกสาร วันที่เผยแพร่ และวันที่ตรวจในรายงาน เพื่อให้ตรวจซ้ำได้
5. หากแหล่งทางการเปิดไม่ได้ ให้รายงานข้อจำกัดและอย่าสรุปว่าเป็นฉบับปัจจุบันจากแหล่งสำรองเพียงแห่งเดียว
