# วิธีเทียบต้นฉบับและคำแปล

1. เลือกระดับภาษาจากงานและผู้รับสาร: หนังสือทางการ อีเมลธุรกิจ ข้อความทีม หรือข้อความสาธารณะ ไม่เลือกสรรพนามตามเพศ/อายุที่คาดเดา
2. ใช้ศัพท์ที่เจ้าของยืนยันก่อนคำแปลทั่วไป เก็บชื่อเฉพาะและชื่อบริษัทตามต้นฉบับ หากไม่มีชื่อภาษาอังกฤษที่ยืนยัน ให้คงชื่อเดิมและทำเครื่องหมายรอยืนยัน
3. คำเทคนิคหรือ acronym อาจคงต้นฉบับพร้อมคำอธิบายเมื่อช่วยผู้รับสาร ไม่ขยาย acronym ที่มีหลายความหมายโดยเดา
4. แปลสำนวนตามความหมายจากบริบท หากบริบทไม่พอ ให้แสดงคำแปลทางเลือก หลีกเลี่ยงการเพิ่มความหมายเชิงสัญญาหรือกล่าวรับรอง
5. ตรวจตารางต่อไปนี้ก่อนส่งร่าง:

| สิ่งที่ตรวจ | วิธีตรวจ |
|---|---|
| ชื่อ / รหัส / เลขหนังสือ | เทียบอักขระและเลขนำหน้ากับต้นฉบับ |
| จำนวนเงิน / หน่วย | เทียบค่า สกุลเงิน และหน่วย ไม่เปลี่ยนอัตราแลกเปลี่ยนเอง |
| วันเวลา | ระบุศักราชเมื่อแปลง และไม่เติมศตวรรษหรือ timezone ที่ไม่มีหลักฐาน |
| เงื่อนไข | รักษาคำปฏิเสธ ยกเว้น ก่อน/หลัง และเงื่อนไขการอนุมัติ |
| สถานะ | proposed / pending / approved ต้องคงสถานะจากต้นฉบับ |
| ข้อมูลที่ขาด | คงช่องว่างพร้อมรายการรอยืนยัน ไม่เติมเพื่อให้เอกสารดูสมบูรณ์ |

การตรวจความหมายไม่เท่ากับการรับรองเอกสารหรือข้อกล่าวอ้างในต้นฉบับ ตารางศัพท์ที่เสนอใหม่ต้องติดสถานะรอยืนยันโดยเจ้าของข้อมูล
